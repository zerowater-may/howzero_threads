# HOWAAA Marketing AX Playbook

## 목적

HOWAAA Marketing AX Playbook은 AX 전환 하우제로가 실제 랜딩, 상담, 콘텐츠, 제안서에서 써야 하는 마케팅 AX 실행 구조다.

전사 AX 컨설팅처럼 넓게 말하지 않는다. 콘텐츠, SEO, 리드, CRM, 광고 리포팅, 세일즈 자료처럼 매출 파이프라인과 직접 연결되는 업무로 좁힌다.

## 핵심 메시지

```txt
AI 툴을 설치하는 게 아닙니다.
마케팅에서 새는 시간과 리드를 찾아 자동화하고,
매달 쌓이는 매출 파이프라인으로 바꿉니다.
```

## 6개 병목 카드

| 병목 | Before | After | 측정 기준 |
|---|---|---|---|
| 콘텐츠 | 블로그, 숏폼, 뉴스레터 초안이 매주 밀림 | 아이디어, 초안, 재가공 흐름 자동화 | 생산량, 제작 시간 |
| SEO/시장 조사 | 매일 검색해서 수동 정리 | 키워드, 경쟁사, 검색 의도 리포트 자동화 | 조사 시간, 발행 수 |
| 리드 수집 | 문의가 흩어지고 누락됨 | 폼/DM/메일 리드 수집과 태깅 | 리드 누락률, 응답 속도 |
| CRM 팔로업 | 문의 후 후속 연락이 늦음 | 세그먼트별 팔로업 메시지 자동 발송 | 응답 시간, 전환율 |
| 광고 리포팅 | 유입/전환 데이터를 손으로 합침 | 광고, GA, 시트 리포팅 자동 정리 | 리포트 시간, 의사결정 속도 |
| 세일즈 자료 | 제안서와 사례를 매번 새로 만듦 | 케이스 스터디, 제안서 초안 생성 | 제작 시간, 영업 준비 속도 |

## 5단계 진행 방식

1. 무료 오딧: 현재 마케팅 업무 흐름과 병목을 듣는다.
2. 마케팅 병목 지도: 콘텐츠, 리드, 팔로업, 리포팅 중 새는 지점을 표시한다.
3. 자동화 설계: 난이도 대비 가치가 높은 Quick Win부터 고른다.
4. 구축·교육: 고객 조직이 직접 운영할 수 있게 설치하고 넘긴다.
5. 월간 개선: 결과를 보고 워크플로우를 수정한다.

## CTA

- 메인: `30분 무료 마케팅 AX 오딧`
- 보조: `자동화 사례 보기`
- 최종: `마케팅에서 자동화할 병목이 없으면 팔지 않습니다.`

## 피해야 할 방향

- "최신 AI로 혁신합니다" 같은 범용 AI 문구.
- 툴 목록 중심 설명.
- 모든 업종 가능만 강조하는 넓은 포지셔닝.
- 실제 수치 없이 "효율 상승", "생산성 향상"만 반복.
- CS/정산/제조 견적처럼 마케팅과 직접 연결되지 않는 전사 업무를 메인으로 배치.
