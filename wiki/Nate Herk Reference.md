## 한 줄 판단

Nate Herk는 `AI 자동화 툴 출시`를 빠르게 받아 `실제 워크플로우`, `AI OS`, `에이전시/오퍼`, `커뮤니티`로 연결하는 채널이다. HowZero가 참고할 핵심은 툴 자체가 아니라 `신기술 → 실무 적용 → 무료 커뮤니티 → 유료 멤버십/구축`으로 이어지는 퍼널이다.

## 포지셔닝

- 표면 포지션: AI automation, Claude Code, n8n, agent workflow를 배우는 실전 채널.
- 실제 강점: 툴 업데이트를 빠르게 해석하고, 바로 쓸 수 있는 구조/템플릿/운영체제 관점으로 묶는다.
- 타겟: AI 자동화 빌더, 1인 창업가, AI 에이전시 준비자, Claude Code/n8n 파워유저.
- 대표 타겟 적합도: 중간. 대표도 볼 수 있지만 제목과 본문이 Claude Code 중심이라 개발자/빌더층으로 강하게 기운다.

## 콘텐츠 기둥

1. AI 툴 출시 해석: 새 모델, 새 기능, 새 워크플로우를 빠르게 설명한다.
2. Claude Code/agent 실습: skills, subagents, workflows, MCP, 배포, 세션 제한, 토큰 비용을 다룬다.
3. AI OS: 개인/사업 운영 파일, 루틴, 연결, 권한, 멘토 역할까지 묶는다.
4. AI 에이전시/오퍼: 자동화 서비스를 어떻게 팔고 상품화할지 다룬다.
5. 비교/벤치마크: Claude Code vs Codex, 모델별 성능, 가격/제한/품질 비교.
6. 쇼츠형 마이크로 훅: 99% 저렴, 10x, 제한 해결, 리드 분류, 제안서 생성 같은 즉시성 높은 소재.

## HowZero가 가져올 것

- 출시 대응 속도: 새 AI 기능을 `대표 업무 1개`에 바로 적용해 보여준다.
- AI OS 프레임: `대표 OS`로 번역한다. 매일 아침 리포트, 콘텐츠 발행, 리드 정리, 팔로업, 회의록, 제안서가 한곳에서 도는 구조.
- 무료 커뮤니티/자료: `대표 업무 자동화 체크리스트`, `30분 AX 오딧`, `대표 브리핑 템플릿`으로 유입시킨다.
- 코스형 롱폼: 1~2시간 풀코스는 신뢰와 검색 자산으로 좋다. 다만 한국 대표 타겟에는 챕터를 명확히 쪼개야 한다.
- 비교 콘텐츠: 도구 비교가 아니라 `업무 결과물 기준 비교`로 바꾼다.
- 비용/제한 콘텐츠: AI 비용, 토큰, 자동화 실패 비용을 대표 언어로 풀면 반응이 좋을 가능성이 높다.

## HowZero가 버릴 것

- Claude Code 중심 제목을 그대로 쓰면 비개발자 대표가 이탈한다.
- `10x`, `destroyed`, `unstoppable` 같은 과장형 표현은 HowZero 페르소나와 충돌한다.
- AI 에이전시로 돈 버는 축을 메인으로 잡으면 대표 고객보다 자동화 창업자만 모일 수 있다.
- 투자/트레이딩 자동화는 수익 약속처럼 보일 수 있다. `시장 리포트 자동화`, `리스크 알림`, `의사결정 보조`로 제한한다.
- 무료 커뮤니티를 열더라도 질문 응답/지원 범위를 정하지 않으면 리소스가 크게 샌다.
