# HowZero Overview

## 한 문장

하우제로는 하나의 이름 아래 두 개의 브레인을 가진다: 기업/1인 사업자 대상 AX 전환 HowZero와, 스마트스토어/쿠팡 셀러 대상 Commerce HowZero다.

## 핵심 정체성

- 실전가: 이론보다 직접 만든 SaaS, 자동화, 콘텐츠 시스템의 경험을 판다.
- 비개발자 편: 개발자가 없다는 이유로 AI 혜택을 못 받는 기업과 1인 사업자를 주요 고객으로 둔다.
- 결과 우선: “어떤 AI를 썼는가”보다 “시간, 인건비, 매출에 어떤 변화가 있었는가”를 기준으로 삼는다.
- 안티하이프: 유행하는 AI 도구 나열보다 프로세스 진단, 빠른 자동화, 운영 가능한 시스템을 중시한다.

## 브레인 분리

| 브레인 | 중심 페이지 | 핵심 질문 |
|---|---|---|
| AX 전환 HowZero | [[HowZero AX Index]] | "기업의 마케팅 병목과 리드 누수를 어떻게 자동화할까?" |
| Commerce HowZero | [[HowZero Commerce Index]] | "셀러의 상품 등록, 상세페이지, 태그 노가다를 어떻게 줄일까?" |

이 둘은 같은 하우제로 이름을 쓰지만 대본, 권위 문장, CTA, 금지 표현이 다르다. 새 작업을 시작할 때는 먼저 어느 브레인인지 정한다.

## 공통 사업 축

1. [[HOWAAA Methodology]]: Audit, Automate, Accumulate 방법론. 기본값은 AX 전환 브레인이다.
2. [[HowZero Product Lineup]]: 오딧, 구축, 리테이너, 교육, 템플릿, SaaS 후보.
3. [[HowZero Content Strategy]]: AX/커머스 콘텐츠 라우터.
4. [[HowZero Content Pipeline]]: 브랜드별 콘텐츠 자동 생성과 예약 발행.
5. [[HowZero Technical System]]: Threads API, 콘텐츠 리퍼포징, Next.js 대시보드, BullMQ worker.

## 저장소 관점

이 저장소는 단순 코드 저장소가 아니라 하우제로 운영체제에 가깝다.

- `docs/`: 페르소나, 전략, 기획, 구현 계획.
- `brands/`: 브랜드별 콘텐츠 원문과 산출물.
- `howzero-web/`: 대시보드와 worker.
- `src/`: Python 자동화 소스.
- `scripts/`: 콘텐츠 생성, 게시, 하이라이트 추출 유틸리티.
- `wiki/`: Codex/Obsidian이 읽기 쉬운 합성 지식 레이어.
