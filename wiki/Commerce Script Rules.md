# Commerce Script Rules

## 목적

커머스 하우제로 대본을 쓸 때 지켜야 할 구조, 말투, 금지 표현, 검증 기준이다.

## 기본 구조

롱폼 8~12분 기준:

| 구간 | 역할 |
|---|---|
| 0:00~0:40 | 손실/시간 압축 훅 |
| 0:40~1:30 | 권위 + 오늘 영상 약속 |
| 1:30~3:00 | 문제 구조 설명 |
| 3:00~5:30 | 데이터/자동화 데모 |
| 5:30~8:00 | 리스크/오해/경계선 |
| 8:00~9:30 | 실전 순서 |
| 9:30~10:00 | CTA |

## 도입부 필수 요소

1. 첫 5초에 대표님이 자기 문제라고 느끼게 만든다.
2. 15초 안에 결과물 또는 손실을 보여준다.
3. 30초 안에 권위와 약속을 박는다.
4. 진부한 방어 문장 대신 실제 비교, 증명, 전후 차이를 먼저 보여준다.
5. 마지막에 실행 지시나 리드매그넷 CTA로 닫는다.

## 자주 쓰는 전개

```txt
대표님 지금 이거 손으로 하고 계시죠?
→ 이거 오래 걸리는 이유는 단계가 많아서입니다.
→ 저희도 똑같이 손으로 했습니다.
→ 그래서 그 순서를 그대로 자동화했습니다.
→ 그런데 여기서 아무거나 넣으면 계정/광고/전환율이 죽습니다.
→ 그래서 안전한 기준은 이겁니다.
→ 지금 상품 하나만 열어서 이 순서로 해보세요.
```

## 좋은 문장 패턴

- "저희도 처음에 손으로 했습니다."
- "신기한 AI 아닙니다. 대표님이 하던 순서를 그대로 옮긴 겁니다."
- "이거 잘못하면 노출 늘리려다 매출이 0 됩니다."
- "대표님은 디자이너가 아니라 판매자입니다."
- "같은 상품도 SEO 없이 올린 버전과 SEO 맞춰 올린 버전은 출발선이 다릅니다."
- "완전 자동으로 밀어 넣는 게 아니라, 사람이 판단해야 할 부분만 남기는 반자동이 맞습니다."

## 금지 패턴

- 경쟁 유튜버나 셀러 코치를 깎아내리는 톤.
- “AI가 알아서 다 해준다” 식 만능론.
- 실증 데이터 없이 수익을 보장하는 문장.
- 포토샵/외주/수동 작업자를 멍청하게 만드는 표현.
- 공백이나 말장난만 바꾼 중복 콘텐츠.
- 반복 노출된 방어형 문장.

## 플랫폼 표현

- 사용: 스마트스토어, 스스, 쿠팡, 네이버쇼핑.
- 금지: 오프라인 판매처처럼 들리는 표현.
- 호칭: 대표님.

## 검증 목표

- 5초 retention: 90% 이상.
- 30초 retention: 75% 이상.
- 롱폼 평균 시청 지속: 50% 이상.
- CTA 클릭: Bulsaja 체험, 무료 오딧, 댓글 질문 중 하나로 측정.


## 쿠팡/광고비 리스크형 에피소드 구조

쿠팡·스마트스토어 광고비/소싱 리스크를 다룰 때는 아래 순서를 우선한다.

1. 첫 15초: 정산표, 광고비, 재고처럼 실제 손실 장면을 보여준다.
2. 문제 3분류: 시장 분석 부족, 손익분기점 없는 광고, 상품 집착.
3. 기준표: 키워드 수요, 상품 수, 최근 리뷰, 가격대, 브랜드/인증 리스크, 손익분기점 ROAS.
4. 자동화 연결: 소싱 후보 정리, 상품명/태그 구조화, 유입수/캠페인/순이익 확인.
5. 리스크 가드: 수익 보장, 노출·순위 보장, AI 만능론, 확정 월천 표현을 제거한다.

핵심 문장:

```txt
대표님이 봐야 하는 건 팔렸냐가 아니라 팔고 남았냐입니다.
```

```txt
자동화는 광고를 대신 켜주는 게 아니라, 대표님이 어디를 봐야 하는지 빨리 알려주는 겁니다.
```

```txt
대표님이 해야 할 건 노가다가 아니라 판단입니다.
```
