# HowZero AX Content Strategy

## 역할

이 페이지는 AX 전환 HowZero의 콘텐츠 전략이다. 커머스 대본은 [[Commerce Script Rules]]와 [[Commerce Hook Library]]를 따른다.

## 퍼널

```txt
유튜브/인스타/틱톡/쓰레드
→ 30분 무료 마케팅 AX 오딧
→ 이메일/DM 리드
→ 유료 오딧 또는 구축 제안
→ 리테이너/교육/템플릿
```

## 콘텐츠 원칙

- 실전 사례를 먼저 보여준다.
- 훅은 숫자, 반전, 비용 절감, 시간 절감으로 시작한다.
- "AI가 신기하다"가 아니라 "업무가 줄었다"를 보여준다.
- CTA는 무료 마케팅 AX 오딧으로 수렴한다.
- 사례가 없으면 도구 소개보다 프로세스 진단 콘텐츠를 우선한다.

## 검증된 훅 패턴

| 패턴 | 역할 | 예시 각도 |
|---|---|---|
| Direct Income | 권위 확보 | GPT-3 SaaS로 연매출 10억 |
| Contrarian | 시장 과장 깨기 | 문제의 80%는 AI가 아니라 프로세스 |
| No Coding Blueprint | 진입장벽 제거 | 코딩 없이 자동화 구축 |
| Marketing Leak | 마케팅 AX 포지셔닝 | 리드가 없는 게 아니라 팔로업이 새고 있다 |

## 채널별 역할

| 채널 | 역할 | AX 콘텐츠 |
|---|---|---|
| 유튜브 | 깊은 신뢰, 검색 유입, 메인 전환 | 오딧 사례, 자동화 구축 과정, 실패 분석 |
| 인스타그램 | 저장, 공유, 리드마그넷 전환 | 병목 체크리스트, Before/After, 비교표 |
| 틱톡 | 발견과 바이럴 | 짧은 자동화 데모, 결과 숫자 |
| 쓰레드 | 관계와 상담 전환 | 직설적 관찰, 실패담, 오딧 모집 |

## 첫 10개 AX 콘텐츠 축

1. 코딩 없이 GPT-3 SaaS로 연매출 10억 만든 과정.
2. AI 도입 전에 프로세스부터 봐야 하는 이유.
3. 30분 마케팅 AX 오딧에서 실제로 보는 것.
4. 콘텐츠 제작 시간이 새는 6가지 지점.
5. 리드 응답이 늦어져 전환이 새는 구조.
6. 광고 리포팅을 손으로 합치면 생기는 손실.
7. 작은 회사가 먼저 자동화해야 할 업무와 미뤄야 할 업무.
8. 툴을 샀는데 직원들이 안 쓰는 이유.
9. 자동화 구축 후에도 리테이너가 필요한 이유.
10. 좋은 AI 자동화 제안서와 나쁜 제안서의 차이.

## 외부 레퍼런스 활용

- [[AX Reference Library]]는 AX 전환 HowZero의 외부 유튜브/크리에이터 레퍼런스 저장소다.
- [[Nate Herk Reference]]는 `AI 자동화 툴 출시 → 실습형 콘텐츠 → 무료 커뮤니티 → 유료 멤버십/구축` 퍼널의 대표 사례로 본다.
- 다만 Nate Herk식 Claude Code 중심 제목을 그대로 쓰면 비개발자 대표보다 AI 빌더가 모인다. HowZero는 툴명을 앞세우기보다 대표의 리드, 리포트, 콘텐츠, 제안서, 팔로업 업무로 번역한다.
