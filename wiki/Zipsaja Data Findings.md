# Zipsaja Data Findings

> 집사자(zipsaja) 콘텐츠가 서울 실거래에서 반복 확인한 인사이트와 data.json schema 누적. 새 데이터 번들을 만들면 여기에 갱신한다. 진입점은 [[Zipsaja Index]]. 콘텐츠 활용은 [[Zipsaja Content Playbook]].

## 1. 데이터 소스 / 방법론

- **공통 소스**: 국토부 실거래가(서울 아파트 매매). 대부분 "300세대 이상 단지" 필터. 내부 `proptech_db`(`real_prices` × `complexes` × `pyeongs`) ingest.
- **수집**: SSH `hh-worker-2` → `proptech_db`. `/zipsaja-data-fetch` 스킬이 25개 구 dataset 생성.

**data.json schema 3변형 (공존)**
- **(A) 기본 25개 구 비교형** — `districts[].{district, priceBefore, priceAfter, changePct}`. 가격 단위 만원(예: `327644` = 32.76억). `periodLabel: 2025.01~12 평균 vs 2026.01~현재 평균`.
- **(B) 같은 단지·평형 매칭형** — (A) + `changeAmountWon/Display`, `matchedTypes`, `baseTrades/recentTrades`, `seoulSummary`, `rankedDistricts`, `bottomDistricts`, `summaryStats`(매칭 N, 중위/평균, 거래량 YoY), 정치 원인 단정 회피용 `methodNote`.
- **(C) 커스텀형** — 전세: `periods.before/after.{deals,avgEok,medianEok}` + `districts[].{priceBeforeEok, priceAfterEok, n2025, n2026, diffEok}`. 노도강 시뮬: `assumptions.{cashEok,ltvPct,loanCapEok}` + `districts[].{loan2025,cashNeeded2025,shortage2025,...}`.

## 3. 반복 확인되는 거시 인사이트

1. **강남 둔화 / 동북·동남권 급등 역전 구조** — 강남 -2.5%·서초 -0.4%인데 용산 +18.5%·광진 +17.9%. 동일단지 매칭(B)에서도 강남 +5.2%·용산 +6.6%로 하위권, 성동·동작·광진이 +20%대 상위. 고가 상위 2~3개 구만 정체, 중·저가 외곽이 더 빠르게 오름.
2. **대출 규제에도 가격은 상승** — 2026.4.1 가계부채 관리방안(스트레스 DSR 2단계, 9억 초과·다주택 제한) 이후에도 서울 평균 +5.3%, 핵심 구 +12~18%. 수요를 중가 지역으로 이동시킴("규제 프리미엄" 가설).
3. **하락장은 통계 착시, 첫집러 체감은 상승장** — 전체 중위 -15.6%·거래량 -18.2%처럼 보이지만, 같은 단지·평형 매칭하면 +22.9%. 싼 거래 구성 증가로 인한 구성효과(composition) 착시. **방법론적으로 가장 강한 발견.**
4. **첫집 현금격차 확대** — 가격 상승분이 곧 필요 현금 증가로 직결. 용산 1년 +5억, 노도강 시뮬 부족 현금 1.24→1.65억. 대출 한도(6억)는 고정인데 가격이 오르니 후보지가 하나씩 지워짐.
5. **매수 막히니 전세로, 전세도 오름 (출구 봉쇄)** — 24평급 전세 중위 +10%(+5천), 24개 구 전부 상승. 매수(대출 제한)·전세(보증금 상승) 양쪽 동시 봉쇄. 만기폭탄 번들의 "다주택 만기제한 → 전세 축소 → 월세 전환 압박" 가설과 연결.
6. **거래량 감소 ≠ 가격 하락** — 매매·전세 모두 거래량 줄었으나 동일물건 가격은 오름. 거래절벽 속 상승.

## 4. 데이터 검증 / 방법론 노트

- **착시 방어 설계가 핵심 신뢰성 장치**: `이재명-취임이후` 의 `methodNote`("정치적 원인 단정이 아니라 2025-06-04 이후 기간 기준 실거래 변화 비교")와 `집값-내려갔다고` 번들의 "동일 단지·평형 매칭"이 가장 명시적인 방법론 통제. 전체 평균/중위의 구성효과 착시를 매칭 표본(2,979 / 3,436)으로 교정.
- **표본 투명성**: B/C schema는 `baseTrades`, `recentTrades`, `matchedTypes`, `n2025/n2026`, `deals`를 구별로 노출 → 표본 검증 가능. 일부 구는 표본이 작음(종로 24, 용산 36, 중구 32) → 작은 N 구의 변동률은 해석 주의.
- **시뮬 번들 가정 명시**: 노도강 번들은 `assumptions`로 LTV 70%·대출 6억한도·취득세/중개비 제외·"실제 한도는 DSR·소득·심사 따라 변동"을 데이터에 박아둠(단정 회피).
- **데이터 재사용 한계 (중요)**: (A) 25개 구 dataset(강남 -2.5% … 용산 +18.5%)이 **5개 번들에서 동일 복사·재사용**됨(`강남빼고`, `강남은빠지고`, `용산광진`, `대출은막혔는데`, `만기폭탄`). 같은 컷을 다른 훅으로 재포장한 것이므로 **독립 데이터 포인트로 세지 말 것**.
- **실질 독립 dataset은 5종**: ① (A) 2025평균 vs 2026현재, ② 취임 90일 매칭, ③ 같은집 YoY 매매/전세, ④ 24평급 전세 B1, ⑤ 노도강 시뮬.
- **E2E 검증 기록 위치**: `이재명-대통령-당선후-서울-실거래-E2E-검증` 번들은 빈 폴더지만 누락이 아니다 — 파이프라인 **E2E 스모크 테스트**의 출력 경로이고 출력물은 gitignore된다. 검증 절차·합격 기준 기록은 `docs/superpowers/plans/2026-04-24-pipeline-full-orchestration.md` Task 14("E2E integration smoke test")에 있다. 데이터 신뢰성 통제 자체는 위 methodNote·동일단지 매칭 설계로 담보.
