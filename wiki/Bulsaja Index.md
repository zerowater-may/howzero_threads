# Bulsaja Index

## 역할

불사자 Index는 하우제로 커머스 콘텐츠가 불사자 기능을 대본, 쇼츠, 강의자료, CTA로 바꿀 때 쓰는 제품 브레인이다.

원문 기능표를 그대로 요약하는 문서가 아니다. 불사자의 기능을 셀러의 고통, 이론, 매출/성과 증거, 자동화 데모, CTA로 바꾸는 변환 지도다.

## 한 줄 포지셔닝

불사자는 해외구매대행과 오픈마켓 셀러가 매일 반복하는 상품 찾기, 키워드 분석, 이미지 번역, 상품명 생성, 등록, 분석 작업을 AI와 데이터로 줄여주는 올인원 셀러 솔루션이다.

하우제로 커머스 말투로 줄이면:

```txt
대표님이 손으로 하던 상품등록 노가다를
데이터와 AI로 줄여주는 셀러용 작업대입니다.
```

## 대본 기본 구조

불사자 연결형 하우제로 커머스 대본은 기본적으로 이 흐름을 따른다.

```txt
1. 셀러 고통
2. 이론
3. 매출/성과 증거
4. 수동으로 하면 오래 걸리는 이유
5. 불사자로 자동화되는 지점
6. 리스크/검수 기준
7. CTA
```

사용자가 “이 자료로 대본 써줘”라고 하면 아래 공식으로 바꾼다.

| 단계 | 역할 | 예시 |
|---|---|---|
| 셀러 고통 | 대표님이 이미 겪는 문제로 시작 | 상품 100개 올렸는데 왜 안 팔릴까 |
| 이론 | 왜 이 문제가 생기는지 구조 설명 | 검색량만 보면 안 되고 상품수/경쟁도/카테고리를 봐야 함 |
| 매출/성과 증거 | 팔린 흔적, 유입수, 리뷰, 순이익, 작업시간으로 증명 | 국내 판매 흔적, 리뷰 빈도, 유입수, 광고비 포함 순이익 |
| 수동 병목 | 사람이 직접 하면 왜 오래 걸리는지 보여줌 | 타오바오 검색, 이미지 번역, 상품명 작성, 마켓별 등록 |
| 불사자 자동화 | 어떤 기능이 그 병목을 줄이는지 연결 | 불사소싱기, AI 상품명, 이미지 번역, 멀티마켓 업로드 |
| 리스크 가드 | 과장/오남용 방지 | 금지어, 브랜드, KC, 정품, 검수 필요 |
| CTA | 무료 체험/확장프로그램/체크리스트 | 영상 끝 무료 사용 방법, 고정댓글 링크 |

## 핵심 메시지

| 메시지 | 하우제로식 변환 |
|---|---|
| 상품소싱부터 번역, 등록, 분석까지 한 번에 | 상품 하나 올리려고 왔다 갔다 하는 시간을 줄입니다 |
| 4,700만+ 상품 데이터 | 감이 아니라 들어갈 만한 후보를 데이터로 좁힙니다 |
| 중국어 이미지 번역 | 포토샵 못해도 중국어 이미지를 한국 판매 이미지로 바꿉니다 |
| 네이버/쿠팡 키워드 기반 상품명 | 상품명은 감으로 쓰지 말고 검색되는 구조로 만듭니다 |
| 4대 마켓 업로드 | 마켓마다 따로 들어가는 반복 등록을 줄입니다 |
| 유입수/정산/광고 분석 | 매출 말고 실제 반응과 남는 돈을 봅니다 |

## 기능 축

### 1. 소싱/키워드

포함 기능:

- 카테고리 소싱
- AI 키워드 소싱
- AI 키워드 분석
- 광고 키워드 분석
- 저장한 키워드/키워드 폴더
- 불사소싱기

셀러 고통:

```txt
뭘 팔아야 할지 모르겠고,
타오바오를 하루 종일 뒤져도 확신이 없습니다.
```

이론:

```txt
검색량만 높은 키워드가 좋은 키워드가 아닙니다.
상품수, 경쟁도, 판매 흔적, 브랜드 리스크를 같이 봐야 합니다.
```

성과 증거:

- 국내 마켓에서 팔린 흔적이 있는 상품.
- 상품수/경쟁도/월별 변화.
- 네이버/쿠팡 키워드 비교.
- 저장 키워드의 재사용성.

자동화 연결:

- 불사소싱기로 국내 판매 흔적 기반 후보 수집.
- AI 키워드 소싱으로 키워드 묶음과 경쟁도 확인.
- 광고 키워드 분석으로 테스트 후보 확장.

콘텐츠 주제:

- 타오바오 직접 뒤지지 마세요. 국내에서 팔린 상품부터 역으로 찾습니다.
- 검색량만 보면 망합니다. 상품수까지 봐야 하는 이유.
- 상품수 1만 개 이하 키워드만 보면 생기는 일.

### 2. 상품명/상품등록 SEO

포함 기능:

- AI 상품명 생성기
- 스마트스토어/쿠팡 상품명 분리
- 스마트스토어 태그/쿠팡 태그 생성
- 중복 단어/특수문자 제거
- 카테고리 기반 제한 정보
- 크롬 확장 프로그램의 네이버/쿠팡 데이터 수집

셀러 고통:

```txt
상품은 올리는데 네이버가 내 상품을 못 알아봅니다.
상품명은 길고, 태그는 감이고, 카테고리는 대충입니다.
```

이론:

```txt
상품명은 예쁜 문장이 아니라 검색되는 문장입니다.
마켓마다 상품명과 태그 구조가 다릅니다.
```

성과 증거:

- 상품명 수정 전후 순위/유입수 변화.
- 상위상품명과 연관 키워드 비교.
- 스마트스토어 50자, 공통 100자 등 길이 기준.

자동화 연결:

- AI 상품명 생성기로 마켓별 상품명 제안.
- 태그 자동 채우기.
- 나만의 AI 레시피로 카테고리별 반복 적용.

콘텐츠 주제:

- 상품명 짓는 데 10분 쓰지 않는 법.
- 스마트스토어와 쿠팡 상품명은 왜 다르게 써야 할까.
- 상품명 하나 잘못 쓰면 100개 올려도 안 팔립니다.

### 3. 이미지/상세페이지

포함 기능:

- AI 이미지 번역
- AI 이미지 만들기/이미지 편집
- 배경 제거
- AI 상세페이지
- 상세페이지 블록, HTML 미리보기, PNG/JPEG 저장

셀러 고통:

```txt
중국어 이미지 때문에 등록이 막히고,
상세페이지는 외주 맡기기엔 비싸고 직접 만들기엔 오래 걸립니다.
```

이론:

```txt
이미지는 클릭과 신뢰를 만들고,
상세페이지는 구매 판단 순서를 만들어야 합니다.
```

성과 증거:

- 중국어 이미지 → 한국어 판매 이미지 전후.
- 썸네일 클릭률/상품 유입수 변화.
- 상세페이지 섹션 구조 전후.

자동화 연결:

- 썸네일/옵션/상세 이미지 번역.
- AI 상세페이지 기획 초안 → 검토 → 승인 → 이미지 저장.
- 실패한 AI 이미지 크레딧 미차감 정책은 안전한 표현으로만 언급.

콘텐츠 주제:

- 중국어 상세페이지를 한국어로 바꾸는 전 과정.
- 포토샵 없이 이미지 번역하는 방법.
- 상품 이미지만 넣고 상세페이지 초안 받는 법.

### 4. 멀티마켓 등록/상품관리

포함 기능:

- URL/엑셀 수집
- 수집/등록 상품관리
- 신규 업로드/수정 업로드
- 스마트스토어, 쿠팡, 11번가, ESM 업로드
- 마켓 그룹/업로드 설정
- 상품명/마진율/배송비 일괄 변경
- 상품 잠금

셀러 고통:

```txt
상품이 10개일 때는 손으로 되지만,
100개부터는 등록보다 관리가 무너집니다.
```

이론:

```txt
상품 수가 늘면 중요한 건 많이 올리는 게 아니라
상태, 가격, 배송비, 업로드 현황을 관리하는 구조입니다.
```

성과 증거:

- 상품 100개 관리 필터.
- 업로드 성공/실패 상태.
- 수정 업로드 전후.
- 마진율 변경 시 판매가 자동 재계산.

자동화 연결:

- 상품관리 필터로 검토 완료, 번역 현황, 업로드 상태 정리.
- 멀티마켓 업로드로 반복 등록 축소.
- 마켓 그룹으로 사업자/계정/상품군 분리.

콘텐츠 주제:

- 상품 100개 관리할 때 꼭 써야 하는 필터 7가지.
- 쿠팡, 스마트스토어, 11번가, G마켓/옥션 동시 등록하기.
- 잘 팔리는 상품은 잠금 처리해야 하는 이유.

### 5. 리뷰/상품기획

포함 기능:

- 쿠팡 리뷰 분석
- AI 상품기획 마술사
- 리뷰 긍정/부정 분석
- 옵션 구매 비중
- 리뷰 빈도 기반 판매 속도 추정

셀러 고통:

```txt
리뷰가 없어서 안 팔린다고 생각하지만,
사실 경쟁 상품 리뷰를 읽으면 고객이 원하는 게 보입니다.
```

이론:

```txt
리뷰는 고객이 남긴 무료 시장조사입니다.
긍정 리뷰는 강조 포인트, 부정 리뷰는 차별화 포인트입니다.
```

성과 증거:

- 리뷰 개수/작성 빈도.
- 옵션 구매 비중.
- 고객 불만 리스트.
- 상세페이지 문구/옵션 구성 개선.

자동화 연결:

- 쿠팡 리뷰 분석으로 경쟁 상품 고객 반응 확인.
- AI 상품기획 마술사로 리뷰를 상품기획서로 변환.

콘텐츠 주제:

- 스마트스토어 리뷰 없으면 안 팔릴까? 초보 셀러가 먼저 해야 할 것.
- 리뷰 1,000개를 직접 읽지 않는 방법.
- 고객 불만 5개로 상세페이지 차별화하기.

### 6. 운영/성과/광고

포함 기능:

- 유입수 분석
- 쿠팡 원가 입력
- 로켓그로스 성과 분석
- 쿠팡 캠페인 분석
- 상품 순위 추적

셀러 고통:

```txt
매출은 나오는데 남는 돈이 없고,
상품을 많이 올렸는데 어떤 상품이 반응하는지 모릅니다.
```

이론:

```txt
매출보다 중요한 건 유입, 전환, 광고비, 원가, 순이익입니다.
노출 개선은 느낌이 아니라 순위 변화로 확인해야 합니다.
```

성과 증거:

- 유입수 없는 상품.
- 광고비 포함 순이익.
- 원가/정산/배송비/추가비용.
- 키워드별 순위 변화.

자동화 연결:

- 유입수 분석으로 저효율 상품 정리.
- 로켓그로스 분석으로 실제 남는 돈 확인.
- 캠페인 분석으로 광고비 새는 상품 확인.
- 순위 추적으로 상품명/가격/광고 수정 효과 확인.

콘텐츠 주제:

- 쿠팡 매출이 높아도 돈이 안 남는 이유.
- 상품 1,000개 올린 뒤 꼭 봐야 할 지표.
- 상품명 바꾼 뒤 순위가 올랐는지 확인하는 법.

### 7. 리스크/검수/운영 기준

포함 기능:

- 제외/금지어 관리
- 수집 설정
- 금지단어, 제외단어, 치환단어
- 미끼상품 자동 제외
- 대표 옵션 선정 기준
- AI 설정/프롬프트/워크플로우

셀러 고통:

```txt
많이 올릴수록 브랜드, 금지어, 미끼상품, 옵션 오류가 사고로 이어집니다.
```

이론:

```txt
자동화는 많이 올리는 버튼이 아니라
위험한 단어와 틀린 기준을 먼저 걸러내는 안전장치여야 합니다.
```

성과 증거:

- 업로드 전 금지어 필터.
- 미끼 옵션 제거.
- 평균가/중간값/재고 최다 옵션 기준 비교.
- 프롬프트/워크플로우로 검수 기준 통일.

자동화 연결:

- 금지어/치환어/제외 카테고리 관리.
- 수집 설정으로 대표 옵션 기준 선택.
- AI 프롬프트 저장으로 반복 기준 통일.

콘텐츠 주제:

- 구매대행 셀러가 꼭 등록해야 하는 금지어 목록.
- 타오바오 최저가 미끼상품에 속지 않는 설정.
- AI도 기준이 있어야 잘 일합니다.

### 8. 조직/교육/제휴

포함 기능:

- 조직/직원 권한
- 화이트라벨/제휴 브랜드
- 마켓 그룹
- 소싱 워크플로우
- 플랜/AI 크레딧

셀러 고통:

```txt
팀원, 직원, 외주, 수강생이 같은 기준으로 일하지 않습니다.
```

이론:

```txt
반복 가능한 운영은 도구 안에 기준을 넣는 것에서 시작합니다.
```

성과 증거:

- 그룹별 상품 수.
- 권한별 기능 노출.
- 프롬프트/금지어/워크플로우 공유.

자동화 연결:

- 마켓 그룹, 조직 권한, 브랜드 모드, 제휴 플랜.

콘텐츠 주제:

- 강사와 대행사를 위한 불사자 화이트라벨.
- 수강생에게 같은 소싱 기준을 제공하는 방법.

## 매출/성과 증거를 쓰는 방식

불사자 콘텐츠에서 "매출 증명"은 과장하면 안 된다. 아래처럼 표현한다.

| 쓰면 좋은 증거 | 안전한 표현 |
|---|---|
| 국내 판매 흔적 | 팔린 흔적이 있는 상품부터 후보를 좁힌다 |
| 리뷰 빈도 | 리뷰 작성 빈도로 판매 속도를 가늠한다 |
| 유입수 | 조회수 없는 상품을 계속 붙잡지 않는다 |
| 순이익 | 매출 말고 광고비/원가 포함 남는 돈을 본다 |
| 순위 변화 | 상품명 수정 후 순위 변화를 확인한다 |
| 작업시간 | 수동 반복 작업 시간을 줄인다 |

금지 표현:

- 무조건 매출 상승.
- 100% 자동 수익.
- 클릭 한 번으로 월 1,000만원.
- 상위노출 보장.
- 마켓 페널티 0%.

## CTA 원칙

불사자는 제목 전면보다 후반부 해결책으로 등장시키는 것이 기본이다.

CTA 예시:

```txt
영상 끝까지 보시면 이 과정을 불사자에서 무료로 써볼 수 있는 방법까지 알려드리겠습니다.
```

```txt
고정 댓글에 오늘 체크리스트와 불사자 무료 체험 링크 남겨두겠습니다.
```

```txt
직접 손으로 해보신 뒤, 반복되는 부분은 불사자에서 줄여보세요.
```
