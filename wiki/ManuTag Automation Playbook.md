# ManuTag Automation Playbook

## 한 줄 컨셉

스마트스토어 태그 10칸은 감으로 찍는 칸이 아니라 노출 적합도에 들어가는 데이터 필드다.

## 핵심 주장

- 태그는 네이버 쇼핑 검색 적합도에 영향을 주는 요소다.
- 태그를 비우면 적합도에서 손해를 본다.
- 태그사전에 등록된 단어만 검색에 적용된다.
- 무관한 태그를 반복하거나 복붙하면 어뷰징이 된다.
- 올바른 사용법은 “상위 상품 태그 복붙”이 아니라 “내 상품에 사실인 태그만 찾기”다.
- 태그만 고치면 끝나는 것이 아니라 상품명, 스토어명, 카테고리, 속성, 리뷰, 클릭, 판매, 연관도와 함께 봐야 한다.

## S-002 메시지

```txt
대표님, 스마트스토어 태그 아직도 감으로 찍고 계시죠?
마누태그는 노출 적합도에 직접 들어가는 필드입니다.
상위노출 상품이 실제로 쓴 태그를 데이터로 보고,
내 상품에 사실인 것만 10칸에 채우세요.
```

## S-002 v4 보강 프레임

```txt
상품명은 마법이 아닙니다.
스토어명도 마법이 아닙니다.
태그 10칸도 마법이 아닙니다.

네이버는 상품명, 스토어명, 카테고리, 속성, 태그,
클릭, 판매, 리뷰, 가격, 연관도를 같이 봅니다.

마누태그는 상위노출 보장 버튼이 아니라,
내 상품에 빠진 상품정보 후보를 찾는 도구입니다.
```

레퍼런스의 위험한 인기도 작업/비공개 점수 단정은 쓰지 않는다. 대본에서는 "상품정보와 사용자 반응이 함께 쌓인다" 정도로 안전하게 말한다.

## S-002 v5 중국구매대행 보강 프레임

```txt
중국구매대행 상품은 키워드보다 사실 확인이 먼저다.
타오바오에서 가져온 상품은 KC, 어린이제품, 전기용품,
브랜드/정품, 통관/관부가세, 해외배송 정보가 섞이기 쉽다.

마누태그는 상위 상품 태그를 베끼는 도구가 아니라,
내 상품에 사실인 상품정보 후보를 찾는 도구다.
```

일반 예시인 사과, 닭갈비, 들기름, 닌텐도, 텀블러 대신 중국구매대행 예시를 쓴다: 타오바오 접이식 캠핑의자, 무타공 욕실 선반, 충전식 LED 무드등, 브랜드 로고 휴대폰 케이스, 여행용 압축 파우치.

## S-002 v6 스마트스토어 상품명 구조 프레임

```txt
상품 100개 올렸는데 왜 안 팔릴까?
스마트스토어에서 상품명은 제일 중요하다.
다만 상품명은 키워드 나열이 아니라 구조로 설계해야 한다.

매출 부진 원인 진단 → 백화점 비유 → 수동 상품명 설계 → 같은 상품 A/B 비교 → 확장프로그램 반자동화
순서로 보여준다.
```

훅은 "상품을 많이 올렸는데 왜 매출이 안 나는가"에서 시작한다. 타겟은 지금까지 상품등록을 아무렇게나 하고 매출이 나길 기다렸던 초보 스마트스토어 셀러다. 이후 네이버쇼핑을 백화점으로 비유한다.

| 비유 | 스마트스토어 요소 |
|---|---|
| 백화점 층/코너 | 카테고리 |
| 매대 설명표 | 상품속성 |
| 보조 표지판 | 태그 |
| 판매처/제조 정보 | 브랜드/제조사 |
| 큰 간판 | 상품명 |

상품명은 가장 강한 신호다. 다만 상품명은 검색 인식영역(카테고리, 상품속성, 태그, 브랜드/제조사)과 같은 방향으로 맞아야 한다.

이후 `무타공 욕실 코너선반` 같은 상품을 두 버전으로 비교한다.

| 구분 | SEO 없이 반자동 등록 | SEO 맞춘 반자동 등록 |
|---|---|---|
| 상품명 | 중국직구 욕실선반 해외배송 인테리어 수납 정리 선반 가성비 | 무타공 욕실 코너선반 접착식 샤워실 수납 선반 |
| 태그 | 중국직구, 해외배송, 생활용품, 인테리어, 수납, 정리, 가성비 | 무타공, 욕실선반, 코너선반, 접착식선반, 샤워실선반, 욕실수납 |
| 문제/강점 | 넓고 흐린 신호 | 검색어, 카테고리, 속성, 태그가 한 방향 |

마지막 CTA는 "완전 자동 대량등록"이 아니라 "불사자 확장프로그램으로 반복 작업을 줄이고, 대표님이 최종 판단한다"로 잡는다. 국내위탁, 사입, 해외구매대행 모두 같은 구조를 적용할 수 있다고 설명한다.

불사자 자체의 페르소나는 [[Bulsaja Commerce Copilot]]을 따른다.

### v6 menuTag 추가 프레임

- 상품명 키워드 전에 검색 인식영역을 설명한다: 카테고리, 상품속성, 태그, 브랜드/제조사.
- 태그는 입력했다고 전부 검색 반영되는 것이 아니다.
- 태그사전에서 숫자가 뜨는 태그를 선택해야 하며, 직접 입력/엔터 입력 태그는 검색 반영을 기대하지 않는다.
- 태그사전 등록 태그라도 실제 검색 신호로 잡히는 태그와 아닌 태그가 갈릴 수 있으므로 `menuTag` 개념을 설명한다.
- 가격비교 상품은 태그가 제 역할을 못 하는 경우가 많으므로 단일 상품 중심으로 확인한다.
- 상품명은 태그보다 훨씬 강한 신호다. 메인 키워드는 상품명에 넣고, 태그는 서브 키워드로 뺀다.
- 불사자는 상위 단일 상품의 태그와 `menuTag` 후보를 정리해, 상품명에 넣을 키워드와 태그로 뺄 키워드를 나누게 도와주는 흐름으로 설명한다.

## 안전한 4단계 워크플로우

1. 상위 상품 마누태그 빈도 추출.
2. 내 상품에 사실인 것만 체크.
3. 태그사전 등록 여부 확인.
4. 빈도와 정확도 기준으로 10칸 채우기.

## 어뷰징 경계선

기준은 한 줄이다.

```txt
내 상품에 사실이냐, 아니냐.
```

무관한 브랜드, 제조사, 기능, 카테고리 키워드를 넣으면 노출을 늘리는 게 아니라 계정 리스크를 만든다. 대본에서는 “노출 늘리려다 매출을 0으로 만들지 마세요” 식으로 보호자 톤을 쓴다.

## 웹 보강 근거

- 네이버 쇼핑파트너 공식블로그는 상품명에서 중복 단어, 상품과 관련 없는 키워드, 할인 정보 등을 제외하고 간결하게 작성하라고 안내하며, 제품 속성, 태그, 바코드, 모델 코드 등 검색 가능한 다양한 정보를 제공하라고 설명한다.
- 네이버 쇼핑검색 SEO & 상품정보 제공 가이드는 검색결과가 판매자가 제공한 상품 정보와 네이버의 사용자 로그를 종합 평가해 구성된다고 설명하고, 상품정보 어뷰징에 대한 상품/몰 단위 페널티를 언급한다.
- 네이버 광고주센터 상품명 가이드는 광고대상 상품과 충분히 관련 있어야 하며, 상품 속성과 무관한 내용이나 동일/유사 문구 반복은 제한될 수 있다고 안내한다.

웹서칭 기준으로는 “태그사전” 자체의 최신 공식 공개 문서를 확인하지 못했다. 그래서 대본에서는 “상품 등록 화면에서 검색 적용되는 태그인지 확인”처럼 과하게 단정하지 않는 표현을 쓴다.

## S-003 자동화 각색

민군 영상은 마누태그를 엑셀로 추출해 빈도순으로 정리하는 12단계 수동 워크플로우다. 하우제로의 보충 포인트는 이 12단계를 비판하는 게 아니라 그대로 자동화했다는 점이다.

```txt
민군님 12단계
→ 같은 순서를 크롬 확장프로그램에 옮김
→ 같은 결과, 1초
→ 어뷰징 경계선과 태그사전 확인까지 보강
```

## 민군 레퍼런스 대응 가드

- 민군님은 동료 코치다.
- “빠뜨린 것”보다 “한 가지 더 보태겠다”로 말한다.
- 직접 화면 캡처보다 다이어그램 재구성을 우선한다.
- 영상 링크는 고정 댓글/설명란에 명시한다.
