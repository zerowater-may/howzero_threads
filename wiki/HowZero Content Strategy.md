# HowZero Content Strategy

## 역할

이 페이지는 하우제로 전체 콘텐츠 라우터다. 새 대본, 레퍼런스, 랜딩, 카러셀을 만들기 전에 먼저 AX 전환 콘텐츠인지 커머스 콘텐츠인지 고른다.

## 브레인 선택

| 질문 | 이동할 페이지 |
|---|---|
| 기업의 마케팅 병목, 리드 누수, AX 오딧, B2B 제안서인가? | [[HowZero AX Content Strategy]] |
| 스마트스토어/쿠팡/구매대행 셀러의 상품 등록, 상세페이지, 태그, 플랫폼 리스크인가? | [[HowZero Commerce Brain]], [[Commerce Script Rules]] |
| 외부 유튜브 레퍼런스를 커머스 대본으로 바꾸는가? | [[YouTube Reference Library]], [[YouTube Reference Analysis Template]] |
| 콘텐츠 생성/게시 파이프라인 자체를 다루는가? | [[HowZero Content Pipeline]] |

## 공통 콘텐츠 원칙

- 실전 사례를 먼저 보여준다.
- 훅은 숫자, 반전, 비용 절감, 시간 절감으로 시작한다.
- “AI가 신기하다”가 아니라 “업무가 줄었다”를 보여준다.
- CTA는 브레인별로 하나만 둔다.

## CTA 분리

| 브레인 | 기본 CTA | 보조 CTA |
|---|---|---|
| AX 전환 | 30분 무료 마케팅 AX 오딧 | 자동화 사례 보기 |
| Commerce | 불사자/마누태그/상세페이지 자동화 | 자료, 템플릿, 영상 댓글 유도 |

## 권위 분리

| 브레인 | 권위 문장 |
|---|---|
| AX 전환 | GPT-3 기반 SaaS와 연매출 10억 실전 경험 |
| Commerce | 셀러 1년 차 월 1억 구조와 셀러 노가다 자동화 경험 |

권위 문장을 섞으면 채널 정체성이 흐려진다. AX 영상에서 커머스 권위를 쓰거나, 커머스 영상에서 SaaS 10억을 반복하지 않는다.

## 채널 공통 역할

| 채널 | 공통 역할 | AX 적용 | Commerce 적용 |
|---|---|---|---|
| 유튜브 | 깊은 신뢰, 검색 유입 | 오딧/구축 과정 | 상세페이지/태그 자동화 롱폼 |
| 인스타그램 | 저장, 공유 | 병목 체크리스트 | 셀러 노가다 체크리스트 |
| 틱톡 | 발견과 바이럴 | 짧은 자동화 데모 | 1분 업무 단축 시연 |
| 쓰레드 | 관계와 대화 | 오딧 모집, 운영 관찰 | 셀러 공감, 레퍼런스 테스트 |

## 작업 전 확인 질문

1. 이 콘텐츠의 시청자는 기업/마케팅팀인가, 셀러인가?
2. CTA는 무료 마케팅 AX 오딧인가, 커머스 자동화 상품인가?
3. 권위 문장은 AX용인가, 커머스용인가?
4. 금지 표현이 서로 섞이지 않았는가?

이 네 가지가 불명확하면 대본을 쓰기 전에 [[HowZero Open Questions]]에 남긴다.
