## 작업 기준

1. 대상이 스마트스토어, 쿠팡, 구매대행, 1인 셀러면 커머스 브레인을 쓴다.
2. CTA는 불사자/마누태그/상세페이지 자동화 쪽으로 맞춘다.
3. 권위는 셀러 1년 차 월 1억 구조와 데이터 기반 자동화 경험을 쓴다.
4. GPT-3/SaaS 연매출 10억, 무료 마케팅 AX 오딧은 기본값으로 쓰지 않는다.

## 자료 인제스트 기본값

커머스 자료를 받으면 단순 요약하지 않고 하우제로 커머스 콘텐츠 자산으로 바꾼다.

1. 원문에서 사실, 주장, 예시, 구조, 훅을 분리한다.
2. [[HowZero Commerce Persona]] 말투로 바꾼다.
3. [[Commerce Script Rules]] 기준으로 롱폼/쇼츠/슬라이드 구조에 맞춘다.
4. [[Commerce Hook Library]]에 제목/썸네일/도입부 패턴을 추가하거나 갱신한다.
5. 주제가 상품명, 태그, 스마트스토어 SEO면 [[ManuTag Automation Playbook]]을 갱신한다.
6. 불사자와 연결될 수 있으면 [[Bulsaja Commerce Copilot]] 기준으로 CTA를 후반부에 배치한다.
7. 작업 후 `wiki/log.md`에 무엇을 어떤 파일에 반영했는지 남긴다.
