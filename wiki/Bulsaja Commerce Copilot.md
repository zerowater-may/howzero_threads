# Bulsaja Commerce Copilot

## 정의

불사자는 해외구매대행과 오픈마켓 셀러가 매일 반복하는 상품 찾기, 키워드 분석, 이미지 번역, 상품명 생성, 등록, 분석 작업을 AI와 데이터로 줄여주는 올인원 셀러 솔루션이다.

불사자의 포지션은 "상품을 아무렇게나 많이 올리는 자동등록기"가 아니다. 셀러가 손으로 하던 소싱, 번역, 상품명, 태그, 등록, 성과 분석의 반복 작업을 줄이고, 대표님이 판단해야 할 후보와 지표를 정리해주는 커머스 코파일럿이다.

제품 전체 브레인은 [[Bulsaja Index]]를 따른다.

## 한 문장 포지셔닝

상품소싱부터 번역, 상품명, 등록, 분석까지 셀러 반복 작업을 한 흐름으로 줄여주는 AI 셀러 작업대.

## 해결하는 문제

| 셀러 작업 | 기존 방식 | 불사자 역할 |
|---|---|---|
| 상품소싱 | 타오바오/국내마켓을 직접 뒤짐 | 국내 판매 흔적과 키워드 데이터 기반 후보 수집 |
| 상품명 작성 | 타오바오 제목 번역 후 키워드 덧붙임 | 메인 키워드와 서브 키워드 분리 |
| 이미지 번역 | 포토샵/외주/수동 번역 | 썸네일, 옵션, 상세 이미지 번역 |
| 태그 10칸 | 감으로 입력하거나 상위 상품 복붙 | 상위 단일 상품 태그와 `menuTag` 후보 정리 |
| 카테고리/속성 | 대량등록 중 누락 또는 오입력 | 검색 인식영역 체크리스트화 |
| 멀티마켓 등록 | 마켓별 관리자에서 반복 입력 | 스마트스토어, 쿠팡, 11번가, ESM 업로드 연결 |
| 성과 분석 | 매출만 보고 감으로 판단 | 유입수, 순위, 리뷰, 순이익, 광고비 지표 확인 |
| 리스크 키워드 | KC, 정품, 유아, 방수 등을 감으로 사용 | 확인 못 한 표현을 거르는 가드 |
| 반복 작업 | 엑셀, 개발자 모드, 복사/정렬 수작업 | 후보를 빠르게 모아 최종 판단만 남김 |

## 말하면 안 되는 포지션

- 완전 자동 대량등록기.
- 네이버 상위노출 보장 프로그램.
- AI가 알아서 팔리는 상품을 만들어주는 도구.
- 상품정보 어뷰징을 우회하는 프로그램.
- 클릭 한 번으로 매출을 보장하는 프로그램.

## 말해야 하는 포지션

- 셀러가 손으로 하던 SEO 가공을 줄인다.
- 네이버가 상품을 이해하게 만드는 상품정보 후보를 정리한다.
- 대표님이 판단해야 할 것만 남긴다.
- 많이 올리는 시대에서 제대로 올리는 시대로 넘어가는 도구다.
- 매출보다 유입수, 순이익, 리뷰, 순위 같은 확인 가능한 지표를 같이 보게 한다.

## 하우제로 대본 연결 공식

불사자 연결형 대본은 [[Bulsaja Index]]의 구조를 쓴다.

```txt
이론
→ 매출/성과 증거
→ 수동으로 하면 오래 걸리는 이유
→ 불사자로 자동화되는 지점
→ 리스크 가드
→ CTA
```

## S-002 제목 방향

불사자는 제목에 넣지 않는다. 아직 모르는 사람에게는 검색어가 아니라 브랜드 장벽이 된다. 제목은 `타오바오 구매대행`, `스마트스토어 상품명`, `SEO`, `대량등록`, `태그 10칸` 같은 검색어와 현재 불안을 먼저 잡는다.

불사자는 영상 후반 CTA, 고정댓글, 설명란에서 "이 과정을 줄이는 도구"로 등장시킨다.

좋은 제목 구조:

```txt
[셀러의 실제 통증] + [네이버쇼핑/스마트스토어] + [상품명 구조]
```

예:

```txt
왜 내 상품은 노출되지 않을까? 네이버쇼핑 상품명 구조가 다릅니다
```

현재 S-002는 구매대행만 전면에 놓지 않는다. 국내위탁, 사입, 해외구매대행 모두에 적용되는 스마트스토어 상품명 구조로 말하고, 불사자는 수동 상품명 설계 과정을 줄이는 확장프로그램으로 후반부에 연결한다.
