# YouTube Reference Library

## 역할

외부 유튜브 레퍼런스를 하우제로 커머스 대본으로 바꾸기 위한 분석 저장소다. 레퍼런스는 베끼는 대상이 아니라 구조, 훅, 흐름, 빈틈을 뽑아 하우제로식으로 재구성하는 입력이다.

## 민군 마누태그 레퍼런스 요약

- URL: `https://youtu.be/jade__mkn6s?si=Iq9cQNs-ze2sns7l`
- 방식: 화면 녹화 + 음성 해설.
- 핵심: 네이버 쇼핑 상위 상품의 manu태그를 엑셀로 뽑아 빈도순으로 정리.
- 강점: 직접 따라 할 수 있고, 단계가 명확하며, 셀러 친화적이다.
- 하우제로 보충: 12단계가 30분~1시간 노가다이므로 같은 결과를 1초 자동화로 보여준다. 어뷰징 경계선과 태그사전 확인을 추가한다.

## 상품명/스토어명/TEMS 레퍼런스 요약

- 입력: 사용자 제공 전사 텍스트.
- 핵심: 상품명 하나로 상위노출이 되는 것이 아니며, 상품명/스토어명/태그/상품정보/사용자 반응이 함께 작동한다.
- 스토어명 예시: `햇사과`, `국산 생들기름`처럼 단어가 하나의 완성형 키워드로 묶이면, 기대한 하위 키워드 신호가 약해질 수 있다는 설명.
- 랭킹 신호: 클릭, 판매, 리뷰, 최신성, 가격, 상품정보, 연관도 등이 함께 작동한다는 구조적 설명.
- 하우제로 보충: 비공개 점수 단정이나 인기도 작업 권유는 제외하고, "네이버를 속이지 말고 내 상품을 정확히 이해하게 만들자"는 안전한 상품정보 최적화 프레임으로 변환한다.

## 중국구매대행 보강 요약

- 입력: 사용자 요청과 웹 확인 자료.
- 핵심: 사과/닭갈비/들기름 같은 일반 예시가 아니라, 실제 중국구매대행 셀러가 다루는 타오바오 소싱 상품 예시를 써야 한다.
- 반영 예시: 접이식 캠핑의자, 무타공 욕실 선반, 충전식 LED 무드등, 브랜드 로고 휴대폰 케이스, 여행용 압축 파우치.
- 가드: KC, 정품, 어린이, 유아, 방수, 의료용, 관부가세, 해외배송 표현은 키워드가 아니라 사실 확인과 고객 안내 관점으로 다룬다.
- 톤 수정: "AI 툴 자랑 영상 아닙니다"처럼 진부한 방어 문장은 제거한다.

## 중국구매대행 SEO 반자동 등록 요약

- 입력: 사용자 피드백.
- 핵심: 셀러들은 상품 등록 한도 축소 이슈 때문에 불안하다. 이 불안을 첫 훅으로 잡고, "많이 올리는 시대"에서 "SEO 맞춰 제대로 올리는 시대"로 프레임을 바꾼다.
- 구조: 이론 설명 → 검색 인식영역 설명 → 같은 타오바오 상품의 SEO 미적용/적용 비교 → 태그사전/menuTag 설명 → 손으로 하면 오래 걸리는 이유 → 불사자 확장프로그램으로 반자동화.
- 예시: `무타공 욕실 코너선반`을 기준으로 상품명, 카테고리, 속성, 태그를 비교한다.
- 태그 레퍼런스 반영: 태그사전 숫자, 직접 입력 태그 미반영 가능성, 가격비교 상품의 태그 한계, 단일 상품의 `menuTag`, 상품명 키워드와 태그 키워드 분리를 추가한다.
- 금지: 사과, 닭갈비, 들기름 같은 비구매대행 예시. "AI 툴 자랑 영상 아닙니다" 같은 진부한 문장.


## 백만장자 앤더슨 쿠팡 3가지 리스크 요약

- URL: `https://youtu.be/ZYbKUUrbatI`
- 제목: `2026년 이 3가지 모른다면 절대 쿠팡 하지 마세요. 돈, 시간 버리고 결국 망하게 될겁니다.`
- 채널: 백만장자 앤더슨.
- 핵심: 쿠팡 초보가 손해 보는 3가지 — 미비한 시장 분석, 전략 없는 광고비 지출, 상품과 사랑에 빠지는 것.
- 제목/훅: `이 3가지 모르면 하지 마세요` 경고형 구조가 강하다. 손실, 시간, 실패 리스크가 첫 클릭 이유다.
- 좋은 점: “팔리는데 적자”, “손익분기점 ROAS”, “효자 상품 반복”처럼 초보 대표님이 실제로 겪는 문제를 건드린다.
- 하우제로 보충: 공포형 코칭 CTA보다 `수요/경쟁/리뷰/가격/리스크/손익분기점` 기준표를 먼저 보여준다. AI는 만능 도구가 아니라 대표님이 손으로 하던 소싱·상품명·광고 판단을 줄이는 작업대로 설명한다.
- 하우제로식 각색: `쿠팡에서 매출은 찍히는데 돈이 안 남는 이유, 이 3개부터 보세요` 또는 `2026년 쿠팡·스마트스토어, 이 3가지 모르고 AI 소싱하면 돈 버립니다` 방향. 불사자는 제목 전면이 아니라 후반 해결책과 고정댓글 CTA에 둔다.
- 금지 톤: 레퍼런스 제작자 비판, 월천/수익 보장, 노출·순위 보장, AI 독식 공포 과장, “시키는 대로만 하면 된다”류 표현.
- 산출물: `brands/howzero/howzero_script/S-004-commerce-coupang-3-loss-holes.md`, `brands/howzero/howzero_misc_coupang-3-loss-holes-playground/index.html`.

## 레퍼런스 인제스트 규칙

새 유튜브 링크를 받으면 [[YouTube Reference Analysis Template]]을 사용한다.

반드시 뽑을 것:

1. 영상의 한 줄 주제.
2. 타겟 시청자.
3. 제목/썸네일 훅.
4. 챕터 구조.
5. 시청자가 얻는 결과.
6. 좋은 점.
7. 빠진 점 또는 보충 각도.
8. 하우제로 커머스식 재해석.
9. 대본으로 바꿀 때의 금지 톤.
10. 관련 wiki 페이지 업데이트 대상.

## 레퍼런스 사용 원칙

- 구조를 가져오고 표현은 새로 쓴다.
- 화면 직접 캡처는 최소화하고 다이어그램 재구성을 우선한다.
- 레퍼런스 제작자를 비판하지 않는다.
- “이 영상이 틀렸다”보다 “이 영상에 한 가지 더 보태겠다”로 간다.
