# BraveYong Lecture Playbook

## 역할

이 페이지는 용감한 용팀장식 롱폼 강의, 쇼츠, 카러셀, 썸네일/제목, CTA를 만들 때 쓰는 실행 플레이북이다.

## 강의 기본 흐름

```txt
공감
-> 원인
-> 반전
-> 해결
-> 실전
-> CTA
```

초보 셀러는 해결책만 던지면 따라오지 못한다. 먼저 "내가 왜 안 됐는지"를 이해시킨 뒤 방법을 보여준다.

## 첫 3~5초 후킹

| 유형 | 쓰임 |
|---|---|
| 문제 제기형 | "상품 계속 올리는데 노출이 안 된다면 상품 문제가 아닐 수 있습니다." |
| 경고형 | "SEO 없이 등록량만 늘리면 시간만 더 빨리 날아갑니다." |
| 반전형 | "상세페이지가 안 팔리는 이유, 디자인 문제가 아닐 수 있습니다." |
| 리스트형 | "초보 셀러가 광고 전에 봐야 할 3가지입니다." |
| 비밀 공유형 | "상위노출이 막히는 세팅 실수, 여기서 많이 나옵니다." |

강한 감정어를 썼으면 바로 실패 장면을 붙인다. "큰일 납니다"에서 끝내지 말고, 검색창에 상품이 안 보이거나 PDF만 쌓이고 매출이 없는 장면까지 보여준다.

## 30~60초 도입부

1. 지금 멈춰야 하는 이유
2. 시청자가 겪는 문제
3. 흔한 방법이 약한 이유
4. 용팀장식 해결책의 한 문장 약속
5. 계속 봐야 하는 이유

## 본문 구조

| 단계 | 역할 |
|---|---|
| 문제 진단 | 시청자가 겪는 막힘을 구체화 |
| 기존 방식의 한계 | 많이 올리기, 감 키워드, 기획 없는 GPT 생성의 약점 설명 |
| 핵심 개념 | SEO, 상품명, 카테고리, 상세페이지 설득 흐름, AI 프로젝트 |
| 실전 적용 | 단계별로 화면 시연 또는 체크리스트 제공 |
| 사례/비교 | 일반 방식 vs 용팀장식 방식의 차이 |
| 실수 방지 | 지재권, 광고비 낭비, 잘못된 자동화, 과장된 수익 주장 방지 |
| CTA | 단톡방, 무료자료, 무료강의, 템플릿으로 연결 |

## 형식별 전략

| 형식 | 구조 |
|---|---|
| 정보형 | 고통/손해 후킹 -> 원인 분석 -> 단계별 해결책 -> 자료/강의 연결 |
| 비교형 | 흔한 방식 -> 한계 -> 용팀장식 대안 -> 결과 차이 |
| 튜토리얼형 | 결과물 먼저 보여주기 -> 준비물 -> 단계별 실행 -> 실수 방지 -> 템플릿 CTA |
| 경고형 | 멈춰야 할 행동 -> 위험 설명 -> 대안 -> 체크리스트 |
| 스토리형 | 손실/충격 -> 갈등 -> 발견 -> 방법론 -> 변화 |

## 썸네일/제목

썸네일과 제목은 클릭 약속이다. 도입부와 본문은 반드시 그 약속을 회수해야 한다.

| 요소 | 기준 |
|---|---|
| 썸네일 | 3~8자 내외, 경고/결과/반전/공개형 단어 |
| 제목 | 30~45자 내외, 검색 키워드와 클릭 후킹을 함께 포함 |
| 검색어 | 글로벌 위탁판매, 구매대행, 스마트스토어, 쿠팡 셀러, 네이버 SEO, 상세페이지, GPT 상세페이지 |
| 금지 | 자극적인 제목을 걸고 본문에서 구체 방법을 주지 않는 구성 |

## 롱폼 제작 순서

1. 주제 확인
2. 지식 자료 정리
3. 목표 분량 결정
4. 세그먼트 아웃라인 제안
5. 각 세그먼트별 글자 수 배분
6. 세그먼트별 순차 작성
7. CTA 삽입
8. 말하기 구조 재작성
9. 4인 검증 시스템으로 점검
10. 유튜브 본문/SEO 설명문 작성

## 분량 기준

| 목표 시간 | 목표 글자 수 |
|---|---:|
| 15분 | 약 3,500~4,500자 |
| 20분 | 약 5,000~6,000자 |
| 30분 | 약 7,000~9,000자 |
| 45분 | 약 11,000~13,000자 |
| 60분 | 약 15,000~18,000자 |

## 4인 검증

| 관점 | 질문 |
|---|---|
| 도파민 헌터 | 첫 1~2초에 멈출 이유가 있는가 |
| 타깃 시청자 | 광고 냄새가 나지 않고 내 문제처럼 느껴지는가 |
| 말투 검사관 | TTS로 읽었을 때 자연스럽고 한 호흡으로 끊기는가 |
| 성과 분석가 | CTR, 완주율, 저장률 관점에서 약한 구간이 있는가 |

## 유료 강의 커리큘럼 (오프라인 부트캠프)

용팀장의 첫 유료 오프라인 상품 `6주 오프라인 AI 셀링 실전반`의 커리큘럼·랜딩 구조·톤 가드는 [[BraveYong AI Selling Bootcamp]]에 따로 정리한다. 위 강의 플레이북은 무료 콘텐츠(롱폼/쇼츠/카러셀)용이고, 부트캠프 페이지는 유료 6주 오프라인 + 줌 보강 구조와 랜딩 페이지 15블록을 다룬다.

핵심만 짚으면:

- 결과물은 `효자상품 10개`다. 매출 보장 표현이 아니라 키워드·카테고리·상품명·대표이미지·상세페이지·가격·등록 전 체크가 갖춰진 상품 10개 완성을 뜻한다.
- 매주 작업물이 쌓이는 6주 구조다. 1주 진단 → 2주 선정/SEO → 3주 상세페이지 → 4주 등록 세트 → 5주 작업 루틴 → 6주 점검·30일 계획.
- 랜딩은 오빵 일본 구매대행 펀딩 상세페이지를 구조만 벤치마크하고, 매출 단정·"리스크 제로"·딸깍 자동화·마감 카운트다운은 차용하지 않는다.
