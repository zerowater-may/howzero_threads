# BraveYong Brain

## 역할

이 페이지는 용감한 용팀장 마케팅의 **중심 뇌**다.

유튜브, 인스타 카드뉴스, 릴스, 스레드, 카톡방, 랜딩 페이지, 신청서, 결제 안내가 모두 같은 메시지와 같은 퍼널을 타도록 만든다. 원문 단일 기준은 `brands/braveyong/braveyong_persona.md`이며, wiki에서는 이 페이지를 먼저 보고 실행한다.

## 한 문장 포지셔닝

상품만 계속 올리는데 안 팔리는 셀러를, SEO·상품명·상세페이지·AI 시스템으로 **진짜 팔리는 구조를 아는 셀러**로 바꾸는 실전형 교육 브랜드.

## 현재 비즈니스 목표

1. 유튜브와 SNS에서 "많이 올렸는데 안 팔리는 문제"를 정확히 찌른다.
2. 댓글 무료자료와 단톡방으로 따뜻한 리드를 모은다.
3. 단톡방에서 신뢰와 질문을 쌓는다.
4. 랜딩 페이지로 보내 신청서를 쓰게 한다.
5. 신청서 제출 후 결제 안내로 연결한다.
6. 5주 오프라인 AI 셀링 실전반으로 전환한다.

## 마케팅 퍼널

```txt
콘텐츠 노출
-> 첫 줄 후킹
-> 문제 공감
-> 용팀장식 기준 제시
-> 무료자료/댓글/단톡방 CTA
-> 카톡방 공지 확인
-> 랜딩 페이지
-> 신청서 작성
-> 결제 링크 안내
-> 용팀장 카톡 확인
-> 5주 오프라인 실전반 참여
```

## 핵심 고객

- 구매대행, 스마트스토어, 쿠팡, 글로벌 위탁판매 초보/현직 셀러
- 상품을 많이 올렸는데 노출·매출·순수익이 막힌 사람
- 상품명, 카테고리, SEO, 상세페이지를 감으로 하고 있는 사람
- AI를 써봤지만 실제 판매 업무에 붙이지 못한 사람
- 직장·육아·본업 때문에 시간이 부족하지만 현금흐름이 필요한 사람

## 핵심 메시지 맵

| 축 | 메시지 | 콘텐츠로 바꾸는 방식 |
|---|---|---|
| SEO/노출 | 많이 올리는 것보다 검색에 걸리는 구조가 먼저다 | 상품명, 카테고리, 키워드 실수 체크 |
| 상세페이지 | 상세페이지는 디자인이 아니라 설득 순서다 | 고객 고통, 구매 이유, 불안 제거 순서 |
| AI | AI가 대신 팔아주는 게 아니라 팔리는 구조를 빨리 만든다 | GPT/이미지 AI를 판매 프로세스에 연결 |
| 현금흐름 | 자산이 있어도 매달 들어오는 돈은 별개다 | 직장인·육아아빠·부업 현실 서사 |
| 실전반 | 혼자 막힌 부분을 5주 동안 같이 고친다 | 신청서 -> 결제 안내 -> 오프라인 작업 |

## 채널별 역할

| 채널 | 역할 | CTA |
|---|---|---|
| 유튜브 롱폼 | 신뢰 형성, 문제 원인 교육, 무료자료 유도 | 댓글 남기면 무료자료 |
| 쇼츠/릴스 | 문제 하나를 찌르고 단톡방/자료로 이동 | 댓글, 프로필 링크, 단톡방 |
| 인스타 카드뉴스 | 저장용 체크리스트, 문제-원인-해결 요약 | 저장, 댓글, 프로필 링크 |
| 스레드 | 짧은 직설형 글로 공감/논쟁/신뢰 축적 | 댓글, 단톡방, 랜딩 |
| 카톡방 | 들어온 리드를 따뜻하게 만들고 질문 받기 | 랜딩/신청서 |
| 랜딩 페이지 | 왜 이 강의인지 설득하고 신청서로 이동 | 신청서 작성 |
| 신청서 | 결제 안내 전 필터와 상태 파악 | 결제 링크 안내 |

## 인스타 카드뉴스 운영 규칙

목표는 예쁜 카드가 아니라 **저장되는 체크리스트**다.

기본 구조:

```txt
1. 표지: 문제/경고/반전 한 문장
2. 공감: 많이 올렸는데 안 팔리는 장면
3. 원인: 상품 수가 아니라 노출 구조
4. 기준: 상품명, 카테고리, SEO, 상세페이지
5. 비교: 흔한 방식 vs 용팀장식 방식
6. 오늘 할 일: 내 스토어 점검 항목
7. CTA: 유튜브 댓글 무료자료 / 단톡방 / 신청서
```

표지 후보:

- 상품 탓 아닙니다
- 많이 올려도 안 팔리는 이유
- SEO 없이 등록하면 시간만 날립니다
- AI 상세페이지, 이렇게 쓰면 안 됩니다
- 상품명 하나가 노출을 막습니다

## 스레드 운영 규칙

스레드는 첫 줄이 전부다. 첫 줄에서 멈추지 않으면 나머지는 읽히지 않는다.

형식:

```txt
첫 줄: 문제를 바로 찌른다
2~4줄: 왜 그런지 짧게 설명한다
5~7줄: 용팀장식 기준을 준다
마지막: 댓글/단톡방/신청서 CTA
```

스레드 첫 줄 후보:

- 상품만 계속 올리는데 안 팔리면, 상품 문제가 아닐 수 있습니다.
- 많이 올렸는데 안 팔리면, 올리는 방식부터 바꿔야 합니다.
- AI로 상세페이지 만들었는데 안 팔리면, 디자인 문제가 아닙니다.
- 광고비 넣기 전에 상품명이 검색에 걸리는지부터 보세요.
- 부업 강의 결제 전에 내 상품이 보이는지부터 확인하세요.

스레드 CTA 후보:

- 무료자료는 유튜브 댓글 남기시면 받을 수 있습니다.
- 혼자 막히면 단톡방에 상품 정보랑 현재 상황 같이 남겨주세요.
- 5주 동안 같이 고쳐보고 싶은 분은 신청서 먼저 남겨주세요.

## 카톡방 운영 규칙

카톡방은 친목방이 아니라 전환 전 단계다. 단, 바로 결제 압박으로 가면 신뢰가 깨진다.

공지 첫 줄:

```text
상품만 계속 올리는데 안 팔리면, 공지부터 꼭 보세요.
```

입장 안내 첫 줄:

```text
많이 올렸는데 안 팔리면, 올리는 방식부터 바꿔야 합니다.
```

카톡방 본문 원칙:

- 짧게 쓴다.
- 무료자료는 "유튜브 댓글 남기면 받는 자료"로 안내한다.
- 질문은 상품 정보와 현재 상황을 같이 적게 한다.
- 1기 실전반은 강남역 또는 선릉역 주변 예정이라고 안내한다.
- 신청서 작성 후 결제 안내가 연결된다고 말한다.

## 1기 실전반 전환 기준

- 상품명: 5주 오프라인 AI 셀링 실전반
- 시작: 2026.06.13
- 장소: 강남역 또는 선릉역 주변 예정
- 구성: 매주 토요일 오프라인 5회 + 수요일 줌 보강 4회 + 매주 과제
- 신청: 구글폼 신청서
- 결제: 신청서 제출 후 결제 안내

핵심 문구:

```text
신청서를 먼저 작성하셔야 결제 링크가 발송됩니다.
신청서 제출 직후 응답 페이지에 결제 링크가 뜨고,
용팀장이 한 번 더 카톡으로 확인 메시지 드려요.
```

## 콘텐츠 기획 엔진

하나의 주제를 받으면 아래 산출물로 확장한다.

```txt
원천 주제
-> 유튜브 롱폼 훅/목차
-> 인스타 카드뉴스 7장
-> 릴스/쇼츠 30초 대본
-> 스레드 1~3개
-> 카톡방 짧은 공지
-> 랜딩/신청 CTA 문구
```

예시 주제: "상품명 때문에 노출이 안 되는 초보 셀러"

- 유튜브: 상품 계속 올리는데 노출 안 되는 진짜 이유
- 카드뉴스: 상품명 하나가 노출을 막습니다
- 릴스: 광고비 쓰기 전에 이 3개부터 보세요
- 스레드: 많이 올렸는데 안 팔리면, 올리는 방식부터 바꿔야 합니다
- 카톡방: 상품명/카테고리 질문은 상품 링크와 현재 상황 같이 남겨주세요
- CTA: 무료자료는 유튜브 댓글, 실전반은 신청서

## 콘텐츠 기둥 5개

1. **SEO/상품명**
   - 상품명, 카테고리, 키워드, 검색 노출
2. **상세페이지/AI**
   - AI 상세페이지, 후킹, 구매 이유, 이미지/카피 흐름
3. **초보 셀러 현실**
   - 많이 올렸는데 안 팔림, 강의 쇼핑, 시간 부족, 직장/육아 병행
4. **실전 체크리스트**
   - 오늘 스토어에서 확인할 것, 광고 전 점검, 등록 전 체크
5. **실전반 전환**
   - 5주 동안 같이 고침, 신청서, 결제 안내, 강남역/선릉역 주변

## 금지

- 수익 보장
