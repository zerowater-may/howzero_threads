# BraveYong AI Selling Bootcamp

## 역할

용감한 용팀장의 첫 유료 오프라인 상품인 `6주 오프라인 AI 셀링 실전반` 합성 페이지다. 커리큘럼, 랜딩 페이지 구조, 톤 가드, 운영 입력 사항을 한 곳에 모아 다음 대본·콘텐츠·후속 기수 기획 작업에서 같은 기준을 쓰도록 한다. 원문 spec은 `docs/superpowers/specs/2026-05-22-braveyong-ai-selling-offline-landing-design.md`다.

## 상품 한 줄

1000개를 무작정 올리는 셀러에서, 효자상품 10개를 만드는 셀러로 — 6주 오프라인 + 줌 보강으로 함께 만든다.

## 상품 기본값

| 항목 | 값 |
|---|---|
| 무료 전환강의 | 2026-06-10 (수), 유튜브 |
| 본강의 시작 | 2026-06-13 (토) |
| 구성 | 오프라인 6회 + 줌 보강 5회 + 매주 과제 |
| 장소 | 서울 강남 (상세주소는 참여 확정자에게 안내) |
| 시간 | 추후 안내 (운영 입력) |
| 모집 인원 | 10~15명 소수정예 |
| 가격 | 1기 실행자 특별가 180만원 / 2기 이후 정가 250만원 |
| 결제 | 카드·계좌이체. 분할 여부 별도 안내. 신청서 검토 후 참여 확정자에게만 결제 안내. |
| 졸업 후 스터디 | 매월 1회 오프라인 · 3개월 15만원 · 선택. 1기 우선 참여권. |
| 핵심 결과물 | 효자상품 10개 (매출 보장 아님, 용팀장 기준 7요소 갖춘 상품 10개) |

## 6주 커리큘럼

오프라인은 현장 작업·피드백, 줌 보강은 중간 과제 점검. 매주 작업물이 쌓이는 구조다.

| 주차 | 주제 | 다루는 것 | 산출물 |
|---|---|---|---|
| 1주 | 대량등록 탈출 진단 | 현재 방식·시간·마진·노출 진단, 살릴/버릴 상품 기준, 6주 실행 목표 | 내 스토어 진단표, 효자상품 기준표 초안, 6주 개인 실행 목표 |
| 2주 | 상품 선정·키워드·카테고리 | 감 소싱 줄이기, 검색 의도·경쟁 구조, 카테고리·상품명 기준, 효자상품 2개 설계 | 후보 상품 리스트, 키워드 맵, 상품명 초안 |
| 3주 | AI 상세페이지 설계 | 구매 이유·불안 제거 순서, 고객 고통, 대표이미지, 스토리보드 | 상세페이지 스토리보드, 이미지/카피 프롬프트, 효자상품 추가 |
| 4주 | 등록·대표이미지·전환 체크 | 상품명·대표이미지·상세페이지·가격·배송/CS 점검, 등록 가능한 상품 세트 완성 | 등록 가능한 상품 세트, 등록 전 체크리스트, 효자상품 추가 |
| 5주 | AI 반복 작업 루틴 | 상품 분석·상품명 개선·상세페이지 초안·CS 답변·체크리스트 템플릿화, 작업 루틴 정리 | 개인 AI 셀링 템플릿, 주간 작업 루틴표, 효자상품 추가 |
| 6주 | 효자상품 10개 점검·다음 30일 | 효자상품 10개 최종 점검, 노출·클릭·문의·주문·순수익 개선 기준, 졸업 후 30일 계획 | 효자상품 10개, 30일 실행 계획, 개선 우선순위, 개인별 피드백 |

`효자상품` = 키워드·카테고리·상품명·대표이미지·상세페이지·가격·등록 전 체크가 갖춰진 상품. 매출을 보장하는 표현이 아니다.

## 랜딩 페이지 확장 15블록

`docs/superpowers/specs/2026-05-22-braveyong-ai-selling-offline-landing-design.md` 2026-05-22 개정판 기준. 오빵 일본 구매대행 펀딩 상세페이지 구조를 벤치마크해 4블록을 추가했다(✚).

1. Hero — 작업화면 70~85% + 얼굴 15~30%, Hero 카피·서브약속·CTA
2. ✚ 신뢰 증거 — 현업 사실 지표 4개(운영 입력) + 1기 후기 자리(정직 placeholder)
3. 문제 제기 — 대량등록 한계 4가지
4. AI 셀링 정의 — 판매 운영 구조 + 반복 루프
5. 핵심 결과물 — 효자상품 10개, 매출 보장 아님 가드
6. 6주 커리큘럼 — 오프라인 6 + 줌 5 (위 표)
7. 운영 방식 — 5개 지표 + 일정/장소
8. 왜 용팀장인가 — 진정성 서사 (직장인·육아아빠·현업셀러)
9. 졸업 후 오프라인 스터디 (가격 바로 앞)
10. ✚ 반론 차단 — "이미 늦었다·시간 없다·AI 모른다·결석" 4종, 사실로만 답
11. ✚ 비교표 — 일반 온라인 강의 vs 오프라인 실전반 6항목
12. 가격 섹션 — 1기 180 / 정가 250, 카피·방어·결제
13. ✚ 소수정예 한정 — 정직 희소성(10~15명·1기 특별가·선별)
14. 신청서 & 선별 — 주/보조 CTA, 신청서 11문항, 강한 문구
15. FAQ 12문항 + 최종 CTA

## 톤 가드 (오빵 벤치마크 차용/금지)

오빵 일본 구매대행 펀딩 상세페이지(메이커 `오빵`, 50p)에서 **구조만** 차용한다.

### 차용한다 (구조)

- 신뢰 증거 블록을 Hero 직후에 배치 (사회적 증거)
- 반론 차단을 가격 직전에 배치
- 비교표로 가격 방어
- 소수정예 희소성을 명시 블록화

### 차용하지 않는다 (톤)

- 매출·수익 단정 ("월 2000만원", "18억", "월 500 신화")
- "리스크 제로 / 돈 잃을 수 없다" 류 보장
- "AI가 알아서 / 매크로로 평생 자동" 류 딸깍 자동화 과장
- 가짜 마감 카운트다운, 거짓 잔여석, "오늘 마감" 류 허위 압박
- 사람을 조롱하는 `가짜 셀러` 표현
- 검증 안 된 수익 단정

**원칙: 강한 설득은 사실·구조·선별로 만든다. 과장·보장·압박 카피로 만들지 않는다.** [[BraveYong Persona]]의 금지 표현과 일치한다.

## 신청서 11문항

`6주 오프라인 실전반 지원하기` 주 CTA는 구글폼으로 연결한다.

1. 이름
2. 연락처
3. 현재 판매 플랫폼
4. 현재 상품 등록 수
5. 월매출 / 순수익 구간
6. 가장 막히는 지점
7. 기존 상품 개선 / 새 상품 제작
8. 오프라인 6회 참석 가능 여부
9. 줌 보강 5회 참여 가능 여부
10. 매주 과제 실행 가능 여부
11. 2026-06-13 시작 본강의 참여 의향

신청서 역할: 무료강의 신청 + 셀러 상태 진단 + 실행 의지 확인 + 본강의 결제 후보 분리.

## 운영 입력 필요 사항

상세페이지 게시 전 운영자가 실제 값으로 채워야 하는 항목. 확정 전까지는 `추후 안내` / `참여 확정자에게 안내` / `data-placeholder`로 표시한다.

- 오프라인 수업 시간
- 상세 주소
- 카드 결제 시스템 또는 PG 링크
- 계좌이체 안내 계좌
- 환불 기준
- 구글폼 실제 URL
- 유튜브 무료강의 URL
- 용팀장 현업 사실 지표 실제 값 (운영 스토어 수, 직접 올린 상품 수, 누적 강의·상담 — 수익 단정 금지)
- 1기 종료 후 실제 후기 텍스트/캡처 (그 전까지는 "1기 모집 중" 자리 유지)

## 후속 콘텐츠 시드

이 부트캠프 자체가 braveyong 콘텐츠의 시드가 된다. 다음 콘텐츠를 만들 때 같은 기준을 쓴다.

- 롱폼/유튜브 대본: 6주 커리큘럼의 한 주차를 한 영상으로. 1주 진단 → 5주 루틴 순서로 시리즈화 가능.
- 쇼츠: 반론 차단 4종 + 비교표 6항목 + 효자상품 7요소를 각 1편씩.
- 카러셀: 효자상품 7요소, 6주 산출물 지도, 일반 강의 vs 실전반 비교.
- 뉴스레터: 1기 모집 공지 + 후기 자리 채우기 캠페인.
- 링크드인: 직장인 육아아빠 셀러 서사 + "강의팔이가 아니라 현업셀러" 톤.

후속 콘텐츠도 톤 가드(매출 보장 ✕, 카운트다운 ✕, AI 대신 팔아준다 ✕)를 그대로 따른다.
