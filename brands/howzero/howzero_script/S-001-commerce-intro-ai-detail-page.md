### [15-25초] Before / After 증명 (★ 스마트스토어 A 실데이터)

```
화면: ★ 스마트스토어 A 광고 관리자 split — 4월 vs 5월

   왼쪽 (Before 4월):  전환율 4%
   오른쪽 (After 5월): 전환율 5%
   상단 한 줄: "같은 상품 · 같은 광고비 · 상세페이지만 교체"

   ★ 후반 자막 폭격 (1% 의미 시각화):
      "겨우 1%?" 빨간 의문 부호
      ↓
      [객단가 10만원 · 방문자 1,000명]
      400만원 → 500만원   (+100만원 / 월)
      [방문자 10,000명]
      4,000만원 → 5,000만원   (+1,000만원 / 월)

대사:
"이게 그 효과예요.
 제 스마트스토어 A인데, 같은 상품·같은 광고비,
 상세페이지만 바꿨더니 전환율이 4%에서 5%로 올랐어요.

 '겨우 1%?'
 이 1%가 진짜 무서운 숫자입니다.

 객단가 10만 원, 방문자 천 명이면
 매출 400만 원이 500만 원으로.
 같은 광고비로 한 달 100만 원 추가예요.

 만 명이면 천만 원 차이. 1%가 이런 거예요."

★ 실증 자산:
  - 본인 운영 스마트스토어 A 실제 광고 화면 캡처
  - 같은 상품 ID에서 상세페이지만 교체한 4월 vs 5월 데이터
  - 전환율 4% → 5% (월 매출 +25%, 객단가 10만원 기준)

★ 1% 계산 근거 (객단가 10만원):
  - 방문자 1,000 → 매출 400만원 → 500만원 (+100만원, +25%)
  - 방문자 10,000 → 매출 4,000만원 → 5,000만원 (+1,000만원, +25%)
  - 방문자 100,000 → 매출 4억 → 5억 (+1억, +25%)

★ 촬영 전 준비:
  [ ] 스마트스토어 A 광고 관리자 4월 30일 캡처
  [ ] 5월 30일 캡처 (상세페이지 교체 후 측정)
  [ ] 화면에 스토어명/상품명 노출되면 모자이크 처리 결정
  [ ] 1% 의미 자막 그래픽 디자인 (400만/500만/+100만 강조)
```

### [25-40초] ★ 권위 — 셀러를 위한 AI 개발자

```
화면: 본인 정면 + 3단 자막
  ▸ 셀러 1년 차에 월 1억 구조 완성
  ▸ 데이터에 빠져 AI 개발자로 전향
  ▸ 미션: 셀러 노가다 → AI 자동화 (= 불사자)

대사:
"안녕하세요 하우제로입니다.

 2020년에 셀러로 시작해 1년 만에 월 1억 구조 만들었고,
 데이터에 빠져 AI 개발자가 됐습니다.

 2023년 4월 AI 나오는 거 보고 결심했어요.
 '셀러가 손으로 하는 노가다, 내가 AI로 다 자동화해주자.'

 그때부터 셀러를 위한 AI 자동화만 박는 중이고,
 그 결과물이 불사자입니다."

★ 핵심 연출: '내가 AI로 다 자동화해주자' 시점에 카메라 정면 직시.
```

### [40-52초] 오늘 영상 가치 약속 (포토샵·크몽·낱개 AI = X / 불사자 1장 30원 ✅)

```
화면: 큰 ❌ 아이콘 3개 순차 → ✅ 1개 등장
  ❌ 포토샵           (5년 전 방식)
  ❌ 크몽 외주        (장당 30만원)
  ❌ 챗GPT·나노바나나 낱개  (한 상품에 1시간)
       ↓
  ✅ 묶은 자동화 워크플로우 (1장 30원 · 3분)

  ★ 시각 강조: "30만원 → 30원, 1만 배 차이" 빨간 박스

대사:
"오늘 영상은 이거 다 푸는 영상입니다.

 ① 포토샵? 5년 전 방식이에요. 이제 안 씁니다.
 ② 크몽 외주 30만 원? 마진 어디서 나와요.
 ③ 챗GPT·나노바나나 하나씩? 그것도 한 상품에 1시간이에요.

 그 셋을 한 번에 묶은 자동화 워크플로우 —
 한 상품 3분, 1장 30원으로 끝냅니다."

★ 핵심:
  - 30만원 → 30원 = 1만 배 차이 (시각으로 충격 박힘)
  - 가격은 자랑 X, 담담히 "30원으로 끝냅니다" 한 줄
  - 크몽 외주 셀러 + 챗GPT 낱개 사용자 둘 다 자기 발견
```

```
대사:
"AI 툴 자랑 영상 아닙니다.
 영상 끝났을 때 대표님 스스든 쿠팡이든 전환율이 올라가는 게 목표예요.
 갑니다."

(컷 → 본론 시작)

★ "스스든 쿠팡이든" = 스마트스토어 셀러 + 쿠팡 셀러 동시 캡처
```

## 📋 영상 내 자막 3단 (25-40초 권위 구간 박스)

```
▸ 셀러 1년 차에 월 1억 구조 완성
▸ 데이터에 빠져 AI 개발자로 전향
▸ 미션: 셀러 노가다 → AI 자동화 (= 불사자)
```

타임라인 박스 버전 (더 시각적):

```
   2020 ───── 2021 ───── 2023.4 ───── 현재
    │          │           │           │
   셀링      월 1억      AI 등장      불사자 +
   시작     (1년만에)   → 효율 박음   자동화
              ↓            ↓
          "왜 팔렸지?"  본격 미션화
              ↓
           개발자 전향
```

## 🎨 시각 연출 핵심 메모

| 구간 | 화면 | 비주얼 포인트 |
|---|---|---|
| 0-5초 | 본인 vs 자동 등록 split | 카운터 +1, +2, +3 실시간 |
| 5-15초 | 결과물 4장 빠른 컷 | 퀄리티 증명 + "판매자" 자막 |
| **15-25초** | **스마트스토어 A 광고 관리자 split** | **전환율 Before → After 빨간 박스 강조** |
| 25-32초 | 본인 정면 + 자막 박스 등장 | 셀러 → 데이터 → 개발자 진화 시각화 |
| **32-40초** | **본인 정면 풀화면, 카메라 직시** | **"내가 AI로 다 자동화해주자" 미션 선언** |
| **40-52초** | **❌ 아이콘 3개 → ✅ 1개** | **"30만원 → 30원, 1만 배 차이" 강조** |
| 52-60초 | 본인 + 스스/쿠팡 로고 split | 전환율 그래프 우상향 |

**60-90초마다 패턴 인터럽트 필수** — 위 흐름 화면 전환 7번 = 충족.
