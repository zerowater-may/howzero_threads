## 🎯 한 줄 컨셉

> 마누태그(= 네이버 쇼핑 상품마다 들어가는 태그)는 노출 적합도에 직접 들어가는 필드다.
> 감으로 찍지 말고, 상위노출 상품이 실제로 쓴 태그를 데이터로 보고 *내 상품에 사실인 것만* 채워라.
> 단, 무관한 태그를 욱여넣으면 어뷰징 — 계정이 죽는다.

---

## 🎭 페르소나 (확정)

> **"셀러 1년 차에 월 1억 만들어보고,
> 데이터에 빠져 AI 개발자가 된 후,
> 셀러를 위한 AI 자동화만 박는 중."**

핵심 톤: 셀러를 위한 AI 개발자가 노가다를 자동화해준다 — 셀러는 객체가 아니라 봉사 대상.
이 영상의 봉사 포인트: **대표님 계정이 어뷰징으로 죽지 않게 경계선까지 짚어준다.**

## ✅ 팩트체크 (영상 주장 근거)

| 영상 주장 | 판정 | 근거 |
|---|---|---|
| 태그는 검색 노출에 영향을 준다 | ✅ 사실 | 네이버 쇼핑 검색 = 적합도·인기도·신뢰도. 적합도 4요소 = 상품명·카테고리·제조사/브랜드·**속성/태그** |
| 태그를 비우면 적합도 손해 | ✅ 사실 | 적합도는 노출의 기본 — 가이드 미준수 시 노출 자체가 안 될 수 있음 |
| 태그사전 등록 단어만 검색 적용 | ✅ 사실 | 태그사전 미등록 단어는 검색 미적용. 등록돼도 상품 부적합 시 미적용 가능 |
| 무관한 태그 남발 = 어뷰징 | ✅ 사실 | 무의미 키워드 반복·무관 정보 입력 = 어뷰징. 누적 시 '제한' 단계 → 스토어 전체 노출 차단, 퇴점 |

→ "꼭 넣어야 노출 잘 된다"는 절반 사실(태그는 적합도 필드), 절반 위험(복붙하면 어뷰징). 영상은 이 경계선을 핵심 메시지로 잡는다.

## 🎬 챕터별 연출 (10분)

### [0:00–0:35] HOOK — 태그 10칸 직격

```
화면: 스마트스토어 상품등록 화면 맨 아래 '태그 10칸' 클로즈업 → 커서가 빈 칸에서 깜빡
       후반: 검색 결과에서 상품이 스르륵 사라지는 모션

대사 포인트:
  "태그 10칸, 지금 어떻게 채우세요?" → 시청자 자기 인식
  "잘못 채우면 스토어 전체가 검색에서 사라진다" → 공포 갭 생성

★ 핵심: 5초 안에 "내 얘기다" 박고, 35초 안에 영상 끝까지 볼 이유(공포)를 건다.
```

### [0:35–1:30] 권위 + 오늘 영상 약속

```
화면: 본인 정면 + 타임라인 자막 (2020 셀링 → 월 1억 → 데이터 → AI 개발자)
       후반: 4챕터 목차 카드

대사 포인트: 자랑 영상 아님 선언 → 4단 목차 제시
★ 안티하이프: "영상 끝나고 본인 상품 태그 다시 열어보게, 그거 하나 만들려고 찍는다"
```

### [1:30–3:20] 챕터 1 — 태그가 왜 노출의 지렛대인가

```
화면: 네이버 쇼핑 3축 다이어그램 (적합도/인기도/신뢰도)
       → 적합도 4칸 그리드 (상품명 / 카테고리 / 제조사·브랜드 / 속성·태그)
       → '속성·태그' 칸만 빨강 하이라이트
       → 태그사전 개념 그래픽

대사 포인트:
  - 인기도·신뢰도는 시간/행동, 적합도는 오늘 당장 손댈 수 있음
  - 적합도 4칸 중 한 칸이 통째로 태그 → 비우면 1/4 버린 것
  - 태그사전: 등록된 단어만 적용, 사전에 있어도 부적합하면 미적용
```

### [3:20–5:40] 챕터 2 — 감 대신 데이터: 마누태그

```
화면: 네이버 쇼핑 '닌텐도 스위치2' 검색 결과 1페이지
       → 상위 상품들 태그를 하나씩 까는 모션
       → 마누태그 빈도 막대그래프 (닌텐도 42 / Nintendo 38 / 정품 31 / 한국닌텐도정품 24 / OLED 15 ...)

대사 포인트:
  - 1페이지 = 네이버가 "태그 잘 채웠다"고 인정한 상품
  - 마누태그 = 네이버 쇼핑 상품마다 들어가는 태그 데이터
  - 빈도순으로 보면 상위 셀러 공통 태그가 드러남 → "감이 아니라 데이터"

★ 실데이터: 닌텐도 스위치2 — 월 검색 482,200 / 총 상품 96,749 / 마누태그 38개
   (불사자 키워드 패널 — 마누태그 탭 실측치. 촬영 전 최신값 재확인)
```

### [5:40–8:00] 챕터 3 — 어뷰징 경계선 (★ 영상의 심장)

```
화면: "38개 다 복붙 = 노출 38배?" 큰 물음표 → 빨간 X
       → 어뷰징 페널티 단계 계단 그래픽 (주의 → 경고 → 제한 → 퇴점)
       → '제한' 단계에서 스토어 상품 그리드가 통째로 회색 처리
       → 정품 닌텐도 셀러 ✅ '정품' 태그 / 케이스 셀러 ❌ '본체' 태그 대비 컷

대사 포인트:
  - 복붙 = 어뷰징. 무의미 반복·무관 브랜드/제조사 박기 모두 해당
  - 페널티는 단계 누적, '제한'이면 스토어 전체 노출 차단, 더 쌓이면 퇴점
  - 마누태그 올바른 사용법: "복붙"이 아니라 "내가 빠뜨린 사실 태그 찾기"
  - 경계선 단 하나 = "내 상품에 사실이냐 아니냐"

★ 봉사 톤 정점: "노출 늘리려다 매출을 0으로 만들지 마세요" — 대표님 계정 지켜주는 구간
```

### [8:00–9:20] 챕터 4 — 태그 10칸 채우는 실전 순서

```
화면: 4단계 체크리스트 애니메이션
       1) 상위 상품 마누태그 빈도 추출
       2) 내 상품에 사실인 것만 체크
       3) 태그사전 등록 여부 확인
       4) 빈도·정확도 우선으로 10칸 채우기
       → 불사자 키워드 패널 마누태그 탭 실제 시연 (키워드 입력 → 빈도 목록 출력)

대사 포인트:
  - 손으로 하면 상품 수십 개 일일이 까야 함 → 하루 종일
  - 불사자 패널: 키워드 한 번 입력 → 빈도 목록 화면 한 장
  - 가격 자랑 X. 패널 기능만 담담히 보여줌

★ 안티하이프: 툴 자랑이 아니라 "이 노가다를 자동화했다" 결과만
```

### [9:20–10:00] CTA

```
화면: 4줄 요약 카드 → 본인 정면 → 스스/쿠팡 로고 split

대사 포인트:
  - 4줄 요약 (적합도 한 칸 / 데이터로 / 사실만 / 욱여넣지 마라)
  - 실행 지시: "상품 딱 하나만 골라 태그 10칸 다시 열어보세요"
  - 리드매그넷: 마누태그 패널 무료 체험 → 고정 댓글
  - "스스든 쿠팡이든 검색에 제대로 뜨는 게 목표"
```
