## 1. 디자인 컨셉

| 원칙 | 적용 |
|---|---|
| **다크 모노 베이스** | 화려한 컬러 X, 검정 위에 핵심 1-2색만 |

## 2. 컬러 팔레트

| 토큰 | HEX | 역할 | 빈도 |
|---|---|---|---|
| `BG` | `#0F0F0F` | 배경 (거의 검정, 모니터 부담 ↓) | 100% 슬라이드 |
| `TEXT` | `#F5F5F5` | 메인 본문 (소프트 화이트) | 80% |
| `MUTED` | `#707070` | 부가 텍스트, 분리선 | 60% |
| `MUTED_LIGHT` | `#A0A0A0` | Before 톤, 안내문 | 70% |
| `ACCENT` 🟡 | `#FFD43B` | 시간 큐 · 화살표 · "겨우 1%?" · 갑니다 | 모든 슬라이드 |
| `HIGHLIGHT` 🔴 | `#FF6B6B` | 부정·X마크·100장·+N만원 강조 | 6장 |
| `GREEN` 🟢 | `#4ECDC4` | 긍정 결과·After 숫자·✓·전환율 ↑ | 5장 |

### 컬러 룰

```
✓ 한 슬라이드에 강조색 최대 2개
✓ Before = MUTED_LIGHT (회색), After = GREEN (민트) — 무조건 동일 매핑
✓ 부정 / X / 비교 손해 = HIGHLIGHT (빨강)
✓ 행동 유도 / 시간 / 흐름 = ACCENT (노랑)
✗ 그라데이션 / 블러 / 글로우 사용 금지
✗ 컬러 3개 이상 동시 등장 금지
```

### 컬러 의미 매트릭스

| 슬라이드 | 빨강 (감정) | 민트 (결과) | 노랑 (시간/행동) |
|---|---|---|---|
| 1 vs 100 | 100장 | — | — |
| 디자이너 / 판매자 | 디자이너 ✕ | 판매자 ✓ | — |
| 4% → 5% | — | 5% | 화살표 |
| "겨우 1%?" | — | — | 1%? |
| 400만 → 500만 | +100만 | 500만 | 화살표 |
| 4천만 → 5천만 | +1,000만 | 5,000만 | 화살표 |
| 권위 타임라인 | 개발자 | 데이터 | 월 1억 |
| 셀러 자동화 | — | — | "박는 중" |
| ✕ 포토샵·크몽·낱개 | ✕ 마크 3개 | — | — |
| 3분 / 30원 | — | 3분 | 30원 |
| 전환율 ↑ / 갑니다 | — | 전환율 ↑ | 갑니다 |

## 3. 타이포그래피

### 폰트 패밀리

```
한글:      Apple SD Gothic Neo  (macOS 표준)
숫자/영문:  SF Pro Display        (Apple system)
```

→ macOS·iOS·Keynote에서 깨짐 없이 표시.
→ Windows에서 열면 시스템 fallback (보통 맑은 고딕 + Segoe UI).

### 사이즈 위계 (10단계)

| 위계 | 크기 | 용도 | 예시 |
|---|---|---|---|
| **GIGA** | 200-220pt | 거대 단일 숫자 | `4%`, `30원`, `3분` |
| **SUPER** | 160-180pt | 좌우 비교 키워드 | `1장`, `100장` |
| **HERO** | 110-170pt | 강조 문구 | `"겨우 1%?"`, `400만 원` |
| **TITLE** | 80-110pt | 단어형 키워드 | `디자이너`, `판매자`, `5%` |
| **HEAD** | 50-80pt | 권위 타임라인 단계 | `2020`, `월 1억` |
| **SUB1** | 32-44pt | 강조 부가 | `한 달 + 100만 원` |
| **SUB2** | 22-32pt | 메타 라인 | `같은 상품 · 같은 광고비` |
| **BODY** | 18-26pt | 구간 제목 | `의심 차단`, `미션` |
| **META** | 22pt | 시간 큐 | `0:00`, `0:15` |
| **PAGE** | 12pt | 페이지 번호 | `1 / 11` |

### 폰트 룰

```
✓ Bold = 키워드만. 부가 텍스트는 Regular
✓ Italic 사용 안 함
✓ 줄 간격 1.1-1.4 (위계별 다름, GIGA는 1.1)
✗ 글자 강조 위해 색을 동시에 2개 사용 금지
✗ 자간 변경 금지 (시스템 기본)
```

## 5. 슬라이드 타입 (5종)

### Type A · 거대 단일 키워드 (Hero)
*용도: 가장 강한 한 문구 박을 때*
- 슬라이드 4 "겨우 1%?"
- 슬라이드 8 "셀러 자동화 = 불사자"
- 슬라이드 11 "전환율 ↑ / 갑니다"

```
┌─────────────────────────┐
│ 0:15                    │
│ 1% 의문                 │
│ ──                      │
│                         │
│      "겨우 1%?"         │  ← 170pt
│                         │
│  이 1%가 무서운 숫자    │  ← 32pt
└─────────────────────────┘
```

### Type B · 좌우 비교 (VS)
*용도: 대비, 충격*
- 슬라이드 1 "1장 vs 100장"
- 슬라이드 2 "디자이너 / 판매자"

```
┌─────────────────────────┐
│ ┌───────┐  ┌───────┐    │
│ │  1장  │vs│ 100장 │    │
│ │ 회색  │  │ 빨강  │    │
│ └───────┘  └───────┘    │
│   같은 시간, 같은 사람   │
└─────────────────────────┘
```

### Type C · 화살표 변환 (Before → After)
*용도: 변화 시각화*
- 슬라이드 3 "4% → 5%"
- 슬라이드 5 "400만 → 500만"
- 슬라이드 6 "4천만 → 5천만"

```
┌─────────────────────────┐
│   [Before]  →  [After]  │
│    회색      노랑    민트│
│            화살표        │
└─────────────────────────┘
```

### Type D · 다단 타임라인
*용도: 진화·스토리*
- 슬라이드 7 "2020 → 월 1억 → 데이터 → 개발자"

```
┌─────────────────────────┐
│ 2020  2021   →   개발자 │
│ 시작 월 1억 데이터 시스템│
└─────────────────────────┘
```

### Type E · 리스트 ✕ (Negation)
*용도: 거부·제거*
- 슬라이드 9 "포토샵·크몽·낱개 ✕"

```
┌─────────────────────────┐
│ ✕ 포토샵     5년 전 방식│
│ ✕ 크몽 외주  장당 30만원 │
│ ✕ 챗GPT 낱개 1시간       │
└─────────────────────────┘
```

## 6. 마이크로 요소

### 화살표
- 도형: `MSO_SHAPE.RIGHT_ARROW`
- 색: `ACCENT` (노랑 #FFD43B)
- 폭·높이: 1.4-1.9" × 0.7-0.9"
- 라인: 없음 (배경 채움만)

### 박스 (Type B 좌우 비교)
- 도형: `MSO_SHAPE.ROUNDED_RECTANGLE`
- 채움: `#1A1A1A` (BG보다 살짝 밝게)
- 보더: `HIGHLIGHT` (빨강) 또는 `GREEN` (민트), 2pt

### 분리선
- 시간 큐 아래 짧은 분리선: 0.6" × 0.04", `ACCENT`
- 좌우 분할 세로 선 (Type 10): 0.03" × 2.5", `MUTED`

### ✕ / ✓ 마크
- 텍스트 기호 사용 (`✕`, `✓`)
- 사이즈 70-110pt
- 색: HIGHLIGHT (✕), GREEN (✓)

## 10. 확장 가이드 (다음 영상부터)

### S-002 이후 새 슬라이드 만들 때 적용 규칙

1. **컬러 토큰 7개 외에 추가 금지** — 시리즈 일관성
2. **시간 큐는 무조건 좌상단 0.7", 노랑 22pt**
3. **새 슬라이드 타입은 A-E 중에서만** — 새 타입 만들고 싶으면 기획서 먼저 갱신
4. **숫자 표기**:
   - 4자리 이하: 그대로 (`400만`)
   - 5자리 이상: 쉼표 (`4,000만`)
   - 단위: 한글 (`원`, `명`, `%`)
5. **시리즈 페이지번호**: `S-00X · N / N`
