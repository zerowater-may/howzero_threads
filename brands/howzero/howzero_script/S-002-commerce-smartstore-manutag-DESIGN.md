## 1. 디자인 컨셉

| 원칙 | 적용 |
|---|---|
| **다크 모노 베이스** | 검정 위에 핵심 1–2색만 |
| **한 점 강조** | 슬라이드당 빨강 또는 민트 1개만 시선 잡음 |
| **거대 타이포** | 키워드만 180–220pt — 0.3초 인식 |
| **여백 = 신뢰** | 박스 빽빽하게 채우지 않음 |
| **숫자는 SF Pro Display** | 영문 폰트로 숫자만 — 데이터 신뢰감 ↑ |

→ S-001과 동일 시스템. 시리즈 일관성 유지.

## 2. 컬러 팔레트 (S-001 계승)

| 토큰 | HEX | 역할 |
|---|---|---|
| `BG` | `#0F0F0F` | 배경 (거의 검정) |
| `TEXT` | `#F5F5F5` | 메인 본문 (소프트 화이트) |
| `MUTED` | `#707070` | 부가 텍스트·분리선 |
| `MUTED_LIGHT` | `#A0A0A0` | 보조 안내문 |
| `ACCENT_RED` | `#FF3B30` | 경고·강조 (어뷰징·빈 칸 손실) |
| `ACCENT_MINT` | `#34E0C0` | 긍정·정답 (데이터·검증된 태그) |

색 규칙: **빨강 = 위험/손실, 민트 = 정답/데이터.** 한 슬라이드에 둘 다 쓰지 않음 (대비 컷 제외).

## 3. 챕터별 슬라이드 키워드

> 키워드만 큐로. 문장 금지. 대사는 -READ.md.

### [0:00–0:35] HOOK
- S01 — `태그 10칸` (180pt) + 빈 칸 그래픽
- S02 — `검색에서 사라집니다` (`ACCENT_RED`)

### [0:35–1:30] 권위 + 목차
- S03 — 타임라인 `2020 → 월 1억 → 데이터 → AI 개발자`
- S04 — 목차 4칸 `① 왜 / ② 데이터 / ③ 어뷰징 / ④ 실전`

### [1:30–3:20] 챕터 1 — 태그 = 노출 지렛대
- S05 — `적합도 · 인기도 · 신뢰도` 3축
- S06 — 적합도 4칸 그리드 `상품명 / 카테고리 / 제조사·브랜드 / 속성·태그` → **'속성·태그'만 `ACCENT_RED` 박스**
- S07 — `태그사전` — 등록된 단어만 적용

### [3:20–5:40] 챕터 2 — 마누태그 데이터
- S08 — `마누태그` (220pt) + 정의 한 줄
- S09 — 닌텐도 스위치2 빈도 막대그래프 (`ACCENT_MINT`) — `닌텐도 42 · Nintendo 38 · 정품 31 · 한국닌텐도정품 24 · OLED 15`
- S10 — `감 ❌ → 데이터 ✅`

### [5:40–8:00] 챕터 3 — 어뷰징 경계선
- S11 — `38개 다 복붙?` → 큰 빨간 `✕`
- S12 — 페널티 계단 `주의 → 경고 → 제한 → 퇴점` (`ACCENT_RED`)
- S13 — `제한 = 스토어 전체 노출 0` (상품 그리드 회색 처리)
- S14 — 대비 컷: 정품 셀러 `정품 ✅` / 케이스 셀러 `본체 ✕`
- S15 — `경계선 = 내 상품에 사실이냐` (민트)

### [8:00–9:20] 챕터 4 — 실전 4단계
- S16 — 4단계 체크리스트 `① 빈도 추출 ② 사실만 체크 ③ 태그사전 확인 ④ 10칸 채우기`
- S17 — 불사자 키워드 패널 마누태그 탭 시연 캡처 (실화면)

### [9:20–10:00] CTA
- S18 — 4줄 요약 카드
- S19 — `상품 1개, 태그 10칸 다시 열기` (실행 지시)
- S20 — `스스 · 쿠팡` 로고 + 고정 댓글 안내

## 4. 타이포 규칙

| 용도 | 폰트 | 크기 |

## 5. 모션 가이드

- 슬라이드 전환: 컷 (페이드 금지 — 다크 모노에서 페이드는 톤 흐림)
- 강조 등장: 빨강/민트 박스만 0.2초 스케일 인
- 빈도 막대그래프(S09): 좌→우 순차 그로우
- 페널티 계단(S12): 한 단씩 빨강 점등 — '제한'에서 0.5초 정지
- 패턴 인터럽트: 챕터 전환 시 풀블랙 0.3초 인서트 후 다음 키워드 등장
