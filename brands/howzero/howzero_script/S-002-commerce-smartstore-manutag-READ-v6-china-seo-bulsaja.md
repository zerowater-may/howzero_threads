# S-002 · 스마트스토어 상품명 구조 롱폼 대본 v6

> v6 현재 방향: 제목과 후킹은 "상품 100개 올렸는데 왜 안 팔리는가"로 시작한다.  
> 핵심 메시지: 상품명이 제일 중요하다. 다만 상품명은 감으로 쓰는 게 아니라 카테고리, 상품속성, 태그, 브랜드/제조사, 텀즈, 데이터랩을 보고 구조적으로 설계해야 한다.  
> 불사자는 제목에 넣지 않고, 영상 후반부에서 수동 작업을 줄이는 확장프로그램으로 등장시킨다.

## 최종 제목

상품 100개 올렸는데 안 팔리는 이유, 상품명 구조가 틀렸습니다

## 썸네일

메인:

```txt
100개 올렸는데 왜 안 팔릴까?
```

서브:

```txt
상품명 구조부터 틀렸습니다
```

## 제목 후보

1. 상품 100개 올렸는데 안 팔리는 이유, 상품명 구조가 틀렸습니다
2. 스마트스토어 상품 100개 올려도 안 뜨는 사람들의 공통점
3. 상품등록 1개 할 때 이 5가지만 확인하세요
4. 상품 100개 대충 올릴 시간에, 이 1개를 제대로 올리세요
5. 스마트스토어 초보가 상품 100개 올리고도 매출 안 나는 이유
6. 상품명 하나 잘못 쓰면 100개 올려도 안 팔립니다
7. 상품등록 전에 이 7개 안 보면 네이버가 상품을 못 알아봅니다

## 한 줄 컨셉

상품을 계속 올리는데 매출이 안 나는 초보 셀러는 노력량보다 등록 구조를 먼저 봐야 한다. 잘 파는 셀러들은 상품명, 카테고리, 속성, 태그, 썸네일, 가격을 기본값처럼 챙긴다. 이 영상에서는 그중 가장 먼저 고쳐야 하는 상품명 구조를 다룬다. 네이버쇼핑에서 노출되는 상품명은 고객 검색어, 카테고리, 상품속성, 태그, 브랜드/제조사, 텀즈가 한 방향으로 맞아야 한다.

## 6:15 · 챕터 3. 수동 작업 2단계: 상품명 키워드를 구조로 나눕니다

두 번째는 상품명 키워드 구조입니다.

상품명은 보통 네 덩어리로 보면 쉽습니다.

메인 키워드.

핵심 속성.

사용 상황.

구매 판단 정보.

예를 들어 `무타공 욕실 코너선반 접착식 샤워실 수납 선반`을 나눠보겠습니다.

메인 키워드:

```txt

```

핵심 속성:

```txt
무타공, 코너형, 접착식
```

사용 상황:

```txt
샤워실, 욕실수납
```

구매 판단 정보:

```txt
소재, 사이즈, 색상, 구성
```

이걸 아무 순서로 넣으면 안 됩니다.

그건 판매 방식이거나 느낌입니다.

상품명은 느낌을 쓰는 칸이 아닙니다.

상품을 설명하는 칸입니다.

그래서 나쁜 상품명은 이렇게 생깁니다.

```txt
중국직구 생활용품 욕실 인테리어 수납 정리 해외배송 가성비 선반
```

좋은 상품명은 이렇게 생깁니다.

```txt
무타공 욕실 코너선반 접착식 샤워실 수납 선반
```

두 상품명 모두 단어가 들어가 있습니다.

하지만 구조가 다릅니다.

첫 번째는 넓은 단어를 나열했습니다.

두 번째는 고객 검색어와 상품 속성을 한 방향으로 묶었습니다.

노출되는 상품명은 길이가 아니라 구조가 다릅니다.

## 8:10 · 챕터 4. 수동 작업 3단계: 텀즈, 데이터랩, 마누태그를 같이 봅니다

세 번째는 자료를 보는 순서입니다.

대표님이 손으로 상품명을 만들 때
최소한 세 가지는 봐야 합니다.

첫째, 텀즈입니다.

텀즈는 쉽게 말하면
네이버가 단어를 어떻게 묶어 이해하는지 보는 기준입니다.

예를 들어 `접이식 캠핑의자`를 팔 때
네이버가 `접이식`, `캠핑의자`를 어떻게 인식하는지 봐야 합니다.

`캠핑의자`,
`접이식 캠핑의자`,
`경량 캠핑의자`,
`릴렉스체어`.

이 단어들이 같은 시장인지,
다른 검색 의도인지 확인해야 합니다.

둘째, 네이버 데이터랩입니다.

데이터랩은 백화점의 고객 동선이라고 생각하면 됩니다.

사람들이 언제 어떤 단어를 많이 검색하는지 보는 겁니다.

예를 들어 `캠핑의자`는 봄, 여름 시즌에 강해질 수 있고,
`여행용 압축 파우치`는 휴가철 전에 검색이 올라올 수 있습니다.

`무타공 욕실 선반`은 시즌보다 생활 니즈에 가까울 수 있습니다.

검색량,
계절성,
시장 규모를 보고
내가 잡을 키워드를 정해야 합니다.

셋째, 마누태그와 `menuTag`입니다.

태그는 입력했다고 전부 검색에 반영되는 게 아닙니다.

스마트스토어 상품 등록 화면에서
태그사전에 등록된 태그를 선택하면 오른쪽에 숫자가 뜹니다.

그런데 그냥 직접 입력하거나 엔터로 넣으면
숫자가 안 뜨는 경우가 있습니다.

이런 태그는 입력은 된 것처럼 보여도
검색 신호로는 약할 수 있습니다.

그리고 태그사전에 등록되어 있어도
실제 검색에 반영되는 태그와 아닌 태그가 또 갈립니다.

이걸 확인할 때 보는 게 `menuTag`입니다.

너무 기술적으로 들어갈 필요는 없습니다.

개념만 잡으면 됩니다.

`menuTag`에 잡히는 태그는
그 상품에서 실제 검색 신호로 쓰이는 태그 후보에 가깝습니다.

그래서 상품명을 만들 때는
상품명에 넣을 메인 키워드와
태그로 뺄 서브 키워드를 나눠야 합니다.

상품명이 100이면,
