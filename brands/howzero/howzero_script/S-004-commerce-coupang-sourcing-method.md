## 1. 한 줄 컨셉

쿠팡 소싱은 “잘 팔리는 상품을 찾는 일”이 아니라, **잘 팔리지만 내가 들어가면 죽을 상품을 먼저 걸러내는 일**이다. 초보 셀러가 봐야 할 것은 유행 상품 하나가 아니라 `검색어`, `상위상품 판매 흔적`, `리뷰 장벽`, `가격/배송 경쟁`, `브랜드·KC·지식재산권 리스크`다. 이 다섯 가지를 손으로 보면 오래 걸리기 때문에, 불사자 쿠팡 스카우터/수집함/엑셀 구조로 반복 작업을 줄인다.

---

## 2. 원본 레퍼런스 구조 vs 하우제로 커머스 변환

> 직전 작업에서 분석한 레퍼런스는 “쿠팡에서 상품 후보를 찾는 방법” 중심이었다. 그대로 베끼지 않고, 하우제로 커머스는 **초보 셀러가 망하는 원인 → 데이터 필터 → 수동 병목 → 불사자 자동화 → 리스크 가드 → 실행 CTA**로 바꾼다.

| 구간 | 원본 레퍼런스에서 가져올 뼈대 | 하우제로 커머스 변환 |
|---|---|---|
| 도입 | 쿠팡에서 상품을 찾아야 한다 | “잘 팔리는 상품 찾기”보다 “들어가면 죽을 상품 걸러내기”로 시작 |
| 방법 | 검색 결과와 상품을 본다 | 검색어 → 상위상품 → 리뷰 장벽 → 가격/배송 → 리스크 5단계 체크 |
| 증거 | 상품 화면을 보여준다 | 판매 흔적, 조회/판매/매출 추정, 리뷰 수, 옵션, 가격을 한 화면에서 비교 |
| 병목 | 손으로 여러 상품을 본다 | 상품 30개만 봐도 탭 이동·엑셀·메모가 무너진다고 공감 |
| 차별화 | 도구/노하우 소개 | “신기한 AI”가 아니라 대표님이 하던 순서를 자동화한 작업대 |
| 마무리 | 따라 해보세요 | 상품 하나만 골라 5개 필터로 걸러보고, 불사자 무료 체험/고정댓글 체크리스트 CTA |

| 영상 주장 | 사용 가능 여부 | 근거/가드 |

| 쿠팡 상위노출을 보장한다 | ❌ | 금지. 광고/리뷰/가격/배송/전환 등 복합 요소이므로 보장 표현 금지 |
| KC/인증/안전기준이 필요한 상품도 그냥 소싱해도 된다 | ❌ | 금지. 카테고리별 인증/안전/수입 요건 확인 필요 |

### [2:40–5:30] 챕터 2 — 쿠팡 소싱 5개 필터

#### 필터 1. 검색어가 너무 넓지 않은가

```txt
첫 번째는 검색어입니다.

예를 들어 “캠핑의자”는 너무 넓습니다.
상위 상품도 많고, 리뷰도 많고, 가격대도 다양합니다.

초보 대표님은 처음부터 큰 키워드로 싸우면 안 됩니다.

“접이식 캠핑의자”
“초경량 캠핑의자”
“아이보리 캠핑의자”

이렇게 고객이 실제로 찾는 세부 키워드로 좁혀야 합니다.
```

#### 필터 2. 상위 상품의 판매 흔적이 있는가

```txt
두 번째는 판매 흔적입니다.

상위에 떠 있는데 실제로 팔린 흔적이 없는 상품은
그냥 노출만 된 상품일 수 있습니다.

반대로 리뷰가 아주 많지는 않은데
최근 판매 흔적이 있고,
조회나 판매 추정이 계속 보이면
후보로 볼 수 있습니다.
```

#### 필터 3. 리뷰 장벽이 너무 높지 않은가

```txt
세 번째는 리뷰 장벽입니다.

리뷰 5,000개 상품 옆에
리뷰 0개로 들어가면
가격을 아무리 낮춰도 고객이 망설입니다.

초보 대표님은 처음부터 리뷰 괴물과 붙지 말고,
리뷰 수가 낮은 상품도 상위에 섞여 있는 키워드를 찾아야 합니다.
```

#### 필터 4. 가격과 배송 경쟁을 버틸 수 있는가

```txt
네 번째는 가격과 배송입니다.

쿠팡은 가격만 보는 플랫폼이 아닙니다.
배송, 리뷰, 판매자 신뢰, 옵션 구성까지 같이 봅니다.

로켓배송이 이미 깔린 상품,
브랜드가 가격을 세게 누르는 상품,
마진이 거의 안 남는 상품은
초보가 들어가면 버티기 어렵습니다.
```

#### 필터 5. 브랜드·KC·지식재산권 리스크가 없는가

```txt
다섯 번째가 제일 중요합니다.

브랜드 로고가 박힌 상품,
캐릭터가 들어간 상품,
인증이 필요한 전기·유아·안전 관련 상품,
상표권이 걸릴 수 있는 상품은
판매량이 좋아 보여도 먼저 걸러야 합니다.

소싱은 많이 찾는 게 아니라
계정이 오래 갈 상품을 남기는 겁니다.
```

```txt
이 5개로 먼저 걸러보세요.

검색어가 너무 넓지 않은가.
판매 흔적이 있는가.
리뷰 장벽이 너무 높지 않은가.
가격과 배송 경쟁을 버틸 수 있는가.
브랜드·KC·지식재산권 리스크가 없는가.

이걸 손으로 해도 됩니다.
처음에는 꼭 손으로 한 번 해보세요.
그래야 기준이 생깁니다.

다만 계속 손으로 하면 오래 걸립니다.
그래서 고정댓글에
쿠팡 소싱 체크리스트랑
불사자 무료 체험 링크 남겨두겠습니다.

대표님 상품 하나만 골라서
오늘 5개 필터로 바로 걸러보세요.

소싱은 많이 찾는 게 아니라,
위험한 걸 빨리 버리고
남길 상품을 고르는 일입니다.
```

## 6. 더 기본적으로 할 수 있는 것

사용자가 물은 “더 기본적으로 할 수 있는 것”은 영상 안팎에서 아래 6개다.

### 1) 쿠팡 소싱 체크리스트 PDF

영상 고정댓글 리드매그넷. 항목은 5개 필터만 넣는다.

```txt
검색어 / 판매 흔적 / 리뷰 장벽 / 가격·배송 / 브랜드·KC·지재권
```

### 2) 엑셀 템플릿

불사자 없이도 따라 할 수 있게 기본 엑셀을 제공한다.

필수 컬럼:

```txt
수집일, 검색어, 순위, 상품명, 가격, 리뷰수, 판매흔적, 로켓/일반, 브랜드 리스크, 인증 리스크, 상품 URL, 메모
```

### 3) 쇼츠 3개 파생

- `잘 팔리는 상품 찾다가 망하는 이유`
- `쿠팡 소싱할 때 리뷰 수만 보면 안 됩니다`
- `브랜드 로고 있는 상품, 초보는 먼저 거르세요`

### 4) 카러셀 1개

제목:

```txt
쿠팡 소싱 전 5개만 체크하세요
```

슬라이드:

1. 아무거나 소싱하면 망합니다
2. 검색어가 너무 넓은가
3. 판매 흔적이 있는가
4. 리뷰 장벽이 높은가
5. 가격·배송을 버틸 수 있는가
6. 브랜드/KC/지재권 리스크가 있는가
7. 손으로 하면 오래 걸립니다
8. 수집함으로 비교하세요
9. 체크리스트 받기 CTA

### 5) 불사자 기능명 정리

영상에서 처음부터 불사자를 전면에 박지 않는다. 후반부 기능명은 아래처럼 쉽게 말한다.

| 기능명 | 영상 표현 |
|---|---|
| 쿠팡 스카우터 | 쿠팡 상품 지표를 한눈에 보는 기능 |
| 소싱 수집함 | 괜찮은 후보를 담아두는 장바구니 |
| 엑셀 다운로드 | 후보 상품을 같은 기준으로 비교하는 파일 |
| 리뷰 분석 | 고객이 뭘 불평하고 뭘 좋아하는지 보는 기능 |
| AI 상품명 | 마켓별 검색 구조에 맞게 상품명을 정리하는 기능 |

### 6) 촬영 전 실제 데모 1개만 준비

완성도 높은 영상에는 상품 예시가 하나 필요하다. 추천 예시:

```txt
접이식 캠핑의자 / 무타공 욕실 선반 / 차량용 햇빛가리개 / 주방 싱크대 정리대
```

조건:

- 너무 유명한 브랜드 상품 금지
- KC/전기/유아/의료처럼 인증 복잡한 카테고리 금지
- 리뷰 괴물만 있는 키워드 금지
- 세부 키워드로 좁히기 쉬운 상품 우선
