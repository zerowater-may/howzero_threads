# 인테리어 업체 선정 자료

봉천동 두산아파트 59A(24평형) · 전체 리모델링 + 발코니 2개소 확장 + 시스템에어컨 4대 + 샷시 전체교체 · 2026년 9월 공사 예정.

## 결과물

- **`인테리어_업체선정_playground.html`** — 인터랙티브 explorer (예산·우선순위 슬라이더→업체 순위 실시간 / 홈루덴스 상담요약 / 미팅 체크리스트 / 메모 복사). 단일 HTML, 더블클릭 실행
- **`통화_전사/홈루덴스_방문상담록.md`** + **`.pdf`** — 홈루덴스 방문상담(6/13, 2시간) 화자구분·교정 대화록 (md / PDF 18p)
- **`통화_전사/홈루덴스_방문상담_요약.md`** + **`.pdf`** — 1페이지 핵심 요약본 (개요·공간별 결정·견적·조언·다음 액션)
- **`인테리어_업체비교.xlsx`** — 파스텔톤 7시트 비교표
  1. **업체비교** — 4곳 한눈에 (총액·평당가·A/S·창호·가구방식·강점/약점)
  2. **항목별견적** — 리바트 vs 한샘 정규화 비교 (검산: 합계 일치)
  3. **선정체크리스트** — 계약 전 확인 24항목 + 업체별 현황 + 내 확인란
  4. **상담녹취요약** — 아파트멘터리 / 퍼스트에비뉴 / 홈루덴스 전화 핵심
  5. **한샘가견적상세** — 한샘 가견적 6장을 카테고리별 하위 항목으로 펼침 (단가·수량·시공비·소계 검산 일치, 7340만 품명 온전)
  6. **업체미팅_질문리스트** — 업체 가서 그대로 읽고 물어볼 실전 멘트 29개 (6단계, 우리집 맞춤 ⭐ 7개). 출처: `참고자료/성공적인_인테리어_공사_안내서.pdf`
  7. **홈루덴스_방문상담** — 6/13 방문상담(2시간) 공간별 결정·제안 + 디자이너 핵심 조언 (집진단/현관/주방/거실/방/욕실/마감재/견적·일정 + ⭐조언 5)
