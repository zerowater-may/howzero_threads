# BraveYong 랜딩페이지 검수용 수정안 템플릿

> 검수 대상: `http://localhost:3200`
> 목적: 사람이 실제 페이지를 보면서 문구, 사실 정보, 톤, 구조, 디자인 수정 의견을 섹션 단위로 전달하기 위한 템플릿.

## 작성 방법

수정 의견은 가능하면 아래 형식으로 적어주세요.

```md
### 섹션명
- 위치:
- 현재 문장/요소:
- 문제:
- 원하는 느낌:
- 수정안:
- 우선순위: 필수 / 권장 / 선택
```

문장을 직접 쓰기 어렵다면 `수정안`은 비워도 됩니다. 대신 `문제`와 `원하는 느낌`을 구체적으로 적어주세요.

날짜, 가격, 장소, 인원, 결제, 혜택, 환불, 수익 숫자처럼 사실 확인이 필요한 정보는 정확한 값으로 적어주세요.
