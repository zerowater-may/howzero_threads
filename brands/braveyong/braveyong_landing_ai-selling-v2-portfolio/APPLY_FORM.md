# 용감한 용팀장 1기 신청서 — Google Form 복붙용

> 작성 소요 시간 ≈ **1분** (8문항, 객관식 위주)
> **원칙**: 신청서 = 결제의 유일한 시작점. 신청서 작성하면 **결제 링크가 즉시 발송**. 결제만 따로 받는 페이지 없음.

## 폼 응답 후 메시지 (확인 메시지) ⭐ 중요

> Google Form → 설정 ⚙ → 응답 → **응답 후 메시지** 영역에 아래 내용 복붙

```

📩 결제 링크 (지금 바로 진행하실 수 있어요)
→ [여기에 실제 결제 페이지 URL 또는 토스/카카오페이 결제 링크 붙여넣기]

🙋 용팀장 1:1 카톡으로 확인 메시지도 드려요
1~2일 내 카톡으로 한 번 더 확인 인사드릴게요.
https://open.kakao.com/o/srD2ziBe

분위기 먼저 보고 싶으시면 단톡방 →
https://open.kakao.com/o/gcjQ8Hpi

— 용감한 용팀장 드림
```

> ⚠️ 결제 페이지 URL 준비 안 됐으면 일단 `https://open.kakao.com/o/srD2ziBe` (용팀장 1:1 카톡)로 두고, 1:1에서 결제 링크 직접 발송하세요.

## Google Form 설정 (오른쪽 톱니바퀴 ⚙)

| 항목 | 설정 |
|---|---|
| 응답 수집 → 응답 1회 제한 | **켜기** (중복 신청 방지) |
| 응답 수집 → 이메일 주소 수집 | **켜기** + 응답자에게 사본 발송 |
| 프레젠테이션 → 진행률 표시줄 | **켜기** (이탈률 감소) |
| 프레젠테이션 → 응답 후 메시지 | 위 ⭐ 내용 복붙 |
| 응답 알림 | 응답 → 알림 받기 (이메일) |

---

## 페이지 연결 (운영자 작업)

```
NEXT_PUBLIC_GOOGLE_FORM_URL=https://docs.google.com/forms/d/[폼ID]/viewform
NEXT_PUBLIC_PAYMENT_URL=https://[실제 결제 페이지 URL]  ← 토스/카카오페이/스트라이프 결제 link 만들고 주입
```

`NEXT_PUBLIC_PAYMENT_URL` 미설정 시 → 자동으로 `kakao1to1Url`로 fallback (1:1 카톡 경로).
