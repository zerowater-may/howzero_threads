## Google Form 설정 (오른쪽 톱니바퀴 ⚙)

| 항목 | 설정 |
|---|---|
| 응답 수집 → 응답 1회 제한 | **켜기** (중복 신청 방지) |
| 응답 수집 → 이메일 주소 수집 | **켜기** + 응답자에게 사본 발송 |
| 프레젠테이션 → 진행률 표시줄 | **켜기** (이탈률 감소) |
| 프레젠테이션 → 질문 순서 무작위 | **끄기** |
| 응답 알림 | 응답 → 알림 받기 (이메일) |

## 페이지 연결 (운영자 작업)

폼 URL 복사 → Vercel Dashboard:

```
1. Vercel → 프로젝트 → Settings → Environment Variables
2. Key: NEXT_PUBLIC_GOOGLE_FORM_URL
   Value: https://docs.google.com/forms/d/[폼ID]/viewform
   Environment: Production / Preview / Development 모두 체크
3. Save
4. 재배포 (vercel deploy --prod)
```

→ 페이지의 모든 "신청서 작성하기" CTA가 자동으로 폼 URL로 연결됨.
