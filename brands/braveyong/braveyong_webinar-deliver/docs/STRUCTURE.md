## 한 줄 구조

```txt
권위 선점 → 고통 공감(참여 유도) → 가능성 각성(사례) → 진짜 노하우 시연(본론) →
영웅 서사(인간화) → 사회적 증거 폭격(라이브 인터뷰) → "Q&A"를 빙자한 세일즈 → 좌석 카운트다운 클로징
```

레퍼런스 이미지(2단 레이어)와 같은 골격:
- **순차 레이어**: 자기소개 → 왜 이 강의 → 본론 → (즙파트=본론 핵심 20분) → 수강생 자랑(영상) → 고조 라이브 → 세일즈 → Q&A
- **감정 레이어**: 공감 → 고조 → 확신 → 세일즈 → 만족(Q&A 만족감)

## 후크/미끼 (끝까지 보게 만드는 장치, 최소 5회)

1. (도입) "끝까지 들어주시는 분들에게 전자책 **광고편**까지 준비했습니다."
2. (소통 미끼) "소통 잘해주시는 세 분께 직접 자택으로 택배를 보내드리겠습니다."
3. (**상위노출 떡밥** — 가장 강력) "Q&A에서 상위노출 질문 주시면… 500만 원, 700만 원짜리 강의 내용이에요." → Q&A에서 "가구매 50개×6,000원×30일=900만 원"으로 회수.
4. (선물 4종) "끝까지 시청하시는 분들을 위한 네 가지 선물을 준비했죠."
5. (스토어 공개) "호응이 좋다면 제 스토어까지 공개하겠습니다."

→ **본론 중반에 떡밥을 깔고, 후반(Q&A)에서 회수**하는 구조가 이탈 방지의 핵심.

## 신뢰·권위 증거 배치 (3겹)

1. **권위 (도입 직후 5~9%)** — 월매출 1.7억, 구독자 4.6만, 경희대 겸임교수, 쿠팡 본사 미팅.
2. **약점/고생담 (중반 45~55%)** — 빚 1억, 경찰서, 30만 원 옥탑방 → 권위를 **인간화**해 신뢰의 결을 다르게.
3. **수강생 증거 (세일즈 직전 55~72%)** — 텍스트 후기(160/400/600/1100만) → **실명 라이브 인터뷰**(대전 50대)로 클라이맥스. 페르소나별(4050/육아맘/건강/요리사/대기업 퇴사) 배치로 청중 자기투영 유도.

## 본론(무료로 주는 진짜 정보) — 깊이 있는 맛보기

"무엇·왜"는 충분히 주고 "어떻게(완성 시스템)"는 유료 게이팅.

- **소싱 필터링**: 불사자에서 비브랜드+쇼핑성+시장 1억↑+검색제안 10만 → 핵심은 **로켓 비율 낮은 틈새 키워드**(테이블톱 2.3억인데 로켓 1명 등).
- **차별화 소구**: 안대→비염 찜질안대, 빨간 소화기→스테인리스, 저울→강화유리, 보풀제거기 머리 2개.
- **판매가 설정**: "다른 고객이 함께 본 상품"(무광고 영역)=쿠팡이 밀어주는 가격대 + 리뷰 4.8↑ → 27,500원 산출.
- **AI 상세페이지**: 크레이지로 핵심 키워드 입력 → AI 생성 시연.
- **게이팅(유료)**: 전환율 분석법, 상세페이지 프롬프트(A4 36장), 체크리스트 300개, KC 인증 30만 원 노하우.

## 잘된 이유 — 설득 기법 7가지

1. **적(敵) 설정** — "많이 올리고 기도하는 유튜버", "쿠팡만 버는 광고", "무자본·쇼츠 거짓말"을 깎아 본인을 유일 정답으로.
2. **고통 구체화 + 자기개방 참여** — 채팅에 간절한 이유 쓰게 해 몰입+손실회피.
3. **소액 vs 거액 리프레이밍** — "1,000원×100개"가 아니라 "3만 원×하루 하나", "치킨값", "학원비보다 싼 월 25만".
4. **데이터·오픈북 프레임** — "감이 아니라 데이터", "온라인은 다 보인다"로 객관성 외피.
5. **사회적 증거 계단** — 텍스트 후기 → 실명 라이브 인터뷰 → "어제 올라온 후기"까지 신선도 다양화.
6. **리스크 리버설 + 희소성 + 긴급성 3종 동시 가동**.
7. **반론 선제·실시간 처리** — "노가다 아닌가?", "초보 가능?", "돈 많이 드나?", "연락 안 된다던데?"를 먼저 입에 올려 분쇄 + 컨디션 카드("몸살인데도 이 열정")로 헌신 어필.
