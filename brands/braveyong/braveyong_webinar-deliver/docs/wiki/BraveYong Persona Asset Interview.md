# BraveYong Persona Asset Interview

## Role

This page turns the 2026-05-24 용팀장님 interview transcript into a reusable persona asset. It is not a raw transcript. It extracts scenes, proof angles, language patterns, and copy rules for BraveYong scripts and landing pages.

Source asset: `brands/braveyong/braveyong_misc_persona-interview-family-seo-seller.md`.

## Core Takeaway

용팀장의 강한 점은 "돈 많이 버는 셀러"보다 "직장, 육아, 자산 형성, 현금흐름, 상품 SEO를 모두 현실 안에서 말하는 셀러"라는 점이다.

이 asset은 BraveYong을 아래처럼 더 선명하게 만든다.

```txt
직장 월급의 한계
-> 현금흐름 필요
-> 구매대행/온라인 셀링 진입
-> 대량등록 한계 체감
-> 상품명/SEO/효자상품 구조로 전환
-> 레버리지와 직원 운영
-> 가족 시간을 지키는 시스템
-> 강의보다 지속 스터디와 실행
```

## Strongest Messages

1. 온라인 셀링은 쉬운 돈벌이가 아니지만, 제대로 배우면 현금흐름이 될 수 있다.
2. 상품 수가 많다고 이기는 시대가 아니라, 검색될 구조를 갖춘 효자상품을 만들어야 한다.
3. 네이버 SEO와 상품명은 공식 한 줄로 끝나는 게 아니라 실제 순위 체크로 검증해야 한다.
4. AI는 딸깍 자동화가 아니라, 용팀장식 판단 로직을 반복 가능하게 만드는 시스템이다.
5. 강의 한 번 듣고 끝나는 사람이 아니라, 계속 공부하고 수정하는 사람이 남는다.
6. 부업이라면 가족 시간을 해치지 않는 시스템까지 같이 만들어야 한다.

## Copy Seeds

- "상품을 1000개 올리는 것보다, 검색되는 상품 10개를 만드는 게 먼저입니다."
- "직장인 부업은 하루 종일 붙잡고 할 수 없습니다. 그래서 처음부터 시스템이 필요합니다."
- "AI가 돈을 벌어주는 게 아닙니다. 내가 하던 판단을 더 빠르게 반복하게 만드는 겁니다."
- "상위노출을 말로 믿지 말고, 키워드별 순위로 확인해야 합니다."
- "저는 쉽게 돈 번다는 강의를 만들고 싶지 않습니다. 대신 시행착오를 줄이는 구조를 같이 만들 겁니다."
- "강의는 6주지만, 진짜 가치는 그 뒤에 같이 업데이트하는 스터디에 있습니다."

## Landing Application

### Hero

Use the life-first credibility angle:

```txt
직장인, 육아아빠, 현업셀러.
대량등록이 아니라 효자상품 10개를 같이 만드는 6주 오프라인 실전반.
```

### Trust

Prefer scene-based proof over big numbers:

- 아이 등원 후 사무실로 가는 생활 장면
- 직접 상품명을 고치고 순위를 보는 화면
- 직원과 시스템으로 CS를 분리하는 운영 방식
- 월 1회 스터디로 계속 업데이트하는 구조

### Pricing Defense

The page should defend the price through hands-on work, not income promises:

```txt
이건 녹화강의가 아닙니다.
6주 동안 내 상품을 같이 보고, 용팀장 기준으로 효자상품 10개를 완성하는 실전반입니다.
```

## Script Application

Use this structure for long-form scripts based on the asset:

```txt
가족/직장인 현실 공감
-> 월급과 현금흐름 문제
-> 온라인 셀링 진입 이유
-> 대량등록과 강의 쇼핑의 한계
-> 상품명/SEO/효자상품 관점
-> 실제 장면 또는 시연
-> 오늘 할 일
-> 단톡방/무료강의/오프라인 실전반 CTA
```
