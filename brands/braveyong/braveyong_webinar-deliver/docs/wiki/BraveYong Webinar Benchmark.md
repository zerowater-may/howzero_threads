### 핵심 골격 (순차 + 감정 2단 레이어)

```txt
권위 선점 → 고통 공감(채팅 참여) → 가능성 각성(사례) → 진짜 노하우 시연(본론) →
영웅 서사(인간화) → 사회적 증거 폭격(라이브 인터뷰) → "Q&A"를 빙자한 세일즈 → 좌석 카운트다운 클로징

감정: 공감 → 고조 → 확신 → 세일즈 → 만족
```

### 벤치마킹 핵심 5가지

1. **권위→인간화→사회적 증거 3겹** — 도입에 권위(매출/교수), 중반에 약점(빚 1억)으로 인간화, 세일즈 직전에 수강생 실명 라이브 인터뷰로 피크.
2. **참여형 고통 공감** — "간절한 이유를 채팅에 써보세요"로 청중이 스스로 감정을 꺼내게 함.
3. **오픈북 데이터 실연** — 추상 노하우를 화면 공유로 직접 증명("온라인은 다 보인다").
4. **본론을 진짜로 준다** — "무엇·왜"는 따라 할 수준으로 주고, "어떻게(완성 시스템)"만 유료 게이팅.
5. **떡밥-회수 구조** — 본론 중반에 "뒤에서 알려준다" 떡밥을 깔고 Q&A에서 회수해 끝까지 잡아둠.

### ⚠️ 용팀장 변환 톤 가드 (베끼면 안 되는 것)

- ❌ 상위노출 보장 떡밥(가구매 산식 등) — 어뷰징/정책 위반. 사용 금지.
- ⚠️ 전액 환불·순수익 보장 → 성과 보장 금지선. "실행 지원" 톤으로 순화.
- ⚠️ 좌석 카운트다운 허위 긴급성 → "신청서 보고 한 분씩 안내" 톤 유지.
