# braveyong_script

용감한 용팀장 롱폼 강의/유튜브 대본을 보관하는 폴더.

## 파일 규칙

- `Y-001-*.md` — 롱폼 강의 대본 원본
- `Y-001-*-READ.md` — 촬영/낭독용 정리본
- `Y-001-*-DESIGN.md` — 슬라이드, 강의 보드, 썸네일 제작용 구조

## 작성 기준

- 핵심 축은 글로벌 위탁판매, 구매대행, 스마트스토어, 쿠팡 셀러, 네이버 SEO, 상세페이지, AI 셀링이다.
- 대본은 `문제 진단 -> 원인 -> 기존 방식의 한계 -> 용팀장식 해결 -> 실전 순서 -> CTA` 흐름을 기본값으로 쓴다.
- 수익, 부동산, 경력, 공개 성과 소재는 사용 전 본인 확인 또는 공개자료 검증이 필요하다.
