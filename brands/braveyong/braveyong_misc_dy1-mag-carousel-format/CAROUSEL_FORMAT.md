# dy1.mag 캐러셀 디자인 포맷

## 한 줄 정의

`다큐 사진 + 백지 여백 + 굵은 산세리프 문장 + 한 줄 밑줄 강조`로 B2B 스토리를 신뢰감 있게 전달하는 매거진형 캐러셀.

## 핵심 DNA

- 사이즈: 1080x1350, 4:5.
- 톤: 스타트업/창업자 매거진, 담백하지만 단정함.
- 구성: 큰 사진 1장, 짧은 본문 3-6줄, 핵심 문장 1줄 굵게 밑줄.
- 배경: 대부분 순백색 또는 아주 옅은 웜화이트.
- 강조: 색상보다 굵기와 밑줄로 강조.
- 장식: 거의 없음. 하단 우측에 작은 검정 페이지 마커만 반복.
- 사진: 현장 사진, 인터뷰 캡처, 제품 사진. 스톡처럼 예쁜 사진보다 실제 기록 느낌.

## 레이아웃 규칙

### 공통 바디 슬라이드

- 캔버스: 1080x1350.
- 좌우 여백: 88-96px.
- 상단 여백: 170-230px. 단, 이미지가 큰 장은 0-80px까지 올림.
- 이미지 영역:
  - 기본 폭: 840-900px.
  - 위치: 상단 중앙.
  - 테두리: 2-3px 검정.
  - 그림자 없음.
- 본문 영역:
  - 이미지 아래 26-54px 간격.
  - 가운데 정렬.
  - 한 문단은 1-2줄.
  - 전체 본문은 3-6줄 안에 끝냄.
- 강조 문장:
  - `font-weight: 900`.
  - `text-decoration: underline`.
  - 밑줄 두께 2-3px, underline offset 6-8px.
- 페이지 마커:
  - 하단 우측.
  - 48x8px 또는 58x10px 검정 막대.
  - 숫자보다 시각적 진행 표시 역할.

### 커버 슬라이드

- 사진: 풀블리드 또는 거의 풀블리드.
- 인물: 중앙 또는 중앙 약간 위.
- 배경: 브랜드 로고/상징을 크게 깔아도 됨.
- 하단 그라데이션: 검정 65-85% 투명도.
- 제목:
  - 하단 좌측 정렬.
  - 72-86px.
  - 2줄 권장.
  - 흰색, 굵게.
- 브랜드명:
  - 하단 중앙.
  - 32-42px.
  - 흰색.

### 블랙 CTA 슬라이드

- 배경: #000000.
- 텍스트: 중앙 정렬.
- 메인 강조: 흰색 + 브랜드 컬러 1개.
- 문장 수: 4-6줄.
- URL/CTA: 마지막 줄에 작게.

## 슬라이드 아키타입

1. 커버: 인물 풀블리드 + 큰 제목.
2. 출처 캡처: 영상 캡처 상단 + 짧은 설명.
3. 사건 전환: 현장 사진 + 굵은 선언 문장.
4. 문제 제기: 이미지 + 숫자/비교 문장.
5. 해결책: 제품/서비스 사진 + 한 줄 결론.
6. 사용 장면: 큰 이미지 + 작은 inset 이미지.
7. 설계/제품 증거: 제품 렌더나 분해도 + 짧은 설명.
8. 검증/성과: 현장 회의 사진 + 숫자 중심 문장.
9. CTA: 검정 배경 + 짧은 모집/행동 문장.
10. 신뢰 마감: 로고/파트너/투자사 + 한 줄 요약.

## BraveYong 적용법

이 포맷을 BraveYong 구매대행 콘텐츠에 적용할 때:

- 커버는 유튜브 캡처나 대표 얼굴을 크게 쓰고, 하단에 2줄 훅만 둔다.
- 본문은 설명형 카드보다 `캡처 1장 + 문장 3줄`로 간다.
- 문장은 너무 깊게 풀지 않는다. 한 장에 하나만 말한다.
- 강조 문장은 밑줄로 처리한다. 빨강 박스, 큰 말풍선, 복잡한 도식은 쓰지 않는다.
- 출처가 필요한 장면은 이미지 바로 아래 20-22px로 작게 둔다.
- 마지막 장은 긴 CTA보다 `오늘 하나만 해보기` 같은 짧은 행동으로 닫는다.

## 카피 구조

좋은 패턴:

```text
[일반 문장]
[짧은 배경 설명]
[굵은 밑줄 핵심 문장]
```

예시:

```text
다들 돈 많아야 시작하는 줄 압니다.
근데 처음엔 상품 하나만 봐도 됩니다.
처음부터 크게 질러볼 필요가 없습니다.
```

피해야 할 패턴:

- 한 장에 3개 이상 개념 설명.
- 표/도식/아이콘 과다 사용.
- 색상 강조를 여러 개 섞기.
- 장문 리스트.
- 성과 보장처럼 보이는 문장.
