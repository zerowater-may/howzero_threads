# braveyong_carousel_raw

용감한 용팀장 카러셀 raw 텍스트를 보관하는 폴더.

## 파일 규칙

- `YC-001-*.md` — 카러셀 원고
- `YC-001-*-caption.md` — 카러셀용 캡션 초안

## 작성 기준

- 첫 장은 `이거 안 하면 손해`, `상품 탓 아님`, `SEO 먼저`, `AI 상세페이지 함정`처럼 멈추는 문장으로 시작한다.
- 중간 장은 문제를 과장하지 않고 상품명, 카테고리, 키워드, 상세페이지 흐름으로 원인을 쪼갠다.
- 마지막 장은 오늘 바로 확인할 체크리스트와 단톡방/무료자료 CTA로 닫는다.
