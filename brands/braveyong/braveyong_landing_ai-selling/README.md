## 디자인 방향

- 톤: 현업 실전·신뢰형 (토스/노션 깔끔 + **사람이 직접 적은 손글씨 메모**)
- 컬러: 워밍 페이퍼(#FAF8F3) + 잉크 + 단일 신뢰 블루(#2257E8), 1기 특별가만 앰버 강조, 형광펜은 따뜻한 노란
- 폰트: 본문 Pretendard Variable + **손글씨 액센트 Nanum Pen Script + Gowun Dodum** (Google Fonts) + 데이터 영역 모노스페이스
- 콘셉트(개정): **"사람이 만든 흔적"** — Hero 작업화면은 CSS mock 대신 *실사진 교체 placeholder*(빈 종이 + 카메라 + "교체 예정" 손글씨 배지)로 두고, 곳곳에 손글씨 메모·서명·형광펜·손그림 동그라미를 더해 AI 슬롭 느낌을 제거
- 가드 준수: 형광 그라데이션 ✕, 과장 카피 ✕, 카운트다운 압박 ✕, 매출 보장 ✕, AI가 대신 팔아준다 ✕
- subtle SVG noise 종이 질감 overlay(opacity .035)로 인쇄물 느낌

## 구조 (기획서 확장 15블록)

> 2026-05-22 개정: 오빵 일본 구매대행 펀딩 상세페이지 구조를 벤치마크해 신뢰 증거·반론 차단·비교표·소수정예 4블록을 추가(✚). **구조만 차용하고 과장·수익보장·마감압박 카피는 차용하지 않음.**

1. Hero — 작업화면 70~85% + 얼굴 15~30%, Hero 카피/CTA/서브약속
2. ✚ 신뢰 증거 — 현업 사실 지표 4개(운영 입력) + 1기 후기 자리(정직 placeholder)
3. 문제 제기 — 대량등록 한계 4가지
4. AI 셀링 정의 — 판매 운영 구조 + 반복 루프 mock
5. 핵심 결과물 — 효자상품 10개 (정의 7요소 + 제작방식 + 매출보장 아님 가드)
6. 6주 커리큘럼 — 오프라인 6 + 줌 5, 주차별 아코디언 (내용/산출물)
7. 운영 방식 — 5개 지표 + 일정/장소
8. 왜 용팀장인가 — 진정성 서사
9. 졸업 후 오프라인 스터디 (가격 바로 앞)
10. ✚ 반론 차단 — 자주 하는 망설임 4종, 사실로만 답
11. ✚ 비교표 — 일반 온라인 강의 vs 오프라인 실전반 6항목
12. 가격 — 1기 180 / 정가 250, 카피·방어·결제
13. ✚ 소수정예 한정 — 정직 희소성(인원·특별가·선별), 카운트다운 금지
14. 신청서 & 선별 — 주/보조 CTA, 신청서 11문항, 강한 문구
15. FAQ — 12문항 + 효자상품 답변 / 최종 CTA

## 운영자 입력 필요 (배포 전 교체)

페이지 내 `data-placeholder` 속성 / 주석으로 표시. 확정 전까지는 `추후 안내` / `참여 확정자에게 안내`로 노출된다.

| 항목 | 위치 | 방법 |
|---|---|---|
| 구글폼 실제 URL | Hero/신청서/최종 CTA의 `[data-cta]` 링크 | `index.html` 하단 `<script>`의 `GOOGLE_FORM_URL` 주석 해제 후 값 입력 → 모든 CTA 일괄 연결 |
| 유튜브 무료강의 URL | 보조 안내 | `<script>`의 `YOUTUBE_FREE_URL` |
| 오프라인 수업 시간 | 운영 방식 `시간` | `data-placeholder="오프라인 수업 시간"` |
| 상세 주소 | 운영 방식 `장소` | `data-placeholder="상세 주소"` |
| 카드 PG 링크 / 계좌이체 계좌 | 가격 섹션 | 결제는 확정자에게만 발송 (주석 표시) |
| 환불 기준 | FAQ Q12 | `data-placeholder="환불 기준"` |
| og:image | `<head>` | 실사 작업화면/커버 이미지로 교체 |
| 용팀장 사진 | Hero `.face` placeholder | 실사진으로 교체 (작게 유지) |
| 작업화면 사진 3종 | Hero `.photo-slot` × 3 | 실제 작업화면 스크린샷으로 교체 — 상품명·SEO 점검 / AI 상품 분석 / 상세페이지 기획·등록 전 체크. 교체 전까지는 "교체 예정" 손글씨 배지로 표시됨. |

## 검증

- Playwright 데스크톱(1280) / 모바일(390) 풀페이지 렌더 확인
- 콘솔 에러 없음 (favicon 404만 — 무해)
- FAQ/커리큘럼 네이티브 `<details>` 토글 동작 확인 (JS 없이도 동작)
- `.reveal` 등장 애니메이션은 JS 있을 때만 적용, no-JS/크롤러는 전체 콘텐츠 노출
- `word-break:keep-all`로 한글 단어 중간 줄바꿈 방지
- 손글씨 액센트: Hero 형광펜+sticky note, AI 정의 형광펜, 효자상품 동그라미, 왜 용팀장 서명, 가격 화살표 메모, 최종 CTA 서명 7곳에 데스크톱+모바일 element 캡처로 확인
