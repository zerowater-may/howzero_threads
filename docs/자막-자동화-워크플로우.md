# 자막 자동화 워크플로우 (Claude Code / Codex + Whisper)

> 출처 영상: https://youtu.be/z_a7D7C-0Tg (김요한자동화)
> 목표: 10분 영상 자막 작업 **2시간 → 5분**. MP3만 던지면 검수 필요 없는 자막 완성.

---

## 왜 이렇게 하나 (핵심 아이디어)

- Whisper/Vrew/CapCut 등 일반 자막 자동화는 오타·문장 길이·영어/숫자 발음·싱크 밀림이 많아 검수에만 1~2시간 걸림.
- 해결책: **Claude Code 또는 Codex + Whisper large-v3** 조합을 스킬로 한 번 세팅 → 이후 MP3 하나로 끝.
- Claude Code와 Codex는 **결과 차이 없음**. 둘 다 내부적으로 Whisper 모델을 사용. 구독 중인 플랫폼(Claude면 Claude Code, GPT면 Codex)을 쓰면 됨.

---

## 0. 사전 세팅 (최초 1회)

1. **Cursor 설치 & 회원가입/로그인**
   - Cursor 가입은 Claude/GPT 로그인과 **별개**. 설치 편의를 위해 Cursor를 껍데기로 사용.
2. **작업 폴더 생성** → Cursor에서 `파일 > 폴더 열기`로 그 폴더 열기.
3. Cursor 채팅에 `클로드 코드를 설치해줘` (또는 `코덱스를 설치해줘`) 입력 → 자동 설치.
   - Cursor를 쓰는 이유: 설치 과정을 AI에 맡길 수 있고, 무료 범위 내에서 커버됨.
4. **터미널 열기**: `터미널 > 새 터미널` → `claude` 또는 `codex` 입력해 실행 확인.
   - 오류 나면 오류 복사 → Cursor 채팅에 붙여넣고 `이런 오류가 났으니 해결해줘`.

---

## 1. 영상 준비 (음성만 추출)

- 컷편집이 끝난 상태 가정 (자막 작업만 다룸).
- **영상이 아니라 음성만 MP3로 추출** → 작업 폴더에 넣기.
  - AI는 화면을 못 봄. 소리로 STT(Speech-to-Text)만 하므로 음성만 주는 게 효율적.
- **대본이 있으면 반드시 같이 폴더에 넣기.** (가장 중요한 정확도 포인트)
  - 대본대로 정확히 말하지 않았어도 OK. AI가 문맥을 이해하는 데 도움 → 훨씬 정확.

---

## 2. 단계별 프롬프트 (코덱스/클로드 코드 공통)

전체 프로세스를 이해하면 자기 자막 스타일에 맞게 응용 가능. (마지막에 스킬로 묶음)

### 2-1. 초벌 STT — 최대한 잘게 쪼개기

```
Whisper large-v3 모델을 사용해서 가능한 가장 작은 단위로 쪼개 STT를 해줘. SRT 파일로 만들어줘.
```

- **왜 잘게?** 나중에 원하는 문장 길이로 합칠 때, 정확한 타임스탬프가 있어야 음성과 싱크가 딱 맞음.
- 처음부터 크게 잡으면 문장을 자를 때 AI가 타임스탬프를 임의로 만들어 **싱크가 밀림**.
- → "처음엔 잘게, 붙일 때 정확한 시간대 문장이 들어간다"

### 2-2. 오타·고유명사·영어/숫자 교정 (★ 핵심 단계)

대본 파일을 `@`로 멘션하면서:

```
@대본파일 을 보면서 현재 STT된 문장들을 문맥에 맞게 수정해줘.
STT가 잘 안 돼 오타가 있거나 영어·숫자·고유명사가 있는 경우 대본을 보며 문맥을 살펴줘.
대본을 그대로 베끼는 게 아니라 전체적인 문맥을 살피는 것이 중요해.
```

- STT는 들리는 대로 받아쓰기라 고유명사/영어/숫자가 자주 틀림. (예: 이름·브랜드명)
- 대본을 문맥 참고용으로 주면 잘못 전사된 단어를 전부 교정. **이 과정이 정확도의 핵심.**

### 2-3. 문장 길이 편집 (롱폼용)

```
현재 만들어진 자막을 롱폼 영상용으로 다시 생성해줘.
하나의 큐(cue) 안에는 텍스트가 반드시 한 줄만 있어야 하고 줄바꿈으로 만들면 안 돼.
문장을 나눠야 하면 새로운 큐와 새로운 타임스탬프로 분리해.
한 줄 길이는 18자~44자 정도를 기준으로 하되 의미가 자연스럽게 끊기는 것을 우선해.
```

- 너무 짧으면 쇼츠처럼 정신없고, 너무 길면 읽기 힘듦. → 롱폼 기준 **한 줄 18~44자**, 의미 단위로 끊기.
- **줄바꿈 금지**가 포인트: 그냥 길이만 지정하면 AI가 2~3줄로 줄바꿈해 버림.
  - "한 자막은 한 줄. 나누고 싶으면 새 타임스탬프의 새 자막으로 만들어라"고 명시.
- **예시를 같이 넣기** — 말로만 설명하는 것보다 예시가 훨씬 정확하게 전달됨.

### 2-4. 공백 구간 채우기 (자막 깜빡임 제거)

```
앞 자막이 끝나는 시간을 다음 자막 시작 시간까지 늘려줘.
시작 시간은 건드리면 안 되고 앞 자막의 종료 시간만 늘려줘.
기존 파일은 쓰지 말고, 파일명 뒤에 공백 내용을 붙인 새로운 SRT 파일로 만들어줘.
```

- 문장 사이 숨 쉬는/멈추는 구간에 자막이 잠깐 사라짐 → 롱폼에서는 정신없음.
- **포인트**: 자막끼리 겹치면 안 되므로 **시작 시간은 유지, 앞 자막 종료 시간만 늘림**.
- 새 SRT 파일로 만드는 이유: 어떤 파일인지 헷갈리지 않게.

---

## 3. 편집툴에서 확인

- AI가 만든 최종 SRT를 편집툴(프리미어/캡컷 등)에 import → 검수.
- 교정 단계(2-2)를 거치면 **검수할 게 거의 없음**. 원하는 자막 스타일만 입히면 끝.

---

## 4. 스킬로 저장 (재사용)

매번 처음부터 하기 귀찮으니 한 번 완성하면 스킬로 저장:

```
지금까지 우리가 사용한 모든 과정을 재사용 가능한 스킬로 제작해줘.
```

- AI가 스킬 이름과 사용 방법까지 정리해줌.
- **다음부터는 한 줄이면 끝:**

```
자막 스킬을 이용해 우리의 원본 MP3 파일로 자막 SRT 파일을 만들어줘.
```

---

## 5. 권한 창 무시 (작업 멈춤 방지)

작업 중 허용(permission) 창이 떠서 멈추는 경우가 잦음 → 자동 허용 모드로:

- **Claude Code**: 터미널에서 `Shift + Tab` → 오토 모드(auto-accept)로 전환.
- **Codex**: `/permissions` 입력 → 허용 모드로 변경.

---

## 한눈에 보는 순서

```
1. Cursor 설치 → claude/codex 설치 → 터미널 실행            (최초 1회)
2. MP3 추출 + 대본 파일 → 작업 폴더에 넣기
3. STT 잘게 쪼개 SRT 생성        (Whisper large-v3)
4. 대본 기반 오타/고유명사 교정   (★ 핵심)
5. 롱폼용 문장 길이 편집          (18~44자, 줄바꿈 금지, 새 큐로 분리)
6. 공백 구간 채우기              (앞 자막 종료시간만 연장, 새 SRT)
7. 편집툴 import → 스타일 입히기
8. 전 과정을 스킬로 저장 → 다음부턴 한 줄로 끝
```

> 운영 팁: 컷편집 → MP3 추출 → AI에 자막 맡겨두고, 그 시간에 BGM·썸네일·B롤 작업 병행.
