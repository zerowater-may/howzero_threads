## 2. AI팀(알파브라더스) 심층 분석

우리가 포지셔닝·사례집·GTM을 가장 직접 벤치마킹할 레퍼런스.

### 운영 주체
- 운영사는 투자·액셀러레이팅사 **알파브라더스**(사이트 푸터 `ⓒ 2018. Alpha Brothers`). alphabrothers.co.kr/business에서 AI팀(ai-team.kr)을 **자사 프로젝트로 링크**한다. 즉 AI팀은 독립 에이전시가 아니라 액셀러레이터가 굴리는 AX 컨설팅 프로젝트.

### 사이트 구조 (4구조)
슬로건 **'AI팀과 업무생산성 10X하세요'** + 서비스 브랜드 **'AX컨설팅'**. 콘텐츠는 4개 축으로 구성:

1. **교육** — 실무 AI 교육
2. **컨설팅** — 기업 맞춤 AX 컨설팅
3. **용역** — 실행 대행
4. **AX 사례집** — 콘텐츠 마케팅 핵심 자산

### 서비스 플로우
`문제정의 → AX설계 → 실행 → 성과측정 → 유지보수` — 국내외 AX 에이전시의 사실상 표준 플로우(우리도 동일 뼈대). 차별화는 플로우가 아니라 **사례집의 정량 수치**와 **도메인 깊이**에서 난다.

### CTA
가격 전면 비공개. 최종 전환은 **1:1 전문가 상담 → 견적**. 사이트 전체가 "사례집으로 신뢰 → 상담 신청"의 단일 퍼널.

### 마케팅 채널
- **사례집(콘텐츠 마케팅)** 중심 홈페이지
- 인스타그램·스레드 **@ai.team_official**
- 전화/이메일 상담
- 서울·부산·일본·싱가포르 지사 표기(글로벌 신뢰 신호)

### ⚠️ 미확인 (원출처에서 확인 실패 → 인용 금지)
- **'100명+ 전문가 조직'**: 홈페이지·확인 페이지에서 해당 문구를 찾지 못함. 하위 페이지에 있을 가능성은 있으나 근거 없음.
- **'글로벌 트렌드 리서치 94% 단축'**: 사례 페이지(idx=171281001)·홈페이지 어디에도 이 수치가 없음. 해당 페이지는 반복업무 자동화의 일반 개념·부서별 예시만 다룸. AX 사례집 목록에서 **유일하게 확인되는 수치성 표현은 '마케팅 핵심 업무 6시간→5분' 제목뿐**. 디자인·영업지원·CS 등 분야별 정량 성과는 근거 없음. → 경쟁사 소구를 언급할 땐 '6시간→5분'만 사실로 인용하고, '94%'는 쓰지 않는다.

### 벤치마크 시사점
AI팀 모델(**사례집 → AX 컨설팅 → 맞춤툴**)이 우리 GTM의 직접 벤치마크. 단, 그들의 사례집이 실제로는 정량 수치가 얇다(‘6시간→5분' 제목 수준)는 것이 **우리가 이길 지점** — 이커머스 셀러 실전 운영(bulsaja/braveyong)의 진짜 before/after 수치를 사례집 전면에 깔면 범용 AX 컨설팅 대비 신뢰 우위.

## 3. 채널별 경쟁사 마케팅 방식

### 3-1. 홈페이지 (리드젠 퍼널)
국내 AX 컨설팅의 **공통 승리공식**:
> 무료 진단/자가진단 리드마그넷 → 성과 %(시간·비용) 사례집 → 상담 견적

- **AX-Consulting**: 무료 1시간 진단 → 맞춤 솔루션·ROI 리포트. 프로젝트 50+·평균 비용절감 47%·월 80h 절감·노쇼율 40%↓·처리시간 70%↓를 헤더/케이스에 노출(전부 자사 랜딩 자기보고 수치, 제3자 검증 없음).
- **AX PARTNER**: 15문항·60점 만점·약 2분 **무료 자가진단** + 상담폼. '거대 자체 모델·무거운 서버 구축은 부담' vs '검증된 도구를 스마트하게 조합' 경량화 카피. 푸터에 '정부지원사업 지원'.
- **넥스트젠AI**: 무료 AX 진단 리포트 리드젠 + '도입보다 정착' 메시지.
- 공통: **가격은 비공개**, 전환은 상담. → 우리가 프로덕타이즈드 공개 가격을 걸면 즉시 차별화 포인트(§4).

### 3-2. 인스타그램 / 스레드
- **AI팀** @ai.team_official — 사례집 배포 채널.
- **레비오사 AI** — 풀 멀티채널(IG·유튜브·틱톡·링크드인·X + 네이버블로그 + 카톡/디스코드). 이커머스 셀러 자동화 SaaS로서 가장 공격적.
- **조코딩** — Threads @youtubejocoding로 AX 사고리더십 + '1인 창업가 프로젝트' 화제화.
- **프리랜서(크몽)** — 스레드/인스타 개인 브랜딩으로 저가 대행 유입.

### 3-3. 유튜브 (practitioner 롱폼)
국내는 **조코딩(68-72만)** 이 사실상 유일한 대형 AX 유튜브 → 팬덤을 대기업 B2B AX 수주로 전환. 나머지 국내 AX 컨설팅사는 유튜브 실습 빌드 콘텐츠를 거의 안 함(§4 빈자리).

**해외 벤치마크(구조가 검증됨)** — 지배적 퍼널:
> 무료 롱폼 유튜브 튜토리얼 + 무료 Skool 커뮤니티(리드마그넷) → 유료 코스/커뮤니티

- **Nate Herk** — 실습형 n8n/AI 에이전트. 강점은 **'step by step, no assumptions, no skipped steps'**(출처 원문 확인). 무료 유튜브 + 무료 Skool → 유료 'AI Automation Society Plus'($94/mo) 업셀(퍼널 확인됨).
- **Liam Ottley / Morningside AI** — 'AI Automation Agency(AAA)' 사업모델 교육. **niche selection·service packaging·pricing·client outreach scripts**를 전면에.
- **Nick Saraev / LeftClick / Maker School** — Make.com·n8n practitioner-first. 73시간+ 무료 튜토리얼을 미끼로 유료 Maker School($184/mo).
- **Jono Catliff** — 자기 회사를 먼저 자동화한 에이전시 오너 크리덴셜.

**두 개의 먹히는 프레이밍(확인됨):**
1. **practitioner 크리덴셜** — '나는 실제 에이전시를 운영한다 / 내 회사를 먼저 자동화했다'. (우리: bulsaja 연매출 10억 운영, 직원 업무 자동화 실전 = 강력한 크리덴셜)

## 4. 빈 자리 (경쟁사가 안 하는 것)

우리(반복업무 전반 AX — 진입 시장은 이커머스 셀러)가 파고들 5개 공백. 공백 1·3·5는 진입 시장(이커머스) 전술이고, 브랜드·메시지 자체는 업종 중립을 유지한다(`_research/decisions.md`).

1. **이커머스 셀러 도메인 특화 + 실전 운영 실적을 사례집 수치로 전면화**
   대부분이 범용 AX 컨설팅이고, 이커머스는 달파·레비오사 정도가 **제품(SaaS/에이전트) 중심**. '실제 셀러를 운영하며 만든 before/after 정량 사례집'은 비어 있다. bulsaja(연매출 10억)·braveyong(셀러 교육) 실전 실적이 곧 사례집.

2. **투명 공개 가격(프로덕타이즈드 패키지)**
   국내 AX 컨설팅은 거의 전부 '비공개 상담 견적'. 공개 과금은 레비오사(제품)뿐. **착수 오딧+빌드 → 리테이너 전환** 하이브리드를 공개 가격으로 걸면 진입장벽·신뢰 양쪽에서 즉시 차별화.

3. **유튜브 롱폼 practitioner 빌드 콘텐츠 (이커머스 니치)**
   국내는 조코딩 외에 AX 컨설팅사가 유튜브 실습 빌드를 거의 안 함. 해외에서 검증된 '무료 빌드 워크스루 → 커뮤니티 → 유료' 퍼널이 **국내 이커머스 셀러 니치에는 아무도 없다**. practitioner 크리덴셜 + 수익 프레이밍 그대로 이식 가능.

4. **창업가/셀러 대상 무료 니치 뉴스레터**
   국내 AX 컨설팅사 중 뉴스레터를 리드 자산으로 굴리는 곳이 없다. Ben's Bites류 '이커머스 셀러 자동화' 니치 뉴스레터는 공백. 니치 밀집 리스트 = B2B 전환 엔진.

5. **이커머스 특화 무료 워크플로우/템플릿 리드마그넷**
   n8n Korea가 GitHub 템플릿을 공유하는 정도이고, **상품등록·CS 자동응대·리포트 같은 이커머스 특화 n8n/자동화 템플릿을 무료로 뿌리는 곳은 없다**. 셀러가 바로 쓰는 무료 템플릿 → 커뮤니티/상담 유입은 검증된 리드마그넷 구조(해외 창작자 공통).
