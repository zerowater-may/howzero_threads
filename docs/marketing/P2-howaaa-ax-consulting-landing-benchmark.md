## 1. 결론

AI TEAM은 전반적인 AX 전환을 파는 페이지다.  
HOWAAA는 그 전체 시장을 그대로 따라가면 안 된다.

HOWAAA가 가져갈 포지션은 **마케팅 AX**다.  
콘텐츠, 리드 수집, SEO, 광고 리포팅, CRM 팔로업처럼 매출 파이프라인과 직접 연결되는 업무를 자동화하는 쪽으로 좁힌다.

AI TEAM 페이지에서 가져올 것은 디자인 복제가 아니라 **전환 설계의 뼈대**다.

가져올 요소는 5개다.

1. **단일 목적 페이지**: 마케팅 AX 오딧 신청 하나로 수렴
2. **현장성 있는 히어로**: 추상 그래픽보다 실제 업무 현장 이미지
3. **문제 진단 → 전략 → 실행 → 측정 → 운영**의 단계 구조
4. **마케팅 자동화 사례를 수치로 보여주는 케이스 카드**
5. **상단/중간/하단 반복 CTA**

그대로 따라 하면 안 되는 요소도 명확하다.

1. 히어로에서 결과 숫자가 약하다.
2. "100개 이상 분야"는 넓어 보이지만 하와의 차별점은 아니다.
3. 중요한 사례가 페이지 하단에 너무 늦게 나온다.
4. 일부 섹션은 여백이 과하고, 스크롤 애니메이션 의존도가 높아 핵심 문구가 흐리게 보인다.
5. CTA가 "상담 신청" 중심이라 전환 장벽이 높다. 하와는 "30분 무료 마케팅 AX 오딧"으로 낮춰야 한다.

HOWAAA는 **AI 도입 컨설팅**이나 **전사 AX 컨설팅**으로 보이면 약하다.  
**마케팅에서 새는 시간과 리드를 찾아 자동화하고, 매출 파이프라인이 쌓이게 만드는 실행 시스템**으로 보여야 한다.

## 2. AI TEAM 페이지 구조 분석

### 2.1 전체 흐름

Playwright로 추출한 페이지 흐름은 아래와 같다.

| 순서 | 섹션 | 핵심 메시지 | 역할 |
|---:|---|---|---|
| 1 | 헤더 | 교육 / 컨설팅 / 용역 / AX 사례집 / AX 전문가 상담 신청 | 탐색과 즉시 CTA |
| 2 | 히어로 | 실제 현장을 바꾸는 AI팀 컨설팅 | 서비스 정체성 제시 |
| 3 | 문제 제기 | 모든 기업에 같은 AX는 없습니다 | 맞춤형 컨설팅 필요성 |
| 4 | 4단계 요약 | 진단 / 전략 실행 / 성과측정 / 유지보수 | 프로세스 신뢰 |
| 5 | Point 01 | 모든 분야의 AX 전략을 보유합니다 | 적용 범위 강조 |
| 6 | Point 02 | 단 5단계로 현장을 바꿉니다 | 실행 방식 구체화 |
| 7 | Point 03 | 실행 이후 운영까지 지원합니다 | 도입 후 불안 해소 |
| 8 | 차별화 섹션 | 비즈니스 임팩트 중심 / 유지보수 지원 | "AI 툴 판매"와 구분 |
| 9 | 성공 사례 | 80% 단축, 94% 단축 등 | 사회적 증거 |
| 10 | 최종 CTA | AX 컨설팅 신청하기 | 전환 |
| 11 | 푸터 | 회사 정보, 지사, SNS | 신뢰 보강 |

### 2.2 강점

**목적이 명확하다.**  
페이지 전체가 "AX 컨설팅 신청"으로 수렴한다. 교육, 용역, 사례집은 보조 탐색이고 메인 CTA는 상담 신청이다.

**구조가 쉽다.**  
"모든 기업에 같은 AX는 없다" → "우리는 이렇게 바꾼다" → "다른 점은 이렇다" → "사례를 보라" 순서다. 방문자가 복잡한 개념을 학습하지 않아도 된다.

**현장 이미지가 있다.**  
히어로와 중간 섹션에 실제 사무실/상담 이미지가 들어간다. AI 컨설팅 페이지에서 흔한 추상 그래픽보다 신뢰가 높다.

**사례에 숫자가 있다.**  
"블로그 작성 시간 80% 단축", "글로벌 트렌드 조사 시간 94% 단축"처럼 성과를 숫자로 보여준다. 하와도 반드시 이 방식을 써야 한다.

**도입 이후 운영을 말한다.**  
마케팅 자동화 구매자의 큰 불안은 "설치 후 우리가 쓸 수 있나?"다. AI TEAM은 유지보수/운영지원 섹션으로 이 불안을 줄인다.

### 2.3 약점

**첫 화면의 전환력이 약하다.**  
히어로 카피가 "실제 현장을 바꾸는 AI팀 컨설팅"이라 방향은 맞지만, 결과 숫자가 없다. HOWAAA는 첫 화면에서 "마케팅 시간이 얼마나 줄고, 리드가 어떻게 쌓이는지"를 말해야 한다.

**핵심 증거가 늦게 나온다.**  
성공 사례가 페이지 하단에 나온다. 모바일 기준으로 한참 내려야 숫자를 본다. HOWAAA는 히어로 직후에 증거 바를 둬야 한다.

**범위가 과하다.**  
"100개 이상 분야"는 큰 회사처럼 보이는 장점은 있지만, 하우제로의 강점인 직설적 실전성에는 덜 맞다. 하와는 많은 분야보다 "마케팅 병목 6종을 빠르게 깎는다"가 더 세다.

**CTA 문구가 추상적이다.**  
"AX 전문가 상담 신청"은 B2B에서는 무난하지만, 초기 방문자에게는 부담이 있다. HOWAAA는 "30분 무료 마케팅 AX 오딧"처럼 손실이 낮고 결과가 분명한 CTA가 맞다.

**모바일 여백과 애니메이션 의존이 크다.**  
Playwright 전체 캡처 기준 일부 섹션의 텍스트가 흐리게 보이고, 큰 여백이 많다. 하와는 모바일에서 마케팅 사례, CTA, 진단 흐름을 더 빨리 보여줘야 한다.

## 3. HOWAAA 마케팅 AX 포지셔닝

### 3.1 핵심 한 문장

> AI 툴을 설치하는 게 아닙니다.  
> 마케팅에서 새는 시간과 리드를 찾아 자동화하고, 매달 쌓이는 매출 파이프라인으로 바꿉니다.

### 3.2 하와가 가져가야 할 차별점

| 구분 | AI TEAM식 메시지 | HOWAAA식 메시지 |
|---|---|---|
| 서비스명 | AX 컨설팅 | HOWAAA Marketing AX |
| 첫 메시지 | 실제 현장을 바꾸는 컨설팅 | 30분 안에 마케팅 병목과 리드 누수를 숫자로 보여드립니다 |
| 강조점 | 맞춤형 AX 전략 | 콘텐츠-리드-팔로업-리포팅 자동화 |
| 권위 | 조직/서비스 신뢰 | 연매출 10억 실전 경험, 직접 해본 사람 |
| 증거 | 사례 카드 | 콘텐츠 생산 시간, SEO 리포팅 시간, 리드 응답 속도, 전환율 |
| CTA | 전문가 상담 신청 | 무료 마케팅 AX 오딧 신청 |
| 톤 | 안정적 B2B | 직설적, 데이터 기반, 과장 배제 |

### 3.3 쓰면 안 되는 방향

- "최신 AI로 혁신합니다" 같은 범용 AI 카피
- 툴 목록 중심 설명
- "모든 업종 가능"만 강조하는 넓은 포지셔닝
- 실제 수치 없이 "효율 상승", "생산성 향상"만 반복
- CS/정산/제조 견적처럼 마케팅과 직접 연결되지 않는 전사 업무를 메인으로 배치
- 상담 전부터 복잡한 구축 패키지를 길게 설명

## 5. 카피 초안

### 5.1 히어로

**헤드라인**

> 마케팅 자동화, 툴 세팅이 아니라 매출 파이프라인입니다.

**서브카피**

> 30분 HOWAAA 오딧으로 콘텐츠, SEO, 리드 응대, 팔로업, 리포팅 병목을 진단하고 자동화 가능성을 숫자로 보여드립니다.

**CTA**

- 메인: `30분 무료 마케팅 AX 오딧`
- 보조: `자동화 사례 보기`

**보조 신뢰 문구**

> 하우제로는 GPT-3 기반 SaaS로 연매출 10억을 만든 실전 경험을 바탕으로, 복잡한 AI 도입보다 마케팅 실행에서 새는 리드와 시간을 먼저 줄입니다.

### 5.2 문제 제기

> 기업의 진짜 문제는 AI를 안 쓰는 게 아닙니다.  
> 콘텐츠를 만들고, 리드를 받고, 팔로업하고, 리포트를 보는 흐름이 끊기는 겁니다.

예시:

- 매주 밀리는 블로그, 숏폼, 뉴스레터 초안
- 매일 검색해서 정리하는 SEO/시장 조사
- 광고, 유입, 전환 데이터를 손으로 합치는 리포트
- 문의가 들어와도 늦게 이어지는 팔로업
- 고객 세그먼트별로 달라지지 않는 CRM 메시지
- 매번 새로 만드는 제안서, 세일즈 자료, 케이스 스터디

### 5.3 HOWAAA 3단계

| 단계 | 메시지 | 방문자가 얻는 답 |
|---|---|---|
| A1 Audit | 30분 안에 마케팅 병목을 찾습니다 | 어디서 리드와 시간이 새는가 |
| A2 Automate | 콘텐츠-리드-팔로업 자동화부터 설치합니다 | 무엇부터 자동화할 것인가 |
| A3 Accumulate | 리드, 콘텐츠, 전환 데이터를 쌓습니다 | 매달 어떤 파이프라인이 남는가 |

### 5.4 사례 카드 포맷

각 사례는 아래 구조를 고정한다.

```text
[채널/업무]
문제: 사람이 매주 00시간 쓰던 마케팅 업무
자동화: 아이디어 → 제작 → 발행 → 리드 수집 → 팔로업까지 자동화
결과: 월 00시간 절감 / 콘텐츠 00개 생산 / 리드 응답 속도 00배 / 전환율 00%
증거: 실제 화면 캡처 또는 산출물 일부
[자세히 보기]
```

실제 숫자가 없는 사례는 노출하지 않는다. 숫자가 없으면 "정성 후기"가 아니라 "후보 사례"로만 보관한다.

## 6. 벤치마킹 적용 우선순위

### P1: 전환 구조

| 작업 | 이유 | 기준 |
|---|---|---|
| 히어로 CTA를 `30분 무료 마케팅 AX 오딧`으로 고정 | 상담보다 진입 장벽 낮음 | 첫 화면 CTA 클릭률 |
| 히어로 직후 증거 바 배치 | 신뢰를 빠르게 제공 | 2스크롤 이내 권위/성과 노출 |
| 사례 1개를 상단으로 이동 | 숫자 증거를 늦게 보여주면 이탈 | 모바일 3번째 섹션 안에 사례 노출 |
| 하단 고정 CTA 추가 | 긴 랜딩에서 전환 손실 감소 | 모바일 전 구간 CTA 접근 가능 |

### P2: 메시지와 콘텐츠

| 작업 | 이유 | 기준 |

## 7. 전환 설계

### 7.1 CTA 문구 체계

| 위치 | CTA |
|---|---|
| 헤더 | 30분 무료 마케팅 오딧 |
| 히어로 | 30분 무료 마케팅 AX 오딧 |
| 문제 섹션 후 | 우리 회사 마케팅 병목 찾기 |
| 사례 섹션 후 | 비슷한 마케팅 업무 진단받기 |
| 가격 섹션 후 | 무료 오딧 후 구축 범위 받기 |
| 최종 CTA | 30분이면 충분합니다. 지금 마케팅 병목 진단받기 |

### 7.2 신청 폼 필드

초기 폼은 5개를 넘기지 않는다.

1. 이름
2. 연락처
3. 회사/브랜드명
4. 가장 병목인 마케팅 채널
5. 월 마케팅 반복 시간 추정

폼 완료 후에는 "상담 확정"이 아니라 "오딧 준비" 흐름으로 연결한다.

### 7.3 리드 품질 필터

무료 오딧이 너무 넓게 열리면 타이어 키커가 늘어난다. 그래서 폼에 아래 질문을 넣는다.

> 한 달에 사람이 반복 처리하는 마케팅 업무가 몇 시간 이상인가요?

선택지:

- 10시간 미만
- 10-30시간
- 30-100시간
- 100시간 이상

10시간 미만은 상담보다 자가진단/뉴스레터로 보내는 것이 맞다.

## 9. 구현 전 승인 기준

이 문서 기준으로 실제 Howwaaa/랜딩을 수정하기 전, 아래 6개를 확정해야 한다.

1. 메인 CTA를 `30분 무료 마케팅 AX 오딧`으로 확정할지
2. 히어로 헤드라인을 `마케팅 자동화, 툴 세팅이 아니라 매출 파이프라인입니다.`로 갈지
3. 첫 사례에 사용할 실제 마케팅 전후 수치
4. 무료 오딧 신청 폼 필드
5. 패키지 가격을 페이지에 노출할지
6. 하와 랜딩의 대상이 1인 기업/대표인지, 마케팅 담당자가 있는 중소기업인지
