## 1. 포지셔닝

AI TEAM은 전사 AX 전환 페이지다.  
HOWAAA는 마케팅 AX로 좁힌다.

핵심 범위:

- 콘텐츠 제작 자동화
- SEO/시장 조사 자동화
- 리드 수집 및 태깅
- CRM 팔로업
- 광고/유입/전환 리포팅
- 세일즈 자료와 케이스 스터디 생성

핵심 메시지:

> 마케팅 자동화, 툴 세팅이 아니라 매출 파이프라인입니다.

---

## 2. Desktop Wireframe

### 2.1 Header

**목적**: 방문자가 서비스 범위와 CTA를 즉시 이해한다.

구성:

- 좌측: HOWAAA 로고
- 중앙: `마케팅 사례`, `진행 방식`, `가격`, `FAQ`
- 우측: `30분 무료 오딧` 버튼

주의:

- 메뉴를 많이 늘리지 않는다.
- `AX`, `AI`, `컨설팅`만 반복하지 말고 `마케팅 사례`를 첫 메뉴로 둔다.

### 2.2 Hero

**목적**: 첫 화면에서 전사 AX가 아니라 마케팅 AX임을 고정한다.

헤드라인:

> 마케팅 자동화, 툴 세팅이 아니라 매출 파이프라인입니다.

서브카피:

> 30분 안에 콘텐츠, SEO, 리드 응대, 팔로업, 리포팅 병목을 진단합니다.

CTA:

- Primary: `30분 무료 마케팅 AX 오딧`
- Secondary: `사례 먼저 보기`

우측 시각 자산:

- 추상 AI 그래픽 금지
- 실제 콘텐츠 캘린더, 리드 테이블, CRM 플로우, 리포팅 대시보드 중 하나 사용
- 민감 정보는 마스킹

### 2.3 Proof Bar

**목적**: 스크롤 전에 신뢰 근거를 제시한다.

4개 항목:

1. 연매출 10억 실전 경험
2. 콘텐츠 자동화
3. 리드 팔로업 자동화
4. 비개발 조직 운영 가능

표현 규칙:

- 가능하면 숫자를 쓴다.
- 숫자가 없는 항목은 짧은 명사형으로 둔다.
- 로고 나열보다 결과 지표가 우선이다.

### 2.4 Problem

**목적**: 방문자가 자기 문제를 찾게 한다.

섹션 카피:

> AI가 없는 게 문제가 아닙니다.  
> 마케팅 실행과 후속 관리가 새는 게 문제입니다.

문제 카드:

- 매주 밀리는 블로그, 숏폼, 뉴스레터 초안
- 매일 검색해서 정리하는 SEO/시장 조사
- 광고, 유입, 전환 데이터를 손으로 합치는 리포트
- 문의가 들어와도 늦게 이어지는 팔로업
- 고객 세그먼트별로 달라지지 않는 CRM 메시지
- 매번 새로 만드는 제안서, 세일즈 자료, 케이스 스터디

### 2.5 HOWAAA 3-Step

**목적**: HOWAAA 방법론을 브랜드 자산으로 각인한다.

| 단계 | 라벨 | 설명 |
|---|---|---|
| A1 | Audit | 마케팅 병목과 리드 누수 진단 |
| A2 | Automate | 콘텐츠-리드-팔로업 자동화 설치 |
| A3 | Accumulate | 리드, 콘텐츠, 전환 데이터 축적 |

디자인:

- 세 단계는 가로로 배치한다.
- 각 단계는 1문장만 둔다.
- `Audit`, `Automate`, `Accumulate` 영문을 같이 노출한다.

### 2.6 Marketing Bottleneck Cards

**목적**: "내 업무도 해당된다"는 자기 인식을 만든다.

6개 카드:

1. 콘텐츠
2. SEO
3. 리드 수집
4. CRM 팔로업
5. 광고 리포팅
6. 세일즈 자료

각 카드 구조:

```text
업무명
Before: 사람이 매주 반복
After: 자동 생성/정리/전달
측정: 시간, 생산량, 응답 속도, 전환율 중 1개
```

### 2.7 Process

**목적**: 상담 이후 무엇이 일어나는지 불안을 줄인다.

5단계:

1. 무료 오딧
2. 마케팅 병목 지도
3. 자동화 설계
4. 구축·교육
5. 월간 개선

주의:

- 단계 설명을 길게 쓰지 않는다.
- "컨설팅 후 끝"이 아니라 "운영 개선"까지 보여준다.

### 2.8 Case Studies

**목적**: 추상적 주장을 숫자로 증명한다.

상단에 3개만 노출한다.

카드 포맷:

```text
[채널/업무]
문제: 사람이 매주 00시간 쓰던 마케팅 업무
자동화: 아이디어 → 제작 → 발행 → 리드 수집 → 팔로업
결과: 월 00시간 절감 / 콘텐츠 00개 생산 / 리드 응답 속도 00배 / 전환율 00%
증거: 실제 화면 캡처 또는 산출물 일부
```

규칙:

- 숫자 없는 사례는 메인에 올리지 않는다.
- "좋아졌다" 대신 전후 수치를 넣는다.

### 2.9 Packages

**목적**: 가격 불안을 줄이고 상담 전 기대치를 맞춘다.

패키지 후보:

| 패키지 | 역할 |
|---|---|
| Marketing Audit | 무료 진단 |
| Content Engine | 콘텐츠 생산 자동화 |
| Lead Engine | 리드 수집·태깅·팔로업 자동화 |
| Growth OS | 콘텐츠, 리드, 리포팅 통합 운영 |

가격 노출은 선택 사항이다.  
노출한다면 "기준가"로만 표기한다.

### 2.10 FAQ

**목적**: 얼리 머조리티의 반대 논리를 선제 해소한다.

필수 질문:

- 비개발자도 운영 가능한가요?
- 어떤 마케팅 채널부터 자동화하나요?
- 기존 노션, 구글시트, CRM과 연결되나요?
- 보안과 고객 정보는 어떻게 처리하나요?
- 구축까지 얼마나 걸리나요?
- 유지보수는 포함되나요?

### 2.11 Final CTA

**목적**: 마지막 전환.

카피:

> 30분이면 충분합니다.  
> 마케팅에서 자동화할 병목이 없으면 팔지 않습니다.

CTA:

`무료 마케팅 AX 오딧 신청`

## 3. Mobile Wireframe

모바일에서는 설명보다 전환 속도가 중요하다.

순서:

1. Logo + 고정 CTA
2. Hero
3. Primary CTA
4. Proof Bar
5. 마케팅 병목 6개
6. HOWAAA 3단계
7. 대표 사례 1개
8. 진행 방식
9. 패키지
10. FAQ
11. Bottom CTA

모바일 규칙:

- 첫 CTA는 1스크롤 안에 있어야 한다.
- 대표 사례는 3스크롤 안에 보여야 한다.
- 하단 고정 CTA를 둔다.
- 카드 안 텍스트는 2줄을 넘기지 않는다.

---

## 4. 필요한 입력 자료

구현 전 필요한 자료:

1. 실제 마케팅 자동화 사례 3개
2. 각 사례의 전후 숫자
3. 리드/콘텐츠/리포팅 화면 캡처
4. 무료 오딧 결과 샘플
5. 신청 폼에 연결할 예약 또는 문의 흐름

사례 숫자 후보:

- 콘텐츠 생산 시간
- 콘텐츠 발행 개수
- SEO 리포팅 시간
- 리드 응답 속도
- 팔로업 누락률
- 광고 리포트 작성 시간
- 전환율 또는 상담 예약률
