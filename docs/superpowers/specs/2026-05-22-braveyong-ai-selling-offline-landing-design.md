# BraveYong AI 셀링 오프라인 실전반 상세페이지 설계

작성일: 2026-05-22
개정: 2026-05-22 (오빵 일본 구매대행 펀딩 상세페이지 구조 벤치마크 반영 — 신뢰 증거·반론 차단·비교표·소수정예 블록 추가, 톤 가드 유지)

## 목적

용감한 용팀장 유료강의 상세페이지를 설계한다. 이 페이지는 단순 무료강의 신청 페이지가 아니라, 페이지 하나만 보고도 `6주 오프라인 AI 셀링 실전반`의 가치, 일정, 가격, 선별 기준, 결제 흐름을 판단할 수 있는 세일즈 페이지다.

## 작업 결론

상세페이지의 핵심 상품은 `6주 오프라인 AI 셀링 실전반`이다.

- 무료 전환강의: 2026년 6월 10일 수요일, 유튜브 진행
- 본강의 시작: 2026년 6월 13일 토요일
- 본강의 구성: 오프라인 6회 + 줌 보강 5회
- 장소: 서울 강남
- 시간: 추후 안내
- 모집 인원: 10~15명
- 가격: 1기 실행자 특별가 180만원, 2기 이후 정가 250만원
- 결제 방식: 카드 결제 / 계좌이체 가능
- 결제 안내: 신청서 검토 후 참여 확정자에게 개별 안내
- 졸업 후 스터디: 매월 1회 오프라인, 3개월 15만원, 선택 참여

## 핵심 포지셔닝

넓은 입구는 `직장인 부업`, `육아아빠`, `초보 셀러`다. 실제 구매 문제는 `대량등록`, `무작정 상품 올리기`, `많이 올렸는데 안 팔림`, `매출은 있는데 안 남음`, `정책 변화와 등록 한도 불안`이다.

핵심 문장:

```txt
저도 직장 다니고,
애 재우고 나서 상품 올렸습니다.

그래서 압니다.
초보 셀러에게 필요한 건 더 많은 상품이 아니라,
적은 시간 안에 팔릴 가능성을 높이는 AI 셀링 구조입니다.
```

서브 약속:

```txt
1000개를 무작정 올리는 셀러에서
효자상품 10개를 만드는 셀러로.
```

## 접근안 비교

### 접근안 A. 무료강의 신청 중심 페이지

상세페이지의 주 CTA를 `6월 10일 유튜브 무료강의 신청하기`로 두는 방식이다.

장점은 진입장벽이 낮고 신청 수를 만들기 쉽다는 점이다. 단점은 180만원 본강의 결제 판단을 페이지 안에서 끝내기 어렵다는 점이다.

### 접근안 B. 본강의 지원 중심 페이지

상세페이지의 주 CTA를 `6주 오프라인 실전반 지원하기`로 두고, 무료 유튜브 강의는 지원 과정에 포함된 전환 이벤트로 둔다.

장점은 페이지 하나만 보고도 가격, 일정, 상품 가치, 결제 흐름을 판단할 수 있다는 점이다. 단점은 페이지 설득 밀도가 높아야 한다.

### 접근안 C. 프리미엄 선별형 페이지

가격, 인원 제한, 신청서 검토를 강하게 내세워 아무나 받지 않는 소수정예 과정으로 포지셔닝한다.

장점은 가격 방어와 수강생 퀄리티 관리가 쉽다는 점이다. 단점은 첫 기수 모집에서 신청 장벽이 높아질 수 있다는 점이다.

### 채택안

B를 기본 구조로 채택하고, C의 선별감을 결합한다.

즉, 페이지는 본강의 결제 직전까지 설득하는 세일즈 페이지로 만들고, 실제 결제는 신청서 검토 후 맞는 사람에게만 안내한다.

## 벤치마크 분석: 오빵 일본 구매대행 펀딩 상세페이지

같은 니치(AI 셀링·구매대행·부업 강의)의 와디즈 앵콜 펀딩 상세페이지(메이커 `오빵`, 50p)를 구조 기준으로 분석했다. 흐름은 아래와 같다.

| 블록 | 역할 |
|---|---|
| 상단 후킹/요약 | 무료강의 신청 + 최신판 배너 |
| 펀딩 실적·후기·사례 (3중) | 신뢰 선점 (1.3억→18억, 27,444명, 평점 5.0) |
| 일상 공감 후킹 | "일본 여행 기념품이 통장에 18억" |
| 관점 전환 | "누군가엔 기념품, 누군가엔 억대 매출 아이템" |
| 수익 후킹 + 수강생 인증 | 매출표·그래프·후기 캡처 |
| 솔루션 등장 + 리스크 제로 | "무한 반복 수익 루프 / 돈 잃을 수 없다" |

### 채택할 것 (구조)

- **신뢰 증거 블록을 Hero 직후에 추가**: 현업셀러 사실 지표 + 1기 후기 자리.
- **반론 차단 블록을 가격 직전에 추가**: "이미 늦었다 / 시간 없다 / AI 몰라도 되나" 등.
- **비교표 추가**: 일반 온라인 강의 vs 이 오프라인 실전반.
- **소수정예 희소성을 명시 블록화**: 10~15명 · 1기 특별가 (사실 기반).
- 관점 전환·솔루션·블루오션 톤은 braveyong 문제 제기 / AI 셀링 정의 블록에 흡수한다.

### 버릴 것 (톤 — 절대 차용 금지)

오빵 페이지의 다음 요소는 braveyong 톤 가드와 정면 충돌하므로 차용하지 않는다.

- 매출·수익 단정 ("월 2000만원", "18억", "월 500 신화")
- "리스크 제로 / 돈 잃을 수 없다" 류 보장
- "AI가 알아서 / 매크로로 평생 자동" 류 딸깍 자동화 과장
- 가짜 마감 카운트다운 · 조기마감 · 거짓 잔여석 압박

**원칙: 구조는 차용하고, 과장·보장·압박 카피는 차용하지 않는다. 강한 설득은 사실·구조·선별로 만든다.**

## 랜딩 페이지 구조

전체 구성은 아래 확장 순서를 따른다. 기존 1~12 섹션에 신뢰 증거·반론 차단·비교표·소수정예 블록을 더한 확장판이다. (✚ = 벤치마크 반영 신규/보강)

1. Hero
2. 신뢰 증거 (현업 사례 · 1기 후기 자리) ✚
3. 문제 제기
4. AI 셀링 정의
5. 핵심 결과물: 효자상품 10개
6. 6주 커리큘럼
7. 운영 방식
8. 왜 용팀장인가 (메이커 신뢰)
9. 졸업 후 오프라인 스터디
10. 반론 차단 (자주 하는 망설임) ✚
11. 비교표: 온라인 강의 vs 이 오프라인 실전반 ✚
12. 가격 섹션 + 소수정예 한정 ✚
13. 신청서와 선별 흐름
14. FAQ
15. 최종 CTA

> 아래 `### 1 ~ ### 12`는 기존 상세 스펙을 유지하며, 신규 블록은 삽입 위치에 `### N-B` 형태로 추가한다.

### 1. Hero

역할: 진정성, 대상, 본강의 약속을 첫 화면에서 전달한다.

구성:

- 용팀장 얼굴은 작게 사용한다.
- 상품등록, SEO 점검, AI 상품 분석, 상세페이지 기획 화면을 크게 보여준다.
- `유명한 사람이 파는 강의`가 아니라 `현업셀러가 실제로 쓰려고 만든 AI 셀링 작업법`처럼 보여야 한다.

Hero 카피:

```txt
저도 직장 다니고,
애 재우고 나서 상품 올렸습니다.

그래서 압니다.
초보 셀러에게 필요한 건 더 많은 상품이 아니라,
적은 시간 안에 팔릴 가능성을 높이는 AI 셀링 구조입니다.
```

Hero CTA:

```txt
6주 오프라인 실전반 지원하기
```

보조 문구:

```txt
신청서 검토 후 참여 안내와 결제 안내를 드립니다.
6월 10일 유튜브 무료강의 안내도 함께 보내드립니다.
```

### 1-B. 신뢰 증거 (현업 사례 · 1기 후기 자리) ✚

역할: 오빵 페이지의 "실적·후기·사례 3중 배치"를 정직 버전으로 가져온다. 1기라 누적 후기가 없으므로 과장하지 않고, 현업셀러로서의 사실과 후기 자리(placeholder)로 신뢰를 선점한다.

구성:

- 용팀장 현업 사실 지표 3~4개 (수익 단정 금지). 예: 직접 운영 중인 스토어, 직접 올린 상품 수, 누적 강의/상담 경험 등 — 실제 값은 운영 입력.
- "1기 후기 자리" placeholder: 1기 종료 후 실제 후기로 교체. 그 전까지는 `1기 모집 중 — 첫 후기를 함께 만들 분을 찾습니다`로 표시.
- 가짜 후기·가짜 숫자 금지. 확정 전 지표는 `운영 입력 필요`로 둔다.

운영 입력 필요:

- 현업 사실 지표 실제 값
- 1기 종료 후 후기 텍스트/캡처

### 2. 문제 제기

역할: 넓은 초보/부업 타겟을 대량등록 한계 문제로 좁힌다.

핵심 메시지:

- 상품을 많이 올렸는데 노출이 없다.
- 매출은 조금 있는데 순수익, CS, 시간 때문에 남는 게 없다.
- 정책 변화, 등록 한도, 프로그램 의존 방식이 불안하다.
- 더 많이 올리는 것이 아니라 다르게 만들어야 한다.

카피:

```txt
대량등록으로 버티던 셀러에게 필요한 건
더 많은 상품이 아니라, 팔리는 구조입니다.
```

### 3. AI 셀링 정의

역할: AI 셀링을 툴 사용법이 아니라 판매 운영 구조로 정의한다.

정의:

```txt
AI가 대신 팔아주는 게 아닙니다.
AI로 상품 선정, SEO, 상품명, 상세페이지, 등록 전 체크를
빠르게 반복하는 구조를 만드는 겁니다.
```

### 4. 핵심 결과물: 효자상품 10개

역할: 강의가 끝났을 때 무엇을 들고 나가는지 명확히 한다.

핵심 약속:

```txt
처음부터 1000개 효자상품을 만드는 건 불가능합니다.
그래서 6주 동안 먼저 효자상품 10개를 함께 만듭니다.
```

효자상품의 정의:

```txt
여기서 말하는 효자상품은 무작정 올린 상품이 아닙니다.
키워드, 카테고리, 상품명, 대표이미지, 상세페이지, 가격,
등록 전 체크가 맞춰진 상품입니다.
```

중요한 가드:

- `효자상품 10개`는 매출 보장 표현이 아니다.
- 페이지에서는 `용팀장 기준으로 팔릴 구조를 갖춘 상품 10개를 완성한다`는 의미로 정의한다.

제작 방식:

- 용팀장이 상품 선정 프레임을 제공한다.
- 수강생이 매주 과제로 1~2개씩 만든다.
- 기존 상품 개선과 새 상품 소싱을 모두 허용한다.
- 6주 동안 총 10개를 완성한다.

### 5. 6주 커리큘럼

본강의는 오프라인 6회와 줌 보강 5회로 구성한다. 오프라인은 현장 작업과 피드백, 줌은 중간 과제 보강 역할을 한다.

#### 1주차. 대량등록 탈출 진단

- 현재 방식, 시간, 마진, 노출 상태 진단
- 살릴 상품과 버릴 상품 기준 정리
- 6주 실행 목표 설정

산출물:

- 내 스토어 진단표
- 효자상품 기준표 초안
- 6주 개인 실행 목표

#### 2주차. 상품 선정, 키워드, 카테고리

- 감 소싱을 줄이고 검색 의도와 경쟁 구조 확인
- 카테고리와 상품명 기준 정리
- 효자상품 2개 설계

산출물:

- 후보 상품 리스트
- 키워드 맵
- 상품명 초안

#### 3주차. AI 상세페이지 설계

- 예쁜 상세페이지가 아니라 구매 이유와 불안 제거 순서로 기획
- 고객 고통, 대표 이미지, 상세페이지 스토리보드 작성

산출물:

- 상세페이지 스토리보드
- 이미지/카피 프롬프트
- 효자상품 추가 제작

#### 4주차. 등록, 대표이미지, 전환 체크

- 상품명, 대표이미지, 상세페이지, 가격, 배송/CS 문구 점검
- 등록 가능한 상품 세트 완성

산출물:

- 등록 가능한 상품 세트
- 등록 전 체크리스트
- 효자상품 추가 제작

#### 5주차. AI 반복 작업 루틴

- 상품 분석, 상품명 개선, 상세페이지 초안, CS 답변, 개선 체크리스트를 템플릿화
- 다음 상품도 같은 기준으로 만들 수 있는 작업 루틴 정리

산출물:

- 개인 AI 셀링 템플릿
- 주간 작업 루틴표
- 효자상품 추가 제작

#### 6주차. 효자상품 10개 점검과 다음 30일 운영 계획

- 효자상품 10개 최종 점검
- 노출, 클릭, 문의, 주문, 순수익 관점의 개선 기준 정리
- 졸업 후 30일 실행 계획 수립

산출물:

- 효자상품 10개
- 30일 실행 계획
- 개선 우선순위
- 개인별 피드백

### 6. 운영 방식

구성:

- 오프라인 6회
- 줌 보강 5회
- 매주 과제
- 상품/스토어 피드백
- 10~15명 소수정예

장소와 일정:

- 무료 전환강의: 2026년 6월 10일 수요일, 유튜브 진행
- 본강의 시작: 2026년 6월 13일 토요일
- 장소: 서울 강남
- 시간: 추후 안내
- 상세 주소와 시간: 참여 확정자에게 안내

### 7. 왜 용팀장인가

역할: 강사 신뢰를 만든다. 과장된 수익 자랑보다 진정성 있는 현업셀러 서사를 사용한다.

핵심 방향:

- 직장인
- 육아아빠
- 현업셀러
- 직접 상품을 올려본 사람
- 대량등록의 한계와 막힘을 겪어본 사람
- 강의 쇼핑보다 실행 구조를 강조하는 사람

사용할 톤:

```txt
저도 직장 다니고, 애 재우고 나서 상품 올렸습니다.
그래서 시간이 부족한 셀러가 왜 무작정 많이 올리면 안 되는지 압니다.
```

피할 것:

- 검증 안 된 수익 단정
- 매출 보장
- AI가 대신 팔아준다는 표현
- 사람을 조롱하는 방식의 `가짜 셀러` 표현

### 8. 졸업 후 오프라인 스터디

위치: 가격 섹션 바로 앞.

역할: 180만원 가격을 보기 전에 장기 가치를 보여준다.

카피:

```txt
6주 강의는 시작일 뿐입니다.

졸업 후에는 매월 1회 오프라인 스터디로 계속 만나서 함께 성장합니다.
정책이 바뀌고, 네이버 로직이 바뀌고, 시장이 바뀌어도
혼자 다시 막히지 않도록 계속 업데이트합니다.
```

운영 방식:

- 매월 1회 오프라인 정기 모임
- 매 모임마다 용팀장 특강 1타임
- 남는 시간은 실습 + Q&A
- 정책 변화와 시장 변화에 맞춘 신규 내용 업데이트

비용:

- 3개월 15만원
- 월 5만원 꼴
- 강제 참여 아님
- 의지 있는 분만 참여

1기 혜택:

```txt
1기 수강생은 졸업 후 스터디 우선 참여권을 드립니다.
```

### 8-B. 반론 차단 (자주 하는 망설임) ✚

역할: 오빵 페이지의 objection-handling 블록을 가격 직전에 배치한다. 단, 보장·과장 없이 사실로만 답한다.

다룰 망설임:

- "이미 늦은 거 아닌가요?" → 대량등록 경쟁이 과열될수록 다르게 만든 상품의 가치가 커진다. AI 셀링 도구도 지금이 접근성이 가장 좋다.
- "시간이 없는데 6주 가능할까요?" → 그래서 매주 1~2개씩, 6주 총 10개로 쪼갰다. 직장·육아 병행 기준으로 설계.
- "AI를 잘 몰라요" → 툴이 목적이 아니라 반복 구조가 목적. 현장에서 같이 따라 만든다.
- "오프라인 못 가는 주가 있으면?" → 줌 보강 5회와 과제로 보완.

가드: 각 답변은 사실·구조로만. "무조건 된다 / 누구나 월 OOO" 같은 표현 금지.

### 8-C. 비교표: 온라인 강의 vs 이 오프라인 실전반 ✚

역할: 가격 방어를 표로 시각화한다. 오빵 페이지의 Package Comparison을 단일 상품용 비교표로 변형.

| 항목 | 일반 온라인 강의 | 6주 오프라인 실전반 |
|---|---|---|
| 진행 | 영상 시청 | 현장 작업 + 피드백 |
| 결과물 | 지식 | 효자상품 10개 (직접 완성) |
| 피드백 | 없음 / 일괄 | 상품·스토어 1:1 |
| 중간 점검 | 없음 | 줌 보강 5회 + 매주 과제 |
| 졸업 후 | 종료 | 매월 오프라인 스터디 (선택) |
| 인원 | 무제한 | 10~15명 소수정예 |

가드: 비교 대상을 비방하지 않는다. 사실 차이만 표기한다.
