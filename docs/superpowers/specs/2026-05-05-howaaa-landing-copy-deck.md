# HOWAAA 랜딩 카피 Deck v1

> 각 섹션마다 **추천안 (★)** 1개 + **변형 3~5개** 제공.
> 변형은 톤/각도가 다르므로, 페르소나(P1 운영리드 / P2 1인 사업가 / P3 C레벨)에 따라 골라 쓸 수 있도록 표기했다.
> A/B 테스트 시 추천안 vs 변형 1개로 짝짓기.

---

## 카피 작성 원칙 (전체 공통)

1. **수치 1자리 강조** — "90% 절감" / "1시간 → 8분" / "월 80개"
2. **"X가 아니라 Y" 대비 구문** — 차별화는 부정+긍정 쌍으로
3. **사람 / 시간 / 돈 한 가지로 말하기** — 한 섹션은 한 메트릭
4. **반말/존댓말 통일 = 존댓말** — HOWAAA는 B2B SaaS, HowZero 기본 직설 + 존댓말 톤
5. **AI / AX / OS 같은 약어는 첫 등장 1회만 풀어쓰기** — 이후 반복 금지
6. **"AI 팀"은 고유 표현으로 일관 사용** — "AI 에이전트들" / "복수 AI" 금지

## §1 Hero

### 의도
"AI 단일 도구"가 아니라 "AI 팀 협업 OS"라는 차별화를 첫 화면에서 박는다. 동시에 "운영 끝까지"라는 약속으로 read-on을 유도.

### ★ 추천안 (P1 + P3 균형)
```
(eyebrow) COLLABORATIVE AI OS

(H1)      콘텐츠 한 편을, AI 팀이
          끝까지 운영합니다.

(sub)     트렌드 수집부터 발행과 성과 회수까지.
          카드 하나가 AI 팀에 자동 배정됩니다.

(CTA)     14일 무료 체험 시작     도입 상담 받기
```

### 변형 A — 시간 절약 직격 (P2 1인 사업가)
```
(H1)  AI에게 콘텐츠 한 편을 맡겼더니,
      운영팀 하나가 사라졌습니다.

(sub) 트렌드부터 발행, 성과까지. AI 팀 6명이 카드 하나를 함께 굴립니다.
```

### 변형 B — 차별화 직설 (P3 C레벨)
```
(H1)  AI가 한 명이면 도구입니다.
      AI가 팀이면, 운영 OS입니다.

(sub) HOWAAA는 콘텐츠 카드 한 장을 AI 팀 6명에게 자동 배정합니다.
```

### 변형 C — 메트릭 약속 (P1 + P3)
```
(H1)  카드 한 장에 AI 팀 6명.
      콘텐츠 운영 시간 90% 절감.

(sub) 트렌드 수집·기획·집필·검증·발행·성과 회수.
      사람은 검증 Gate 1곳에서만 결정합니다.
```

### 변형 D — 질문 훅 (P1)
```
(H1)  어제 만든 콘텐츠, 지금 누가 운영하고 있나요?
      HOWAAA가 합니다.

(sub) AI가 만들기만 하는 시대는 끝났습니다.
      AI 팀이 발행과 성과까지 끌고 갑니다.
```

## §2 Problem

### 의도
"AI 도구는 다 비슷한데 왜 결과가 다른가?" 라는 운영 리드의 진짜 페인을 정면에서 짚는다. 짧고 단정적.

### ★ 추천안
```
(H3)  똑같은 AI 도구를 써도, 결과는 모두 다릅니다.

(p)   AI는 콘텐츠 한 편을 빠르게 만들 수 있습니다.
      하지만 트렌드 추적, 분배, 검증, 발행, 회수까지 운영하는 일은
      여전히 사람이 들고 있습니다.
```

### 변형 A — 시장 진단형
```
(H3)  AI는 만드는 데 1시간, 운영하는 데 9시간이 듭니다.

(p)   콘텐츠 한 편을 띄우려면 트렌드를 보고, 각도를 잡고,
      검수하고, 채널별로 나누고, 성과를 다시 묶어야 합니다.
      이 9시간을 누가 들고 있나요?
```

### 변형 B — 도구 피로형
```
(H3)  AI 도구 5개로 6시간을 쓴 적이 있나요?

(p)   결과물은 5곳에 흩어져 있고, 누가 무엇을 했는지 추적할 수 없습니다.
      도구가 늘수록 운영은 더 무거워집니다.
```

### 변형 C — 단정형 (가장 짧음)
```
(H3)  AI는 콘텐츠를 만들 뿐, 운영하지 않습니다.

(p)   그래서 매번 사람이 다시 챙겨야 합니다.
```

## §3 Point 01 — 트렌드 자동

### 의도
"입력부터 자동" — HOWAAA가 매일 아침 데이터 6종을 카드 위에 올려놓는다는 약속. "내가 트렌드 안 찾아도 됨"을 시각으로 증명.

### ★ 추천안
```
(pill)  POINT 01
(H3)    트렌드 근거 수집부터 자동입니다
(p)     유튜브, 인스타, 검색, 뉴스, 자사 데이터까지.
        HOWAAA가 매일 아침 콘텐츠 카드 위에 올려둡니다.
```

### 변형 A — 매일 아침 의식 강조
```
(H3)  매일 아침 6개 채널이 카드로 도착합니다
(p)   유튜브 트렌드, 인스타 해시태그, 검색량, 뉴스, GA4, 댓글까지.
      AI 팀이 분석을 끝낸 카드부터 보여드립니다.
```

### 변형 B — 사라지는 노동 강조
```
(H3)  "오늘 뭐 만들지" 회의가 사라집니다
(p)   HOWAAA가 6개 채널의 트렌드를 매일 카드로 정리합니다.
      회의가 아니라 결정만 하면 됩니다.
```

### 변형 C — 데이터 폭 강조 (P3 C레벨)
```
(H3)  6개 채널 + 자사 데이터, 한 카드에서
(p)   트렌드 수집 도구 5~6개를 매일 갈아입을 필요가 없습니다.
      모든 신호가 한 카드에 합쳐집니다.
```

### 카드 라벨 (6개)
| # | ★ 추천 | 변형 |
|---|---|---|
| 1 | YouTube 트렌드 | 영상 트렌드 / Reels 트렌드 |
| 2 | 인스타 해시태그 | 소셜 시그널 / 해시태그 클러스터 |
| 3 | 검색량 워드클라우드 | 키워드 검색 / 검색 의도 |
| 4 | 뉴스 헤드라인 | 산업 뉴스 / 시장 변화 |
| 5 | 자사 GA4 라인 | 우리 사이트 추세 / 자사 분석 |
| 6 | 댓글 / 리뷰 stack | VOC 시그널 / 고객 피드백 |

## §4 Point 02 — AI 팀 협업

### 의도
HOWAAA의 진짜 차별화. "AI 1명이 다 하는" 경쟁사 대비, "AI 5~6명이 분업"한다는 구조를 시각 + 카피로 못박는다. "사람은 1군데만 결정"으로 운영 부담을 0에 가깝게 약속.

### ★ 추천안
```
(pill)  POINT 02
(H3)    AI 한 명이 아니라 AI 팀이 일합니다
(p)     카드 한 장이 5명의 AI 담당자에게 차례로 배정됩니다.
        사람은 검증 Gate에서만 결정합니다.
```

### 변형 A — 분업 비유 직설
```
(H3)  AI 한 명이 다 하면 어디서 틀렸는지 모릅니다
(p)   HOWAAA는 카드 한 장을 5명의 AI에게 분업시킵니다.
      누가 어디서 잘못했는지 카드에 그대로 남습니다.
```

### 변형 B — 신뢰 강조 (P3)
```
(H3)  검증 없이 발행하지 않습니다
(p)   카드 한 장은 기획 → 집필 → 검증 → 발행 → 회수 5단계를 거칩니다.
      검증은 AI 팩트체커 + 사람 Gate가 함께 봅니다.
```

### 변형 C — 사람 시간 강조 (P2)
```
(H3)  사람은 검증 1곳에서만 결정합니다
(p)   기획·집필·발행·성과 회수는 AI 팀이 끝냅니다.
      여러분은 'OK / NG'만 누르면 됩니다.
```

### 5단계 라벨
| # | ★ 추천 | 짧은 변형 |
|---|---|---|
| 1 | 기획 | Plan |
| 2 | 집필 | Draft |
| 3 | 검증 | Verify |
| 4 | 발행 | Publish |
| 5 | 회수 | Review |

각 단계 한 줄 캡션:

| 단계 | ★ 한 줄 | 짧은 변형 |
|---|---|---|
| 기획 | 트렌드 카드 → brief + 각도 5개 | 무엇을 / 왜 / 누구에게 |
| 집필 | 초안 + 변형 5개 | 톤·길이별로 자동 다중 작성 |
| 검증 | 출처·숫자·표현 자동 검수 | 사람 Gate에서 최종 결정 |
| 발행 | 채널별 자동 게시 + 스케줄 | IG / Threads / Blog 동시 |
| 회수 | 성과를 다음 카드 컨텍스트로 | 인수인계 0회 |

## §5 Point 03 — 운영 자산화

### 의도
"한 번 만든 콘텐츠가 다음 콘텐츠의 컨텍스트가 된다" — HOWAAA만의 운영 자산화 개념. 인수인계가 사라진다는 긍정 약속.

### ★ 추천안
```
(pill)  POINT 03
(H3)    운영 카드가 사라지지 않고 자산이 됩니다
(p)     AI가 다음 카드를 만들 때, 지난 카드의 성과·결정이
        그대로 컨텍스트로 들어갑니다. 인수인계가 사라집니다.
```

### 변형 A — 신입 비유 (P1)
```
(H3)  매번 신입 AI에게 처음부터 설명하지 않습니다
(p)   지난 카드의 성과·실패·기획 결정이 그대로 다음 카드로 흐릅니다.
      AI는 잊지 않고, 사람은 매번 인수인계할 필요가 없습니다.
```

### 변형 B — 누적 자산 강조 (P3)
```
(H3)  콘텐츠가 쌓일수록 다음 콘텐츠가 빨라집니다
(p)   카드 100장이 쌓이면 101번째 카드는 100장의 결정을 모두 안고 시작합니다.
      운영의 학습 곡선이 우상향합니다.
```

### 변형 C — 직설 메트릭
```
(H3)  월 80장 운영, 인수인계 0회
(p)   사람이 떠나도, AI 팀이 바뀌어도
      카드 안에 모든 컨텍스트가 그대로 살아 있습니다.
```

### 한 줄 캡션 (사진 아래)
- ★ "월 80개 카드 운영 · 인수인계 0회"
- "AI 팀이 알아서 분배 · 사람은 결정만"
- "100장이 쌓이면 101번째가 빨라집니다"

## §6 Dark — 비즈니스 임팩트 중심

### 의도
"콘텐츠를 만들기만 하는 OS가 아니라, **비즈니스 임팩트로 연결되는** OS"임을 강조. C레벨 의사결정자에게 ROI 가능성을 보여줌.

### ★ 추천안
```
(H3)  AI 팀의 OS는,
      비즈니스 임팩트가 중심입니다.

(p)   콘텐츠는 단순히 발행하는 것이 아닙니다.
      매출 증대와 비용 절감으로 연결되는 카드만
      우선 순위에 올라옵니다.
```

### 변형 A — 부정+긍정 (ai-team 패턴 차용)
```
(H3)  발행이 목적이 아닙니다.
      성과가 목적입니다.

(p)   HOWAAA는 모든 카드를 비즈니스 KPI에 연결합니다.
      "발행했다"가 아니라 "기여했다"로 보고됩니다.
```

### 변형 B — 우선순위 강조
```
(H3)  매출에 연결되는 카드만, 위에 올라옵니다
(p)   AI 팀이 매일 80장의 카드를 트리아지합니다.
      여러분은 '오늘 뭐 할까'가 아니라 '오늘 어떤 KPI를 끌어올릴까'를 봅니다.
```

## §7 Dark — AI 팀 6명

"AI 팀이 진짜로 6명이 있다"를 페르소나 카드로 구체화. 단일 chatbot 경쟁사와 가장 강한 차별화 포인트.

### ★ 추천안
```
(H3)   AI 팀에는 6명의 담당자가 있습니다
(p)    각자 역할이 있고, 카드 한 장이 차례로 거쳐갑니다.
```

### 변형 A — 회사 비유
```
(H3)  AI에게도 직무 분담이 필요합니다
(p)   기획자, 카피라이터, 팩트체커, 채널 매니저, 분석가, 큐레이터.
      한 카드는 6명을 모두 거쳐야 발행됩니다.
```

### 변형 B — 결과 약속
```
(H3)  AI 6명, 사람 1명. 콘텐츠 80장.
(p)   각 담당자는 한 가지 일만 잘합니다. 그래서 결과가 깊어집니다.
```
