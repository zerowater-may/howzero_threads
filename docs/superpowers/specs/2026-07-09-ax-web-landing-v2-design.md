## 4. "당신 회사의 OS" 캔버스 상세

- **라이브러리**: `@xyflow/react` v12, 클라이언트 전용
- **구성**: 서사 헤더 → 4단계 스텝퍼(프로세스 정립→플로우 정립→잘게 쪼개기→자동화, 스크롤 시 순차 하이라이트) → 업무별 프리셋 탭 → 캔버스
- **프리셋 탭 4개**: CS 응대 / 정산·리포트 / 콘텐츠 제작 / 주문·재고. 탭 전환 시 nodes/edges 교체 (fade 트랜지션)
- **노드 타입 4종**: 트리거(회색) / AI 처리(오렌지 보더) / 휴먼 게이트(점선 — "사람이 지키는 게이트" 시각화) / Running(그린 + 펄스 뱃지, **각 파이프라인 마지막 노드에만** — "구축 후 운영 중" 상태 표현). 레퍼런스(flow-*.jpg)처럼 Settings·Output 뱃지 장식
- **4개 탭 파이프라인 확정** (노드명(타입) 순서):
  - **CS 응대**: 문의 수신(트리거) → AI 분류(AI) → 답변 생성(AI) → 휴먼 검수(게이트) → 발송(AI) → 로그·학습(Running)
  - **정산·리포트**: 판매 데이터 수집(트리거) → 정산 대사(AI) → 이상치 감지(AI) → 휴먼 확인(게이트) → 리포트 생성·발송(Running)
  - **콘텐츠 제작**: 소재 수집(트리거) → 초안 생성(AI) → 브랜드 톤 변환(AI) → 휴먼 승인(게이트) → 발행 예약(Running)
  - **주문·재고**: 주문 수신(트리거) → 재고 확인(AI) → 발주 제안(AI) → 휴먼 승인(게이트) → 발주·입고 추적(Running)
- **인터랙션**: 노드 자유 드래그, 엣지 dash 애니메이션, 노드 클릭 → 상세 카드("이 단계가 하는 일" 설명 필수. **시간 비교(before/after)는 검증된 내부 수치가 문서화된 노드에만 표기** — 현재 검증된 after 수치가 없으므로 v2 출시 시점에는 전 노드 생략, 04-persona §3의 내부 실적 문서화 완료 후 추가. 임의 수치 창작 금지)
- **모바일 폴백**: 캔버스 대신 세로 스텝 리스트(같은 정보, 드래그 없음)
- **데이터**: `presets.ts`에 탭별 nodes/edges 하드코딩 JSON. CMS 없음

## 5. 기술 아키텍처

- **유지**: Next.js App Router, port 3300, `/api/chat`(OpenRouter+리드 추출), `/api/leads`, PGlite(`.pglite`), ratelimit, ContactForm 로직, 테스트 2종
- **신규 의존성**: `@paper-design/shaders-react`, `@xyflow/react`, `three`, `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`, `framer-motion`, (lanyard가 요구 시) `meshline`
- **컴포넌트 구조**:
  - `src/components/hero/` — `HeroChat.tsx`(기존 리스킨), `ShaderOrb.tsx`, `LanyardBadge.tsx`
  - `src/components/os-canvas/` — `OsCanvas.tsx`, `nodes.tsx`(커스텀 노드 4종), `presets.ts`, `DetailCard.tsx`
  - 나머지 섹션은 `page.tsx` 내 마크업 유지 (v1 방식)
- **성능**: 3D/셰이더/캔버스 전부 `dynamic(import, { ssr: false })` + IntersectionObserver 뷰포트 진입 로드. 첫 페인트는 텍스트+채팅 골격(LCP 텍스트 우선)
- **주의 — 클라이언트 래퍼 필수**: `page.tsx`는 Server Component 유지. Next.js App Router에서 Server Component 안의 `dynamic(..., { ssr: false })`는 빌드 에러이므로, `LanyardBadge.tsx`·`OsCanvas.tsx` 등 무거운 컴포넌트는 각각 `"use client"` 래퍼 컴포넌트로 만들고 **그 내부에서** dynamic import 한다
- **globals.css**: 다크 토큰 재작성 (`--paper` → 다크 계열, 오렌지 액센트 변수 추가)
